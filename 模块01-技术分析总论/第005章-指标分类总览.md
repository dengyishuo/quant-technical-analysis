# 第005章 指标分类总览

在进入具体指标之前，先建立一张地图。技术指标数量众多，但如果按"它想从价格里提取什么信息"来划分，可以归为四类，彼此分工明确。

## 分类的依据

分类不按指标的数学形式（平均、差值、比值），而按它回答的问题。原因是数学形式会重复：移动平均与布林带都用到均值，但它们回答的问题完全不同，前者问方向，后者问波动幅度。

四类的划分标准如下：

| 类别 | 回答的问题 | 是否有方向 | 典型输出 |
|------|-----------|-----------|---------|
| 趋势类 | 价格往哪走，能持续多久 | 有 | 与价格同量纲，或无界的强度值 |
| 震荡类 | 当前处于极端还是均衡 | 弱 | 有界振荡值，通常在 0 到 100 之间 |
| 波动率类 | 波动有多剧烈 | 无 | 正数，量纲为价格或百分比 |
| 量价类 | 资金是在进场还是离场 | 有 | 累积值或偏离值 |

这个划分有一个实用的判别方法：**看指标是否带方向**。趋势类和量价类能给出多空的判断；波动率类完全不区分方向，只给出幅度；震荡类虽然数值有高低，但它的高低对应的是"偏离中枢的程度"，不是"趋势的方向"。

## 趋势类

趋势类指标的共同动作是**平滑**。价格序列里既有趋势也有噪音，平滑的目的是压掉噪音、留下方向。

这一类内部按平滑方式分三种。**等权平滑**的代表是简单移动平均（SMA），它对每一期价格赋予相同权重，最贴近"平均持仓成本"的概念，代价是滞后最长。**加权平滑**包括加权移动平均（WMA）和指数移动平均（EMA），前者用线性递减权重，后者用指数衰减权重，都对近期价格赋予更高权重，因而反应更快。**滞后补偿**类包括双指数移动平均（DEMA）和零延迟指数移动平均（ZLEMA），它们的思路是承认滞后存在，然后从公式上减去滞后的估计量。

第二组趋势指标关注方向强度而非位置。动向指标（DMI）把上涨动向与下跌动向分开度量，得到两个方向性数值；平均趋向指数（ADX）把这两个数值合成一个无方向的趋势强度值。抛物线指标（SAR）则是一个完整的跟踪止损系统，它用一条随时间加速移动的曲线，给出止损位置的反转信号。

第三组是差值型。指数平滑异同平均线（MACD）用两条不同周期的 EMA 之差构造动能曲线，再用它的平滑线给出信号。双移动平均线（DMA）和多空指数（BBI）是这一思路的简化版。

趋势类指标的共同弱点是**在震荡市失效**。平滑的本质是假设方向存在，当方向不存在时，平滑的结果就是在价格附近来回摆动，产生大量假信号。这是所有趋势指标的结构性缺陷，不是参数能解决的。

## 震荡类

震荡类指标的共同动作是**标准化**。它们把价格在某段区间中的位置，或者涨跌力量的对比，映射到一个有界刻度上，通常是 0 到 100。

映射的目的是让不同标的、不同价位的数据可以横向比较。贵州茅台的价格是 1500 元，某只低价股是 5 元，绝对价格没法比；但它们的相对强弱指数都落在 0 到 100 之间，就可以比。

这一类分两种构造方式。**区间位置型**看当前价格落在近期区间的哪个位置：随机指标（KDJ）、威廉指标（WPR）属于这一种，它们用最高价与最低价构造区间。**力量对比型**看涨跌力量的比值：相对强弱指数（RSI）比较平均涨幅与平均跌幅，商品通道指数（CCI）比较价格与均线的偏离程度，变化率指标（ROC）与变化率动量指标（CMO）比较不同时点的价格变化。

震荡类的用途集中在两处：识别极端位置（超买超卖），以及识别背离（价格创新高但指标不创新高）。它的结构性弱点是**在趋势市里失效**：强趋势中指标可以长时间停在极端区域，把超买当卖出信号的人会被持续上涨碾过。

## 波动率类

波动率类指标的共同动作是**度量离散程度**。它们关心的不是价格往哪走，而是价格走得有多剧烈。

最基础的是平均真实波幅（ATR），它先算每日的"真实波幅"（考虑跳空），再做平滑。历史波动率（HV）从收益率序列直接计算标准差。布林带（BBands）在均线上下加减标准差倍数形成通道，通道宽度随波动率自动伸缩。肯特纳通道（Keltner）和价格包络线（Envelope）是类似的通道构造，区别只在通道宽度用什么度量：肯特纳用真实波幅，包络线用固定百分比。

波动率类指标有两个典型用途。一是**风险控制**：用 ATR 的倍数设定止损距离，波动大的品种止损放宽，波动小的收紧，使得不同品种的风险暴露可比。二是**突破确认**：通道收窄往往意味着能量积累，随后的突破更可能有效。

波动率类在量化研究里地位特殊。它可以作为独立因子使用（低波动率异象是一个被广泛记录的异象），也可以作为风险模型的一部分。它与收益的关系通常是非线性的，这使它在机器学习模型里比在线性因子里更有价值。

## 量价类

量价类指标的共同动作是**加权或累加**。它们把成交量与价格变化方向结合起来，构造出反映资金流向的序列。

能量潮（OBV）的做法最直接：当日收涨就把成交量加上，收跌就减去，得到一个累积曲线。柴金资金流量（CMF）的做法更精细：先用收盘价在当日区间中的位置算出一个乘数，再用它给成交量加权。成交量震荡器（VO）不涉及方向，只比较短期与长期成交量均线的偏离，衡量资金活跃度的变化。

弹性成交量加权移动平均线（EVWMA）比较特殊，它把成交量作为权重引入移动平均，成交越大的日子对均线的影响越大，因此这条均线更贴近"真实成交成本"。

量价类的核心价值是**确认**。价格信号与成交量信号一致时可信度提升，不一致时降低。它的弱点是数据质量敏感：成交量数据的准确性不如价格，且不同市场对成交量的统计口径不同（比如是否包含大宗交易、是否双边计算）。

## 四类如何配合

单用一类指标，都会在特定市况下失效。四类配合的逻辑是：

**先用波动率和趋势判断市况。** 平均趋向指数高于 25 说明存在有效趋势，此时用趋势类指标顺势操作；低于 25 说明在震荡，此时用震荡类指标做区间操作。

**再用量价确认信号。** 趋势指标给出方向后，看成交量是否配合。突破时成交量放大，信号可信；成交量萎缩，可能是假突破。

**最后用波动率定仓位和止损。** 信号方向确定后，用真实波幅的倍数决定止损距离，用波动率倒数决定仓位大小，使得每个品种的风险贡献接近。

这四步的次序不能颠倒。先判断市况再选工具，与先选工具再找理由，结果差别很大。

## 本书的编排

第二部分按四类分篇，每篇先有一章讲该类的共性和内部差异，然后逐个指标展开。每个指标的写法固定为七段：

| 段落 | 内容 |
|------|------|
| 名称与来历 | 全称、英文、缩写，提出者与年代，原始动机 |
| 核心逻辑 | 它测量什么，为什么这样测量有用 |
| 计算公式 | 分步推导，含 LaTeX 公式与参数含义 |
| 用法与信号 | 常见信号形态及其含义 |
| 边界与误区 | 什么情况下失效，常见误用 |
| 代码实现 | R 与 Python 各一份可运行实现 |
| 量化检验 | 作为横截面因子的构造方式与验证口径 |
| AI 引导词 | 若干条自然语言指令，用于借助 AI 扩展研究 |

固定格式的好处是可以横向比较。读完几个指标之后，读者会形成自己的判断标准，不再需要依赖口诀。

## 小结

技术指标按"回答什么问题"分为四类：趋势类平滑价格以提取方向，震荡类标准化数值以判断偏离，波动率类度量离散程度以控制风险，量价类结合成交量以确认资金流向。判别方法是看指标是否带方向。四类的配合次序是先判断市况、再确认信号、最后定仓止损。本书第二部分按此分类逐指标展开，每个指标采用固定七段格式。
