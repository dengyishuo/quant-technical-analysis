# 第006章 从指标到可检验的因子

知道一个指标怎么算，和知道它是否有用，是两件不同的事。指标的存在只说明有人相信它有效，不说明它真的有效。检验有效性需要一套独立的方法，而方法本身要先讲清楚，才谈得上用在具体指标上。

这就是本章与下一章的定位。本章说明为什么要逐个检验、四步流程是什么；第 007 章把截面检验与择时检验的完整口径、公式、判读标准一次性交代。之后模块 03 到 06 的 28 个指标章，每一个都在讲完原理之后，直接接着走完这四步。读者不需要记住这套方法，后面每个指标都会重新用一遍。

## 为什么要以单个指标为单位

一个自然的疑问是：既然最终要做多因子模型，为什么不直接跳到组合，而要先逐个检查单个指标？

原因有三个。

**单个指标的检验结果是组合优化的输入。** 多因子合成时的权重，通常来自各因子的历史表现。如果单个指标的 IC 序列不干净，权重估计就会被污染。先逐个测准，再谈加权。

**单个指标的失效原因可以被诊断。** 一个组合表现不好，很难判断是哪个环节出了问题：可能是某个因子本身无效，可能是因子之间互相抵消，也可能是权重的估计噪声太大。而单个指标检验失败时，原因通常是具体的：或者构造方式不对，或者在这类标的上没效果，或者只在特定市况下有效。诊断得了，才有改进方向。

**技术指标的价值高度依赖构造方式。** 同一条 20 日均线，"价格相对均线的偏离百分比"与"均线本身的斜率"，是完全不同的两个特征，预测能力可以一个正一个负。不看构造方式而谈"均线有没有用"，这个问题的提法本身就有问题。

因此本书对每个指标的处理都从拆解开始：先问它能拆出哪些可入模的特征，再逐个检验。

## 四步流程

每个指标走完四步。

**第一步，拆解。** 一个指标不是单一数值，而是一族特征的来源。同一条均线至少可以拆出五组数：价格相对均线的偏离度（位置）、均线自身的变化率（方向）、变化率的变化率（加速度）、多条均线的排列状态（结构）、价格在均线上方持续的天数（久期）。拆解要回答的是：这个指标的信息可以被切分成哪几个正交或半正交的维度。

**第二步，检验截面选股能力。** 把一个特征用在横截面上：同一个时点，把所有标的按特征值排序，看排序能否预测未来收益的排序。核心工具是秩信息系数（Rank IC）及其稳定性指标 ICIR，配合分层回测看单调性。

**第三步，检验择时能力。** 把同一个特征用在单个标的时间序列上：特征值处于极端时，是否对应更好的进场或离场时机。这里用的工具与时序有关，包括时序 IC、信号触发日与非触发日的收益差异检验、极端分位的条件收益、以及完整的择时策略回测。

**第四步，检验组合使用。** 技术指标在实践中很少单独使用。多数指标有明确的互补对象：趋势指标配市况过滤器，震荡指标配趋势确认，量价指标用于信号验证。第四步先确定该指标的常见搭档，再把组合当作一个新的复合信号，重新走一遍第二步和第三步。

这四步的次序体现了本书的一个基本立场：**先确认单个零件可用，再讨论装配方式。** 反过来做，即先组合再验证，得到的结果无法归因。

## 一个容易混淆的地方

截面选股能力与择时能力是两个不同的概念，经常被混为一谈。

截面选股回答的是：**在同一时刻，买哪只。** 它比较的是标的之间的相对强弱。

择时回答的是：**在什么时刻，该不该买。** 它比较的是同一标的在不同时间的状态。

两者的关系不是包含关系。一个特征可以只有截面区分度而没有择时能力。典型例子是动量因子：在横截面上，过去涨得多的股票未来继续涨（截面有效）；但在时间序列上，市场整体的动量与市场整体未来收益的相关性可能接近于零，因为 "所有股票都涨" 这件事并不预示市场还会涨。

反过来，一个特征也可以只有择时能力而没有截面区分度。典型的是一些基于市场整体情绪或广度的指标：它们能提示市场整体的风险状态，但对选哪只股票没有帮助。

这个区分有实际后果。如果一个特征只有截面能力，它只能用于选股，不能用来决定仓位；如果一个特征只有择时能力，它只能用来调整整体敞口，不能用来排序。混淆两者，会导致工具用错地方。

第三部分因此把两类检验分开做，各自给出结论，而不是合成一个模糊的"有效性"判断。

## 检验纪律

为了让结果可比较、可复现，第三部分采用统一的检验纪律。这些标准在第四部分同样适用。

| 项目 | 标准 |
|------|------|
| 相关性方法 | 秩相关（Spearman），不用线性相关 |
| 截面标的数 | 不少于 50 只，5 只标的仅用于演示 |
| 行业控制 | 需要做行业中性处理，避免因子实为行业暴露 |
| 前向收益 | 1 日与 5 日，需说明是否使用复权价 |
| 交易成本 | 费率 0.0003，印花税 0.001，印花税单边收取 |
| 数据切分 | 按时间顺序切分，禁止随机打乱 |
| 样本外 | 必须留出独立的时间段做样本外检验 |
| 可交易性 | 剔除停牌、涨跌停无法成交的样本 |

测试结果全部按同一格式呈现，便于横向比较：IC 均值、IC 标准差、ICIR、IC 大于零的比例、分层回测各组年化收益与换手率、择时策略的年化收益与最大回撤。

## 这套流程怎么用

方法论定好之后，接下来是 28 个指标，分四类：

| 模块 | 覆盖指标 | 数量 |
|---|---------|------|
| 03 趋势类指标 | SMA、EMA、WMA、DEMA、ZLEMA、DMA、BBI、MACD、DMI、ADX、SAR | 11 |
| 04 震荡类指标 | RSI、KDJ、CCI、WPR、ROC、CMO、DPO、SMI | 8 |
| 05 波动率类指标 | ATR、HV、BBands、Keltner、Envelope | 5 |
| 06 量价类指标 | OBV、CMF、VO、EVWMA | 4 |

每个指标章固定十一节，前六节讲原理，后四节走检验：

| 段落 | 内容 |
|------|------|
| 名称与来历 | 全称、缩写、提出者、原始动机 |
| 核心逻辑 | 它测量什么，为什么这样测量有意义 |
| 计算公式 | 分步推导与参数含义 |
| 用法与信号 | 常见的信号形态 |
| 边界与误区 | 什么情况下失效 |
| 代码实现 | R 与 Python 各一份 |
| 拆解 | 拆成 3–5 个无量纲特征，说明各自的经济含义 |
| 截面选股能力 | 构造式、符号方向、预期表现、检验代码 |
| 择时能力 | 时序逻辑、检验方法、关键陷阱、检验代码 |
| 组合使用与验证 | 常见搭档、组合的截面验证与择时验证、增益判读 |
| AI 引导词 | 三条可交给 AI 助手的研究任务 |

把检验放在原理之后、而不是集中成一部分，是为了让问题连着答案出现。读完一个指标的公式和信号，紧接着的问题就是它到底有没有用；隔二十多章再回答，前面的细节已经淡了。模块 07 再做一次跨类别的组合验证，回答的是另一个层次的问题：单个都不错的几个特征，放在一起是否还成立。

模块 08 进入机器学习。它回答的问题是：当单个特征的线性组合已经做到极限时，如何用模型去挖掘特征之间的非线性关系与交互结构。

## 小结

检验一个指标是否有效，走四步：先拆解成可入模的特征，再分别检验截面选股能力与择时能力，最后检验它与常见搭档组合后的表现。以单个指标为单位的原因是可诊断、可归因，且单个指标的检验结果是后续组合与建模的输入。截面能力与择时能力是两个不同的概念，前者回答买哪只，后者回答何时买，需要分开检验。

这套流程会在后面 28 个指标章里反复用到。第 007 章给出全部公式与代码实现，指标章只调用、不重复推导。
