# 第007章 双重检验方法论：截面与择时

上一章说明了为什么要分开检验截面选股能力与择时能力。本章把两套检验的完整口径交代清楚，包括公式、计算步骤、判读阈值与代码实现。后续四章的所有检验都按这一章的标准执行，不再重复说明。

## 要解决的问题

假设把一条 20 日均线拆成了"价格偏离度"这一个特征。想判断它有没有用，会遇到三个具体困难。

第一，**用什么指标衡量有用**。收益率、胜率、夏普比率都有人用，但它们的口径不同，结论可能不一致。需要一个统一的评价语言。

第二，**两个不同的问题混在一起**。这条均线在选股上可能有用，在判断大盘高低上可能没用。如果只算一个数字，无法区分这两件事。

第三，**结果如何判断是好是坏**。IC 算出来是 0.04，这个数算好还是不好？没有基准就无法判断。

本章的方法论就是为了解决这三个问题。

## 核心思想

检验分两条线，各自有明确的回答对象。

**截面线**回答"买哪只"。做法是在每一个时点上，把所有标的按特征值排序，看这个排序能否预测未来收益的排序。由于每个时点都算一次，得到的是一个 IC 序列。序列的均值反映方向是否稳定，序列的标准差反映能力是否波动，两者相除得到一个风险调整后的度量。

**择时线**回答"何时买"。做法是在单个标的（或指数）上，看特征值处于不同区间时，其后的收益分布是否不同。这里不涉及标的之间的比较，只关心同一个标的在不同时刻的状态差异。

两条线用的数据相同，但组织方式不同：截面线按时间点切片，每个切片内部横向比较；择时线按标的切片，每个序列内部纵向比较。

**为什么不能合并成一个数字。** 因为两者的用途完全不同。截面能力用于构建股票组合，择时能力用于决定整体仓位。一个特征可能只具备其中一种能力，合并后会互相抵消，得到一个无意义的中间值。

## 方法细节

### 特征预处理

检验之前必须先预处理，否则得到的结果可能只是量纲或极值的产物。

**横截面标准化。** 在每一个时点内部，把特征值转换为标准分：

$$z_{i,t} = \frac{f_{i,t} - \text{median}(f_{\cdot,t})}{\text{MAD}(f_{\cdot,t})}$$

其中 MAD 是绝对中位差，定义为

$$\text{MAD}(f_{\cdot,t}) = \text{median}\left(|f_{i,t} - \text{median}(f_{\cdot,t})|\right)$$

用中位数与 MAD 而非均值与标准差，是因为金融数据的分布有明显厚尾，均值和标准差会被极值拉动。

**去极值。** 把标准化后的值截断在 ±3 之间：

$$z_{i,t} \leftarrow \max(-3, \min(3, z_{i,t}))$$

这一步的作用是防止个别异常值主导 IC 的计算。检验用秩相关，本身对极值不敏感，但分层回测会受影响。

**行业中性。** 在行业内做去均值处理，避免特征值实际上代表的是行业属性。做法是在每个时点、每个行业内部减去该行业的均值。

### 截面选股能力

**第一步，计算 IC 序列。** 在每个时点 t，计算特征值排名与未来 h 日收益排名的秩相关系数：

$$IC_t = \rho_s\left(f_{\cdot,t},\ r_{\cdot,t\to t+h}\right)$$

其中 $\rho_s$ 是 Spearman 秩相关系数。用秩相关而非线性相关，是因为特征与收益的关系通常不是线性的，而且秩相关对异常值稳健。

$h$ 的取值至少算两组：$h=1$ 反映超短期预测能力，$h=5$ 反映一周的预测能力。两个值差异很大时，说明特征的衰减速度不同。

**第二步，汇总统计量。**

$$\overline{IC} = \frac{1}{T}\sum_{t=1}^{T} IC_t$$

$$\sigma_{IC} = \sqrt{\frac{1}{T-1}\sum_{t=1}^{T}\left(IC_t - \overline{IC}\right)^2}$$

$$ICIR = \frac{\overline{IC}}{\sigma_{IC}}$$

$$t_{IC} = ICIR \times \sqrt{T}$$

$t_{IC}$ 用于判断 IC 均值是否显著异于零。经验上 $|t_{IC}|$ 大于 2 可以认为显著，但要注意 IC 序列存在自相关，标准误会被低估，实际门槛应更高。

**ICIR 是一个与频率绑定的数。** 公式里没有出现频率，但 IC 序列本身有：日频 IC 的标准差通常远大于月频，同样的预测能力，日频算出的 ICIR 会小得多。因此两个不同频率的 ICIR 不能直接比较，也不能套同一张阈值表。

频率的影响可以直接从 t 统计量看出来。$T=252$ 时，ICIR 为 0.13 只能得到 $t \approx 2.06$，刚刚过线；$T=36$ 时，ICIR 为 0.33 才有同样的 $t$。换句话说，日频研究需要更大的样本量才能把同样强度的信号检出，而 ICIR 的阈值必须随频率调整。下面的表把两个常用口径分开列。

**第三步，分层回测。** 按特征值把标的分为 Q 组（通常 Q 取 5 或 10），计算每组的平均未来收益：

$$r_{q,t} = \frac{1}{|S_{q,t}|}\sum_{i \in S_{q,t}} r_{i,t \to t+h}$$

其中 $S_{q,t}$ 是第 t 期第 q 组的标的集合。检验单调性：计算组序号与组平均收益的秩相关，接近 1 说明单调性好。

**第四步，计算换手。** 换手率决定成本。单边换手定义为相邻两期持仓集合的差异比例：

$$turnover_t = 1 - \frac{|S_{q,t} \cap S_{q,t-1}|}{|S_{q,t}|}$$

**判读标准。** 以下阈值是经验值，不是硬性规则：

| 指标 | 口径 | 可用 | 良好 | 优秀 |
|------|------|------|------|------|
| 横截面 IC 均值 | 月频 | 0.02 以上 | 0.04 以上 | 0.06 以上 |
| ICIR | 月频 | 0.3 以上 | 0.5 以上 | 1.0 以上 |
| ICIR | 日频 | 0.13 以上 | 0.20 以上 | 0.30 以上 |
| IC 大于零的比例 | 不分频率 | 0.55 以上 | 0.60 以上 | 0.65 以上 |
| 分层单调性（秩相关） | 不分频率 | 0.6 以上 | 0.8 以上 | 0.9 以上 |

日频那一行的数字是按 $t=2$ 反推的：$0.13 \times \sqrt{252} \approx 2.06$。这不是行业惯例，而是显著性要求在这个样本长度下的直接结果。表中给月频 0.3 是有历史原因的，早期因子研究多用月频数据，36 个月样本下 0.3 刚好接近显著；把这个数字搬到日频上，就会把一大批本已显著的因子判成不可用。

需要特别注意：**单看 IC 均值会误判。** 假设特征甲 IC 均值为 0.05、标准差为 0.20，特征乙 IC 均值为 0.03、标准差为 0.06。甲的 IC 均值更高，但 ICIR 是 0.25 与 0.50，乙的方向稳定性明显更强。在组合里，乙通常更受青睐，因为它不会在特定时期反向。

### 择时能力

择时检验的对象是单个标的的时间序列。这里给出四种方法，从轻到重。

**方法一，时序 IC。** 直接计算特征值与自身未来收益的秩相关：

$$IC^{TS}_i = \rho_s\left(f_{i,t},\ r_{i,t \to t+h}\right)$$

这是最简单的方法，但它有一个缺陷：单个标的的样本量有限，且时间序列存在自相关，显著性检验容易失效。因此它只能作为参考，不能作为结论。

**方法二，信号触发日的收益检验。** 把特征转化为二值信号。例如特征值超过上分位阈值时记为触发，低于下分位阈值时记为未触发。把交易日分为两个集合，用 Welch 检验比较两组的未来收益均值：

$$t = \frac{\bar{r}_A - \bar{r}_B}{\sqrt{\dfrac{s_A^2}{n_A} + \dfrac{s_B^2}{n_B}}}$$

其中 A 为触发集合，B 为非触发集合。这个检验直接回答一个实务问题：信号出现的那几天，后面的收益是否真的不一样。

**方法三，条件分位收益。** 把特征的时序值分为 Q 档，计算每档的条件平均未来收益：

$$E\left[r_{t \to t+h} \mid f_t \in Q_k\right]$$

看最高档与最低档的差值，以及各档是否单调。这个方法比信号检验更精细，能看出特征与收益的关系形状：是线性的，还是只在极端处有效。

**方法四，择时策略回测。** 把特征转化为仓位规则，比如特征值高于中位数时满仓、否则空仓，然后回测：

$$\text{年化收益} = \left(\prod_{t=1}^{T}(1 + w_t \cdot r_t)\right)^{252/T} - 1$$

其中 $w_t$ 是仓位。评判的依据不是收益绝对值，而是**相对于买入持有的改进**：夏普是否提升，最大回撤是否下降，胜率与盈亏比如何。

**判读标准。** 择时能力没有统一的阈值，因为市场状态差异很大。可行的判读方式是横向比较：在同样的数据和规则下，比较不同特征的择时表现，选出相对更好的。同时要看**信号频次**，信号过于频繁（一年几十次）时交易成本会吃掉大部分收益。

### 组合信号的检验

第四步检验组合。技术指标的组合方式有两类，检验方法也不同。

**加权型组合。** 把多个特征标准化后加权相加，得到一个综合分数：

$$g_{i,t} = \sum_{k=1}^{K} w_k \cdot z\left(f^{(k)}_{i,t}\right)$$

然后把这个 $g$ 当作一个新的特征，重新走一遍截面检验。权重的确定方式有三种：等权（最简单的基准）、按历史 IC 均值加权、按 ICIR 加权。

**条件型组合。** 只在多个特征同时满足条件时才触发信号，逻辑是"双重确认"。例如只有趋势向上且量价配合时才买入。这类组合无法用加权表示，检验方式是把组合后的触发条件作为一个二值信号，走择时检验的流程。

**为什么要检验组合。** 一个常见的误解是：两个各自有效的特征组合起来一定更强。实际情况是，如果两个特征高度相关，组合不会带来增益；如果两个特征的方向在特定时期相反，组合的表现可能比单个更差。组合增益来自**信息的互补性**，这需要检验才能确认。

检验组合增益的具体做法是比较三组结果：特征甲单独、特征乙单独、两者组合。如果组合的 ICIR 高于两者，且相关性较低，说明互补性存在；如果组合的 ICIR 介于两者之间，说明只是平均，没有增益。

### 数据从哪来

后面的所有代码都读本地文件，不从网络抓数据。数据在 `data/parquet/` 下，由 `scripts/export_from_db.R` 从本地 MySQL 库导出，`scripts/csv_to_parquet.py` 转成 parquet 并派生研究面板。完整说明见 `data/README.md`。

两个文件覆盖两种用途。`panel_blue_chip.parquet` 是正文示例用的 5 只蓝筹，2905 行，区间 2023-01 至 2025-06。`panel.parquet` 是真实横截面用的 287 只，30 万行，区间 2021-06 至 2025-12。Python 读 parquet，R 读同名的 `.csv`，后者是为了让 R 不必安装 arrow。

字段除了 `date`、`code`、`open`、`high`、`low`、`close`、`volume`，还有几列是为检验准备的：`adjusted` 用于算收益，`forward_1`、`forward_5`、`forward_20` 是前向收益，`fwd_vol_20` 是未来 20 日已实现波动率，`limit_up`、`limit_down`、`suspended`、`tradable` 标记可交易性，`industry` 是申万一级行业。

有几处数据处理需要知道，否则算出来的结果会和别人不一致。**送转除权已自动修补**：库里原始的复权字段做了现金分红复权，没做送股转增复权，会导致除权日出现负 30% 这类不可能的收益。全样本 10 处，修补方式是按开盘价比例重建复权因子，原始价格保留在 `*_raw` 列。**涨跌停按板块分别判定**，主板 9.8%、创业板与科创板 19.8%，留 0.2 个百分点余量以容纳四舍五入。**行业分类是 2026-09-30 的单一时点快照**，用它做行业中性化会带上幸存者偏差。

import numpy as np
import pandas as pd
from scipy import stats


def cross_section_ic(panel, factor_col, ret_col, date_col="date"):
    """计算横截面 IC 序列。panel 需含 date / code / factor_col / ret_col。"""
    def _ic(g):
        sub = g.dropna(subset=[factor_col, ret_col])
        if len(sub) < 5:
            return np.nan
        rho, _ = stats.spearmanr(sub[factor_col], sub[ret_col])
        return rho
    ic = panel.groupby(date_col).apply(_ic)
    return ic.dropna()


def ic_summary(ic):
    """汇总 IC 序列的统计量。"""
    mean_ic = ic.mean()
    std_ic = ic.std()
    icir = mean_ic / std_ic if std_ic > 0 else np.nan
    t_stat = icir * np.sqrt(len(ic))
    win_rate = (ic > 0).mean()
    return pd.Series({
        "IC均值": round(mean_ic, 4),
        "IC标准差": round(std_ic, 4),
        "ICIR": round(icir, 3),
        "t统计量": round(t_stat, 2),
        "IC大于零比例": round(win_rate, 3),
        "样本期数": len(ic),
    })


def layered_returns(panel, factor_col, ret_col, q=5, date_col="date"):
    """分层回测，返回各组的平均收益与单调性。"""
    def _assign(g):
        g = g.dropna(subset=[factor_col, ret_col]).copy()
        if len(g) < q:
            return None
        g["group"] = pd.qcut(g[factor_col].rank(method="first"), q, labels=False) + 1
        return g
    tmp = panel.groupby(date_col, group_keys=False).apply(_assign).dropna(subset=["group"])
    grp_ret = tmp.groupby(["date", "group"])[ret_col].mean().unstack()
    group_mean = grp_ret.mean()
    mono, _ = stats.spearmanr(group_mean.index.values, group_mean.values)
    return group_mean, round(mono, 3)


def timing_signal_test(df, factor_col, ret_col, upper=0.8, lower=0.2):
    """择时检验：极端分位触发日与非触发日的收益差异（Welch t 检验）。"""
    f = df[factor_col].dropna()
    hi = f.quantile(upper)
    lo = f.quantile(lower)
    trig = df.loc[f.index, ret_col][f >= hi].dropna()
    rest = df.loc[f.index, ret_col][f < hi].dropna()
    t_stat, p_val = stats.ttest_ind(trig, rest, equal_var=False)
    return pd.Series({
        "触发日数": len(trig),
        "触发日平均收益": round(trig.mean() * 100, 3),
        "非触发日平均收益": round(rest.mean() * 100, 3),
        "差异t统计量": round(t_stat, 2),
        "p值": round(p_val, 4),
    })


def conditional_quantile_return(df, factor_col, ret_col, q=5):
    """择时检验：特征时序分档后的条件平均收益。"""
    tmp = df[[factor_col, ret_col]].dropna().copy()
    tmp["bucket"] = pd.qcut(tmp[factor_col].rank(method="first"), q, labels=False) + 1
    return tmp.groupby("bucket")[ret_col].agg(["mean", "count"]).round(4)


def timing_backtest(df, factor_col, ret_col, entry_q=0.7):
    """择时策略：特征值高于分位阈值时持仓，否则空仓，并与买入持有对比。"""
    tmp = df[[factor_col, ret_col]].dropna().copy()
    thr = tmp[factor_col].quantile(entry_q)
    tmp["pos"] = (tmp[factor_col] > thr).astype(int)
    tmp["strat"] = tmp["pos"].shift(1).fillna(0) * tmp[ret_col]
    def _stats(r):
        ann = (1 + r).prod() ** (252 / len(r)) - 1
        sharpe = r.mean() / r.std() * np.sqrt(252) if r.std() > 0 else np.nan
        cum = (1 + r).cumprod()
        mdd = ((cum / cum.cummax()) - 1).min()
        return round(ann, 4), round(sharpe, 2), round(mdd, 4)
    s_ann, s_sh, s_mdd = _stats(tmp["strat"])
    b_ann, b_sh, b_mdd = _stats(tmp[ret_col])
    return pd.DataFrame({
        "策略": [s_ann, s_sh, s_mdd],
        "买入持有": [b_ann, b_sh, b_mdd],
    }, index=["年化收益", "夏普", "最大回撤"])


def combined_signal(panel, factor_cols, weights=None, date_col="date"):
    """加权型组合：横截面标准化后加权求和。"""
    df = panel.copy()

    def _z(s):
        # 绝对中位差用显式计算：pandas 2.0 起已移除 Series.mad()
        m = (s - s.median()).abs().median()
        return (s - s.median()) / m if m and m > 0 else 0.0

    z_cols = []
    for c in factor_cols:
        zc = c + "_z"
        df[zc] = df.groupby(date_col)[c].transform(_z)
        z_cols.append(zc)
    w = np.ones(len(z_cols)) / len(z_cols) if weights is None else np.array(weights)
    df["combined"] = (df[z_cols] * w).sum(axis=1)
    return df

cross_section_ic <- function(panel, factor_col, ret_col) {
  ic <- panel |>
    group_by(date) |>
    filter(!is.na(.data[[factor_col]]), !is.na(.data[[ret_col]])) |>
    summarise(
      ic = if (n() >= 5) cor(.data[[factor_col]], .data[[ret_col]],
                             method = "spearman") else NA_real_,
      .groups = "drop"
    ) |>
    filter(!is.na(ic))

  names(out) <- as.character(ic$date)
  out
}

# IC 汇总
ic_summary <- function(ic) {
  ic <- as.numeric(ic)
  m <- mean(ic); s <- sd(ic)
  data.frame(
    IC均值 = round(m, 4),
    IC标准差 = round(s, 4),
    ICIR = round(m / s, 3),
    t统计量 = round(m / s * sqrt(length(ic)), 2),
    IC大于零比例 = round(mean(ic > 0), 3),
    样本期数 = length(ic)
  )
}

# 分层回测
layered_returns <- function(panel, factor_col, ret_col, q = 5) {
  res <- panel |>
    group_by(date) |>
    filter(!is.na(.data[[factor_col]]), !is.na(.data[[ret_col]])) |>
    mutate(group = ntile(.data[[factor_col]], q)) |>
    group_by(date, group) |>
    summarise(r = mean(.data[[ret_col]]), .groups = "drop") |>
    tidyr::pivot_wider(names_from = group, values_from = r)
  mat <- as.data.frame(res)[, -1, drop = FALSE]
  group_mean <- colMeans(mat, na.rm = TRUE)
  list(组均收益 = round(group_mean, 6),
       单调性 = round(cor(as.numeric(names(group_mean)), group_mean,
                        method = "spearman"), 3))
}

# 择时：信号触发日检验
timing_signal_test <- function(df, factor_col, ret_col, upper = 0.8) {
  f <- df[[factor_col]]
  r <- df[[ret_col]]
  ok <- !is.na(f) & !is.na(r)
  f <- f[ok]; r <- r[ok]
  thr <- quantile(f, upper, na.rm = TRUE)
  trig <- r[f >= thr]
  rest <- r[f <  thr]
  # 两组样本都足够时才做检验，否则返回 NA 以免中断
  if (length(trig) < 3 || length(rest) < 3) {
    return(data.frame(触发日数 = length(trig),
                      触发日平均收益 = NA_real_,
                      非触发日平均收益 = round(mean(rest) * 100, 3),
                      t统计量 = NA_real_, p值 = NA_real_))
  }
  tt <- t.test(trig, rest)
  data.frame(触发日数 = length(trig),
             触发日平均收益 = round(mean(trig) * 100, 3),
             非触发日平均收益 = round(mean(rest) * 100, 3),
             t统计量 = round(unname(tt$statistic), 2),
             p值 = round(tt$p.value, 4))
}

# 择时：条件分位收益
conditional_quantile_return <- function(df, factor_col, ret_col, q = 5) {
  df |>
    filter(!is.na(.data[[factor_col]]), !is.na(.data[[ret_col]])) |>
    mutate(bucket = ntile(.data[[factor_col]], q)) |>
    group_by(bucket) |>
    summarise(mean = round(mean(.data[[ret_col]]), 4),
              count = n(),
              .groups = "drop")
}

# 择时策略回测
timing_backtest <- function(df, factor_col, ret_col, entry_q = 0.7) {
  f <- df[[factor_col]]
  r <- df[[ret_col]]
  ok <- !is.na(f) & !is.na(r)
  f <- f[ok]; r <- r[ok]
  thr <- quantile(f, entry_q)
  # 信号在当日收盘产生，次日持仓，因此仓位滞后一期
  pos <- dplyr::lag(ifelse(f > thr, 1, 0), 1)
  stat <- function(x) {
    x <- x[!is.na(x)]
    if (length(x) < 2 || sd(x) == 0) {
      return(c(年化收益 = NA_real_, 夏普 = NA_real_, 最大回撤 = NA_real_))
    }
    cum <- cumprod(1 + x)
    c(年化收益 = round(prod(1 + x)^(252 / length(x)) - 1, 4),
      夏普 = round(mean(x) / sd(x) * sqrt(252), 2),
      最大回撤 = round(min(cum / cummax(cum) - 1), 4))
  }
  data.frame(策略 = stat(pos * r),
             买入持有 = stat(r))
}

# 加权型组合：先横截面标准化，再等权或指定权重相加
combined_signal <- function(panel, factor_cols, weights = NULL) {
  z_cols <- paste0(factor_cols, "_z")
  out <- panel |>
    group_by(date) |>
    mutate(across(all_of(factor_cols), function(x) {
      # constant = 1 取裸中位绝对差，与 Python 侧保持一致
      # （R 的 mad() 默认 constant = 1.4826，会放大 1.4826 倍）
      m <- mad(x, na.rm = TRUE, constant = 1)
      if (isTRUE(m > 0)) (x - median(x, na.rm = TRUE)) / m else 0
    }, .names = "{.col}_z")) |>
    ungroup()
  w <- if (is.null(weights)) rep(1 / length(z_cols), length(z_cols)) else weights
  stopifnot(length(w) == length(z_cols))
  out$combined <- as.matrix(out[, z_cols]) %*% w
  out
}

## 这套方法面对的证据格局

方法本身不产生结论，结论来自把它用在真实数据上。技术分析被这样检验了半个多世纪，结果既不是"有效"，也不是"无效"，而是一条随方法改进而移动的曲线。

最早的一批检验给出过正结果。Brock、Lakonishok 与 LeBaron（1992）在道琼斯工业平均指数 1897 至 1986 年的日线上检验了 26 条简单规则，包括均线穿越与交易区间突破，发现这些规则在统计上带有预测力。这个结论让"技术分析可以被严肃检验"这件事站住了脚，也成了后来所有讨论的起点。

问题出在规则的数量上。Sullivan、Timmermann 与 White（1999）把同一思路扩展到近八千条规则，再用 White 的 Reality Check 自助法校正"试了很多次才挑出最好那条"带来的偏差。校正之后，最优规则的表现大幅缩水。这个现象叫数据窥探偏差（data snooping bias）：在足够大的规则空间里，总能找到一条在历史上看起来很不错的规则，而它的好只是筛选的结果。

更晚的综述把尺度拉到全部研究上。Park 与 Irwin（2007）整理了 95 项现代研究，约一半得到正结果，四分之一为负，其余混合；扣除交易成本并做风险调整之后，正结果普遍减弱。这个分布本身就是结论。它既不支持"技术分析普遍有效"，也不支持"技术分析已被证伪"。它支持的是一个更窄的判断：某些规则在某些市场、某些样本段内存在可测的预测力，而这份预测力对成本、样本区间与规则定义高度敏感。

单看某个指标时，证据还要再薄一层。规则族层面的检验无法把绩效归因到单个指标，因为一条均线规则同时包含周期、穿越定义、止损方式与仓位规则，四项中任何一项改变都会改变结果。这也是本书在每个指标章单列一节、说明该指标有没有被单独检验过的原因。多数指标没有。布林带是少数例外，Lento、Gradojevic 与 Wright（2007）报告，扣除交易成本后布林带规则不能超越买入持有，而触轨反向的做法结果有所改善。

近十年的变化来自因子与模型两侧。Harvey、Liu 与 Zhu（2016）指出，在因子数量激增之后，传统的 t 值 2.0 门槛已不足以区分真实与偶然，提出以 3.0 作为新的参照。Gu、Kelly 与 Xiu（2020）用同一套机器学习方法比较线性模型、树模型与神经网络，发现后者的预测确实更好，但样本外解释力的量级仍在百分之一以下。两条合起来说明一件事：方法可以进步，信噪比不会因此改变。

因此本书在每一处结论上都保留条件。写"某因子在某个样本段内 IC 为正"，不写"该因子有效"；写"扣成本后不占优"，不写"该指标无用"。这不是措辞上的谨慎，而是证据本身只支持这个强度。读者如果只带走一句话，可以是这一句：技术指标的可检验性，比它是否有效更值得关心。

## 常见陷阱

**用线性相关代替秩相关。** 特征与收益的关系常呈非线性，且金融数据厚尾。线性相关会被极值主导，得出与实际相反的符号。

**忽略 IC 序列的自相关。** IC 序列通常存在正自相关，这会让 t 统计量被高估。样本期数较多时应使用 Newey-West 调整后的标准误。

**用 5 只标的做横截面检验。** 标的数太少时，单只股票的异常收益就能改变整个横截面的排序。这个做法只能用于验证代码是否跑通，不能用于得出结论。

**把择时检验的样本内结果当成能力。** 择时规则的参数（如分位阈值）如果是在同一段数据上选出来的，那这个结果反映的是拟合能力。必须留出独立时间段验证。

**混淆"信号方向"与"因子方向"。** 一个因子的 IC 为负，不代表它无用，只代表它与收益负相关。使用时把排序反过来即可。但要注意这个负号是否稳定，如果符号在样本间反复变化，说明关系不稳定。

**忽略成本对高频信号的影响。** 择时策略每天换仓时，即使单次成本只有万分之几，累积起来也会吃掉大部分收益。计算策略收益时要把成本算进去，而不是最后再扣。
