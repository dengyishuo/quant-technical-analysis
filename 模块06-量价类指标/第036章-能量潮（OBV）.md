# 第036章 能量潮（OBV）

价格连涨五天，成交量却一天比一天小，一个交易者盯着量柱开始犹豫。他想知道这波上涨还有人在接着买，还是只剩惯性在推。单看某一天的量没有用，放量与缩量都要和前面几周比才有意义。他需要一条把每日成交量按涨跌方向累加起来的曲线，看它的斜率有没有跟价格同向。这段上涨背后，资金是在进还是在退。

## 名称与来历

能量潮（On-Balance Volume，OBV），有时也译作能量潮指标。

它由美国分析师约瑟夫·格兰维尔（Joseph Granville）在 1963 年的著作《股市获利新钥匙》（Granville's New Key to Stock Market Profits）中提出 [@granville1963]。格兰维尔想回答的是一个在当时没有得到系统处理的问题：如果每天把成交量按当日的涨跌分类，上涨日计入买方、下跌日计入卖方，再逐日累加，会得到什么？他发现这条累加曲线常常先于价格发出方向改变的信号，于是把它命名为能量潮，取"成交量是价格的燃料"之意。

在格兰维尔之前，成交量分析主要依靠观察量柱的高低和形态，缺少一个可累积、可比较的序列。OBV 提供的就是这样一个序列。它把离散的每日成交量汇总成一条有走势的曲线，让"资金是净流入还是净流出"第一次有了连续的度量。

OBV 的影响超出了它本身的用法。它确立了一种思路：成交量不是价格的附属信息，而是可以独立构造序列的一手数据。此后出现的柴金震荡器、资金流量指标，都在不同程度上沿用了这个思路，区别只在于如何给成交量分类。从这个角度看，OBV 是量价类指标的方法起点。

## 核心逻辑

OBV 最初的问题很具体：成交量本身是一个正数，看不出买卖哪一方更主动。放量上涨可能是资金主动买入，也可能是主力借成交活跃出货。把成交量单独看，无法区分这两种情形。

格兰维尔的思路是引入一个假设：当日收涨，说明当日的成交量总体上由买方完成；当日收跌，说明由卖方完成。这个假设把成交量从一个正数变成了一个带符号的量，再累加，就得到一条记录净买卖压力的曲线。曲线向上，说明一段时间内上涨日的成交规模系统性大于下跌日；曲线向下，说明相反。

这个"全有或全无"的归类显然是一种简化。一个交易日内买卖是同时发生的，成交的每一手都对应一个买方和一个卖方，不可能只有买方或只有卖方。但在统计意义上，如果大资金在上涨日集中建仓、在下跌日集中派发，那么上涨日的成交量就会系统性地偏高，累加曲线就会持续走高。OBV 捕捉的是这种系统性偏差，而不是某一日的真实买卖对比。

由于是累加量，OBV 天然带有趋势性。持续放量上涨会形成上升的 OBV，持续放量下跌则形成下降的 OBV。单日巨量会在曲线上留下一次跳变，但不会改变长期走向。这一点决定了 OBV 的用法：看的是曲线的方向和斜率，而不是数值本身。

从这个构造也能看出 OBV 的边界。它只使用收盘价的涨跌方向，不使用涨跌幅的大小。上涨 9% 和上涨 0.1% 在 OBV 里的处理完全相同，只要收涨就加上全部成交量。这个简化让 OBV 对小幅波动和大幅波动一视同仁，好处是稳健，坏处是丢失了涨跌强度的信息。需要强度区分时，就要改用带权重的构造，也就是下面会提到的资金流量类指标。

## 计算公式

OBV 采用递推形式，每一步只需要前一日数值和当日成交量：

$$OBV_t = \begin{cases}
OBV_{t-1} + v_t, & \text{若 } c_t > c_{t-1} \\[6pt]
OBV_{t-1} - v_t, & \text{若 } c_t < c_{t-1} \\[6pt]
OBV_{t-1},        & \text{若 } c_t = c_{t-1}
\end{cases}$$

其中 $c_t$ 为第 t 日收盘价，$v_t$ 为第 t 日成交量。初始值 $OBV_0$ 可以任意设定，通常取 0 或首日成交量。

**计算示例。** 假设连续四个交易日的收盘价与成交量如下：

| 交易日 | 收盘价 | 成交量 | 与前一日的比较 | OBV |
|--------|--------|--------|--------------|-----|
| 1 | 10.0 | 100 万 | 起始 | 100 万 |
| 2 | 10.5 | 120 万 | 收涨 | 220 万 |
| 3 | 10.2 | 90 万 | 收跌 | 130 万 |
| 4 | 10.2 | 80 万 | 平盘 | 130 万 |

第二天收涨，把 120 万加到 100 万上得到 220 万；第三天收跌，减去 90 万得到 130 万；第四天平盘，数值不变。四天下来 OBV 从 100 万升到 130 万，说明这段时间净买入的成交规模为正，尽管第三、四天的价格在回落。

**参数含义。** OBV 本身没有可调参数，它的"参数"来自后续处理：

| 处理方式 | 参数 | 作用 |
|---------|------|------|
| 平滑 | 均线周期 n | 对 OBV 施加减权均线，过滤单日巨量的跳变 |
| 变化率 | 观察窗口 k | 计算 k 日内的 OBV 变化率，用于横截面比较 |
| 交叉 | 短周期与长周期 | 用 OBV 的两条均线交叉判断曲线方向的转向 |

未经处理的 OBV 曲线每日随涨跌交替而频繁波动，直接观察容易产生误导。实务中通常至少叠加一条 20 日或 30 日的均线，让资金流向的大方向清晰呈现。

## 用法与信号

**趋势确认。** 价格与 OBV 同向运行时，是对现有趋势的确认。价格创新高且 OBV 同步创新高，说明上涨有资金持续流入支撑；价格创新低且 OBV 同步创新低，说明下跌由持续的资金流出推动。同步性越强、持续越久，趋势的可靠性相对越高。

**背离。** 这是 OBV 最受关注的信号，也是"量在价先"最直观的体现。顶背离发生在价格走高而 OBV 的高点逐步下移时，说明上涨的推动力在减弱，价格在涨但资金并未同步跟进。底背离发生在价格走低而 OBV 的低点逐步抬高时，说明卖压在衰减，低位有资金承接。背离的有效性依赖对比跨度，日线级别上跨越两三个月的背离，比一两周的短周期背离更值得关注。

**领先突破。** 格兰维尔发现 OBV 的突破有时早于价格的突破。价格仍在箱体或三角形内整理时，OBV 已经突破对应区域的水平阻力，这种"量先于价"的现象通常被解读为大资金提前建仓。同样的观察适用于向下的情形：价格看似守在支撑上方，OBV 却率先跌破对应水平。

**与均线的交叉。** 对 OBV 自身施加两条不同周期的均线，用交叉判断资金流向的拐点。OBV 的短均线上穿长均线，说明净流入的动能转强；下穿则转弱。这种用法的好处是把随机波动的 OBV 曲线转成明确的离散信号，代价是引入了均线固有的滞后。

把四种形态放在一起，可以看出它们的性质差异：

| 信号形态 | 触发条件 | 含义 | 可靠性倾向 |
|---------|---------|------|-----------|
| 趋势确认 | 价格与 OBV 同向创新高或新低 | 现有趋势有资金支撑 | 较高，但滞后 |
| 背离 | 价格与 OBV 高点或低点方向相反 | 推动力衰减或积累 | 中等，需价格确认 |
| 领先突破 | OBV 先于价格突破整理区间 | 大资金提前动作 | 偏低，多为提示 |
| 均线交叉 | OBV 短均线与长均线交叉 | 资金动能方向切换 | 中等，滞后较小 |

### 与其他指标的组合

OBV 是量价类中逻辑最直接的一个，它与其他指标的组合用法也相对固定。

**与动能指标同看，验证背离。** 当 OBV 出现顶背离时，如果动能指标（比如指数平滑异同平均线）同时出现顶背离，两个独立构造的指标指向同一结论，背离的可信度相对提升。两者都源自价格与成交量的不同侧面，同时背离比单独背离更值得重视。

**与均线同看，做双向确认。** 价格站上中期均线，同时 OBV 站上自身的均线，构成价格与资金的双重确认；两个条件同时被打破时，信号的可靠性也在两个维度上下降。这种用法把 OBV 从独立信号变成确认信号，降低了假信号的干扰。

**与震荡指标同看，过滤超买超卖。** 震荡指标进入超买区域时，用它本身无法判断回落还是继续上行，此时观察 OBV 的方向。OBV 同步走高，超买可能维持；OBV 走平或下行，回落的概率上升。这个组合把"价格偏离了多少"和"资金还在不在"合并成一次判断。

**与波动率指标同看，判断风险。** 波动率指标给出当前波动水平，OBV 给出资金方向，两者结合可以粗略判断当前的波动是趋势性的还是无序的：波动上升且 OBV 持续走高，多半是趋势行情；波动上升而 OBV 来回摆动，多半是震荡加剧。

需要注意的是，组合用法增加了判断的维度，也增加了主观性。每个指标都要设定自己的触发条件，条件越多，规则越复杂，回测中可调整的自由度也越大，过拟合的风险随之上升。组合的数量以一两个为宜，且每个条件都应有明确的数值定义。

## 边界与误区

**对单日巨量无条件接纳。** OBV 把当日成交量整体计入，无论这笔成交是主动换手还是被动撮合。财报发布日、解禁日出现的天量，会在曲线上留下突兀的跳变，干扰对资金方向的判断。缓解方式是先对 OBV 做平滑，但平滑同时也钝化了真实的转折信号，需要在降噪和灵敏之间权衡。

**背离不等于反转。** 底背离可能持续数周甚至数月，价格在低位反复磨底。把背离当作入场信号而不是预警信号，容易在漫长的筑底过程中消耗耐心。更稳妥的做法是等价格突破关键阻力位确认后再行动。

**在低流动性品种上失真。** OBV 依赖成交量反映真实交易。成交清淡的小市值个股存在对倒制造虚假成交量的可能，这类品种的 OBV 信号可靠性有限。OBV 更适合流动性好的品种，比如大盘股、ETF 和主要指数。

**跨品种比较绝对数值。** OBV 是累积量，上市时间越长、累计成交量越大，数值就越大，量纲随历史长度变化。两只股票的 OBV 曲线放在一起比较高低没有意义，能比较的只有各自的走势形态。这一点在把 OBV 用作横截面因子时尤其重要，处理方法见下节。

**成交量口径不一致会使读数失真。** 累加型指标对成交量的口径最敏感。不同数据源可能对大宗交易、盘后固定价格交易是否计入成交量给出不同处理，同一只股票在两个数据源上的 OBV 曲线会缓慢分叉。做时序研究时问题不大，做跨市场或跨数据源的比较时，需要先确认口径一致。

## 它被检验过吗

OBV 没有针对它本身的独立同行评议检验。常被引来支持它的是 Karpoff（1987）在 *JFQA* 上的综述：成交量与价格正相关，且存在不对称，放量更多伴随上涨。

这条结论属于价格与成交量之间的关系层面，不是对 OBV 的绩效检验。OBV 在关系之上还加了累积与符号两个假设，这两步都没有被单独检验；把关系层面的规律当作指标层面的验证，是量价类章节最容易出现的误读。完整证据链见第 007 章。

这一类的真实失效案例，见第 035 章的「真实案例与失败模式」。

```python
import numpy as np
import pandas as pd

# 本地数据，由 xquant-db 导出，字段见 data/README.md
_panel = pd.read_parquet("data/parquet/panel_blue_chip.parquet")
import matplotlib
matplotlib.rcParams["font.sans-serif"] = ["PingFang SC", "SimHei", "Arial Unicode MS"]
matplotlib.rcParams["axes.unicode_minus"] = False
import matplotlib.pyplot as plt

# 1. 获取数据
_panel = pd.read_parquet("data/parquet/panel_blue_chip.parquet")
data = (_panel[_panel["code"] == "600519.SS"]
        .set_index("date").sort_index()[["open", "high", "low", "close", "volume"]])
data.columns = ["Open", "High", "Low", "Close", "Volume"]
close = data["Close"].squeeze()
volume = data["Volume"].squeeze()

# 2. 计算 OBV：按涨跌符号给成交量定号后累加
direction = np.sign(close.diff()).fillna(0)
df = pd.DataFrame({"close": close, "obv": (direction * volume).cumsum()})

# 3. 计算 OBV 的 30 日均线
df["obv_ma30"] = df["obv"].rolling(30).mean()

# 4. 识别信号：OBV 上穿均线
df["above"] = (df["obv"] > df["obv_ma30"]).astype(int)
df["cross_up"] = (df["above"] == 1) & (df["above"].shift(1) == 0)
print(f"OBV 上穿均线次数：{df['cross_up'].sum()}")

# 5. 绘图
fig, axes = plt.subplots(2, 1, figsize=(12, 7), sharex=True)
axes[0].plot(df.index, df["close"], color="#333", linewidth=1)
axes[0].set_title("贵州茅台 收盘价与 OBV")
axes[1].plot(df.index, df["obv"], label="OBV", color="#2f6fb5")
axes[1].plot(df.index, df["obv_ma30"], label="OBV 30 日均线", color="#c0392b")
axes[1].legend()
plt.tight_layout()
plt.show()

# 6. 输出统计
price_up = close.diff() > 0
obv_up = df["obv"].diff() > 0
print("价格与 OBV 同向比例：", round((price_up == obv_up).mean(), 3))
```

## 拆解

OBV 的输出是累积成交量，单位是手。它的绝对水平随上市时间单调增长：上市五年的标的与上市一年的标的放在一起，数值差距主要来自累积长度，而不是当期资金的强弱。按 OBV 大小排序，排在前面的往往是老股票，排序结果与资金流向的关系很弱。

> **累积量陷阱。** OBV 的绝对数值由起点设定与历史长度共同决定。两个数据源取不同起点，读数可以相差一个量级；同一只标的不换起点，读数也会逐年抬高。把 OBV 原始值直接放进横截面，排序退化为上市时间的排序，得到的 IC 只是在度量规模。

因此进入检验之前，先把它拆成若干无量纲或有序的特征。

| 特征名 | 计算式 | 量纲 | 经济含义 |
|--------|--------|------|----------|
| OBV 绝对水平 | $OBV_t$ | 手（累积） | 上市以来净买入成交规模，随历史长度增长，跨标不可比 |
| OBV 变化率 | $(OBV_t-OBV_{t-k})/\lvert OBV_{t-k}\rvert$ | 无量纲比例 | $k$ 日内净流向的相对变化，是本章的主因子 |
| 相对均线偏离 | $OBV_t/\overline{OBV}_t^{(n)}-1$ | 无量纲比例 | 净流向相对自身近期水平的位置 |
| 量价背离标记 | $\mathbf{1}\{p_t=\max_{k}p,\ OBV_t<\max_{k}OBV\}$ | 取值为 0 或 1 | 价格新高而资金未跟上，事件型信号 |

四个特征处在不同层级。变化率刻画流量，偏离度刻画位置，背离标记刻画事件，绝对水平只作中间量。变化率可以连续排序，背离标记稀疏，更适合作为条件变量。

变化率是本章的主构造，它的分母值得单独讨论。当 $OBV_{t-k}$ 接近零时，分子即使很小，比值也会被放大到失去经济含义的量级。OBV 曲线在起点设为零、窗口内净流入与净流出大致抵消时，恰好会经过零点。这类读数并不代表资金流向发生了剧烈变化，只是除法在分母上出了问题。处理方式有两种：给分母加一个与成交量同量级的下限，或者在横截面上去极值。前者改变的是构造，后者改变的是分布，两者都应在检验报告中写明。分母取绝对值的作用是让变化率的符号与增量保持一致；若分母保留符号，净流出窗口里的正增量会被读成负值，方向整个反过来。

偏离度有类似的问题，只是位置不同。OBV 的滚动均值穿过零轴时，偏离度的分母接近零，读数同样会出现尖峰。它的符号含义还会随 OBV 的水平漂移：OBV 长期为正时，正的偏离意味着资金加速流入；OBV 长期为负时，正的偏离只意味着流出放缓。同样是正值，含义并不相同。这也是变化率比偏离度更常用的原因。

背离标记是二值变量，构造时要先定下"新高"的窗口。窗口短，标记密集但多为噪音；窗口长，标记稀疏，单只标的几年内只出现数次。稀疏变量的横截面排序意义有限，因为同一天里触发标记的标的可能只有一两只。它更适合放在时序里做事件统计，或者在截面上作为分组条件，与连续特征配合使用。

```r
    # 累积量本身只作记录，不进入横截面排序
    obv_level = obv,
    # k 日变化率：分母取绝对值，并设下限防止接近零时放大
    obv_lag = dplyr::lag(obv, 10),
    obv_chg = (obv - obv_lag) / pmax(abs(obv_lag), 1e-8),
    # 相对自身 20 日均线的偏离
    obv_ma20 = zoo::rollmean(obv, 20, fill = NA, align = "right"),
    obv_dev = obv / obv_ma20 - 1,
    # 量价背离：20 日价格新高但 OBV 未创新高
    px_hi = as.integer(close >= zoo::rollmax(close, 20, fill = NA, align = "right")),
    obv_hi = as.integer(obv >= zoo::rollmax(obv, 20, fill = NA, align = "right")),
    diverge = as.integer(px_hi == 1 & obv_hi == 0)
  ) |>
  ungroup()
```

### Python

```python
# 沿用第 007 章定义的 cross_section_ic / ic_summary / layered_returns
import numpy as np
import pandas as pd

# panel 已含 date / code / close / volume / forward_1 / forward_5
panel = panel.sort_values(["code", "date"]).reset_index(drop=True)
grp = panel.groupby("code")

# OBV：按涨跌符号给成交量定号后累加
direction = np.sign(grp["close"].diff()).fillna(0)
panel["obv"] = (direction * panel["volume"]).groupby(panel["code"]).cumsum()
panel["obv_level"] = panel["obv"]

# k 日变化率：分母取绝对值，并设下限防止接近零时放大
obv_lag = grp["obv"].shift(10)
panel["obv_chg"] = (panel["obv"] - obv_lag) / obv_lag.abs().clip(lower=1e-8)

# 相对自身 20 日均线的偏离
panel["obv_ma20"] = grp["obv"].transform(lambda s: s.rolling(20).mean())
panel["obv_dev"] = panel["obv"] / panel["obv_ma20"] - 1

# 量价背离：20 日价格新高但 OBV 未创新高（前 20 日为预热期，记 0）
px_hi = panel["close"] >= grp["close"].transform(lambda s: s.rolling(20).max())
obv_hi = panel["obv"] >= grp["obv"].transform(lambda s: s.rolling(20).max())
panel["diverge"] = (px_hi & ~obv_hi).astype(int)
```

绝对水平在百万到千万手之间，变化率与偏离度落在个位数以内，背离标记只有两个取值。四者不能放进同一个权重体系。

## 截面选股能力

OBV 的横截面因子以变化率为主：

$$f^{chg}_t=\frac{OBV_t-OBV_{t-k}}{\lvert OBV_{t-k}\rvert}$$

另一个候选是滚动标准化后的 OBV：

$$f^{z}_t=\frac{OBV_t-\overline{OBV}_{t-n}}{\hat\sigma_{OBV,t-n}}$$

前者度量一段时间内净流向的变化速度，后者度量当前净流向相对自身近期水平的位置。区别在于对累积水平的处理：变化率把水平整体消掉，只留增量；滚动标准化保留水平，用自身的历史波动做归一。若标的的 OBV 长期单边上升，标准化读数会长期停留在高位，排序里混进了"这只股票一直在涨"的信息。两者可以分别检验，比较 ICIR，也可以同时纳入看增量。

预期表现上，变化率因子属于量价动量型，方向通常偏正。资金净流入加速的标的，后续收益倾向于更高，因为净流入同时包含了信息扩散与交易冲击两重效应。它的强度依赖市场环境。增量资金入场、板块轮动有序的阶段，资金流向的横截面差异更清楚；存量博弈、快速轮动的阶段，资金在板块之间来回搬移，十日窗口的变化率容易反复变号，IC 序列的标准差上升，ICIR 随之下降。因此按市场状态分段报告，比只看全样本均值更有信息量。

还有一层结构性的差异。OBV 变化率对上涨日与下跌日的处理并不对称，两者在窗口内可能部分抵消。涨跌交替频繁的标的，分子趋近于零，读数被压在中间；单边上涨的标的，分子接近窗口成交量总和，读数被推到尾部。这种压缩与扩张含有信息，但也意味着因子分布随市况改变，分层边界会漂移。

检验时有三点值得特别注意。

第一，分母的处理要在全样本内统一。给分母加下限与按横截面缩尾是两种不同的干预，前者压低了极端读数，后者只截断分布尾部。两种做法得到的 IC 不能直接比较，报告时应说明用的是哪一种，并且不要在样本中途更换。

第二，变化率与成交量水平存在天然关联。一段窗口内成交量整体放大，OBV 的增量也随之放大，因子值系统性偏高。若标的池里同时有小盘股与大盘股，因子可能部分在排序流动性而非资金流向。稳健的做法是检查因子与对数成交量的横截面相关，必要时对成交量取残差后再算一次 IC。

第三，成交量口径要在比较前确认。OBV 是累加型指标，口径差异会沿着时间累积。不同数据源对大宗交易、盘后固定价格交易是否计入成交量处理不同，同一只标的在两个源上的 OBV 曲线会缓慢分叉。跨数据源做横截面时，先确认口径一致。

## 择时能力

时序上 OBV 的择时逻辑分三层。第一层是 OBV 与自身均线的交叉，短均线上穿长均线视为净流入动能转强。第二层是变化率的符号与幅度，连续为正说明资金持续进场，由正转负说明动能切换。第三层是量价背离，价格创新高而 OBV 未创新高，提示推动力衰减。

方法与信号形态要匹配。交叉是离散事件，一年出现十来次，适合用触发日检验，比较交叉日与其余交易日的后续收益。变化率是连续变量，适合条件分位收益，观察分档后是否单调，再用阈值回测看相对买入持有的改进。背离是稀疏的二值事件，单只标的一年可能只有两三次，两组样本量悬殊，直接做均值检验的效力不足，宜先看频次与两组均值，再把背离写成连续量，例如价格二十日涨幅减去 OBV 二十日变化率，走连续变量的检验流程。

三条路径的分工不同：交叉给出时点，变化率给出强度，背离给出预警。只测事件会漏掉状态的持续性，只测状态又看不出交叉时点是否有效。

陷阱有三处。第一，背离的判定规则要在看数据之前定下。"价格高点"与"OBV 高点"的选取窗口、允许的容差、两个高点之间是否要求间隔，这些细节不同，结论可以完全相反。第二，OBV 的递推依赖起点。不同起点的曲线形状相同而水平不同，交叉信号的位置不受影响，基于绝对水平的分档却会受影响；用滚动分位替代绝对阈值可以规避。第三，信号频率与成本。OBV 与均线的交叉在震荡期相当密集，若每次都调仓，费率与印花税会吃掉大部分名义收益。

## 组合使用与验证

OBV 常见的搭档有三个。与量比搭配，一个给出方向，一个给出参与度，两者同源于成交量但加工方式不同。与价格均线搭配，构成价格与资金的双重确认：均线过滤方向，OBV 过滤资金的真实性。与 CMF 搭配属于同类互证，两者构造目标相同，相关性通常较高，增量空间有限，更多用于交叉验证而非提升 IC。

**组合的截面验证。** 加权型做法是把 OBV 变化率与量比各自做横截面标准化，按等权相加，再走一遍截面检验，比较组合与两个单特征的 ICIR。这里要先看两者的横截面相关：同源于成交量，相关性往往不低，组合更容易落在"介于两者之间"的区间。条件型做法是取交集，只在资金净流入为正且成交量高于均量时选股，再比较触发样本内的收益差异。前者回答排序是否更准，后者回答两个条件同时成立时是否更准。

**组合的择时验证。** 把"OBV 变化率为正且价格站上二十日均线"设为持仓条件，满足时持有，否则空仓，与单条件、买入持有分别对照。加入均线过滤后持仓天数下降，收益可能略减，改进通常体现在回撤与换手上。若三项都没有改善，说明过滤没有提供增量，

增益的判读依据方法论章的标准：**组合的 ICIR 高于两个单特征，才说明存在互补性；介于两者之间，说明只是平均；低于两者，说明信号在某些时段互相抵消。** OBV 与量比同源，落在中间区间的可能性较大；与价格均线的信息维度差异更大，增量空间也更大一些。
