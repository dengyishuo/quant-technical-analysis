# 第040章 跨类别组合的量化验证

前四章对趋势、震荡、波动率、量价四类共 28 个指标逐个做了检验，每个指标都走完拆解、截面选股、择时、组合使用四步。前四章的组合使用小节处理的是指标自己的两三个常见搭档，多数落在同一类别内部。同一类别的特征信息源接近，叠加之后往往只是把同一个维度数了两遍，增益有限。

本章往上一级，处理跨类别的组合，回答三个问题：不同类别的特征如何组合；组合是否真带来增益；增益来自哪里。检验口径沿用第 007 章，工具仍是 `cross_section_ic`、`ic_summary`、`layered_returns`、`timing_signal_test`、`conditional_quantile_return`、`timing_backtest` 与 `combined_signal` 这一组函数，本章只补充组合专用的构造与判读。

本章同时是第三部分的收尾，也是通往第四部分的桥梁。四类代表特征分别取趋势偏离度、震荡中轴偏离、波动率分位与量价变化率，理由在下一节展开。

## 组合的三个层次

组合不是单一动作，按信息结构可以分成三层，复杂度依次上升。分层的意义在于，不同的结构对应不同的检验重点与不同的失效原因，混在一起谈容易把问题搅乱。

第一层是同类组合，指同一类别内部的多个特征。趋势类里同时使用价格相对均线的偏离度与平均趋向指数，或者震荡类里同时使用中轴偏离与变化率，都属于这一层。这一层的信息冗余度偏高，几个特征多半共享同一个价格均值或同一段涨跌幅，叠加后的效果接近把原始特征重新加权一次。增益有限，但计算简单、稳定性好，常作为铺垫与对照。

第二层是跨类组合，指不同类别特征之间的组合，例如趋势与震荡、趋势与波动率、波动率与量价。这一层的互补性最强，也是本章的重点。趋势类提取的是方向，震荡类提取的是位置，波动率类提取的是风险状态，量价类提取的是参与度，四者回答的问题不同，理论上可以叠加。跨类组合的形式大多还是加权合成，只是权重需要重新估计，估计的稳定性成为主要关注点。

第三层是条件组合，指一类特征作为主信号，另一类作为条件掩码。例如只在趋势成立时才启用震荡信号，或者只在量能配合时才采信价格突破。这一层的信息结构最复杂：掩码改变了主信号的生效范围，组合结果不再等于两个特征的线性叠加，也最接近实际交易的决策顺序。代价是掩码的阈值多了一个需要选择的参数，拟合风险随之上升。

三层之间的差别可以用一个简单的例子说明。假设趋势偏离度为正的标的后市偏好，震荡中轴偏离为负的标的后市偏好。加权合成会把两个信号按权重相加，得到的是一个综合分数，趋势与震荡的作用在每只标的上同时发生。条件组合则先判断趋势是否成立，只在趋势为正的标的中再按震荡排序，趋势不成立的标的直接被排除。同样的两个特征，两种组合得到的持仓集合可能完全不同。前者覆盖全部标的，后者只覆盖一部分，取舍取决于研究者更相信哪一个逻辑。

层次越高并不代表效果越好。条件组合的表达能力最强，可解释性也最弱，出了问题是掩码选错还是主信号本身就无效，往往不容易区分。第 007 章强调的归因原则在这里同样适用：结构越复杂，越需要把增益拆开看，否则无法判断改进来自哪里。下面这张表把三层的主要特征并列出来，表中的互补性与风险都是先验取向，不是实测结论。

| 层次 | 典型例子 | 互补性来源 | 主要风险 | 检验难度 |
|------|---------|-----------|---------|---------|
| 同类组合 | 趋势偏离度与 ADX 强度 | 信息源接近，仅有时间尺度差异 | 冗余高，增益接近零 | 低 |
| 跨类组合 | 趋势偏离度与波动率分位 | 方向与风险状态两个维度 | 实测相关高于预期，部分信息相互抵消 | 中 |
| 条件组合 | 趋势掩码下的震荡信号 | 方向与位置的市况分工 | 掩码阈值带来拟合风险 | 高 |

实际研究很少只停留在某一层。常见的做法是先用跨类组合把维度补齐，再用条件组合处理市况切换，最后回到等权做一次基准对照。三层并不是互斥的选项，而是同一套特征在不同结构下的三种用法。

从检验的角度看，层次越高，需要估计的参数越多，需要留出的样本外也越长。同类组合几乎没有参数，一组数据就够对照；条件组合多出一个掩码阈值，至少要能在两个先验阈值下给出稳定结论；跨类组合的加权方式若涉及权重估计，则样本外的要求与最优化权重相同。这一条约束在选择组合层次时值得先想清楚：如果数据长度不足以支撑样本外验证，那么更简单的结构反而更值得信任。

## 跨类组合的互补性来源

跨类组合有效的前提，是四类特征提取的信息确实不同。趋势类从价格序列中提取方向，回答价格在向哪边走；震荡类从价格相对区间的位置中提取状态，回答当前是否偏离常态；波动率类提取风险状态，回答幅度是扩张还是收缩；量价类提取参与度，回答价格变化有多少成交在背后支撑。方向、位置、风险状态、参与度是四个不同的维度，理论上正交或半正交，组合之后信息量有叠加的空间。

理论上的正交，落到实测数据上往往要打折扣，有三点需要提前说明。

第一，实测相关性通常高于理论预期。趋势与震荡在构造上都用到价格的某种均值，趋势偏离度的分母是均线，震荡中轴偏离的分母是近期区间中位，两者都可能随同一段价格走势同向变动，于是出现残留相关。量价类中带价格符号的特征与趋势特征也并非完全无关。相关性的实测值需要在组合之前单独计算，不能从经济含义出发想当然。

第二，互补性随市况变化。在趋势明确的市场里，趋势特征给出的方向与震荡特征给出的反向信号会正面冲突：价格持续走强，趋势偏离度为正，而震荡指标可能已经进入超买区。此时的组合不是互补，而是两个方向相反的因子相互抵消。反过来，在横盘市场里两者又可能同时有效。因此跨类组合的检验需要按市况分段，全样本的平均相关系数会掩盖这种结构。

第三，组合不是越多越好。每增加一个特征，都会引入新的权重需要估计，而权重本身带着估计误差。当新增特征与已有特征相关性偏高时，它对组合 ICIR 的边际贡献接近于零，但它的权重估计噪声照旧进入组合。特征数量超过某个规模之后，估计误差累积的速度可能快过信息叠加的速度，组合反而变得不稳定。这是下一节反复要回到的一个结论。

四类特征的理论关系与实测偏离，可以整理成下面这张对照表。表中的相关性水平为定性示意，用于说明方向，不是实测结果。

| 特征类别 | 提取维度 | 代表特征 | 与其他三类的理论关系 | 实测相关性的常见偏离 |
|---------|---------|---------|-------------------|-------------------|
| 趋势 | 方向 | 价格相对均线偏离度 | 与震荡共用价格均值，与量价可能重叠 | 实测高于预期，趋势与震荡残留相关明显 |
| 震荡 | 位置 | 读数相对中轴偏离 | 与趋势共用价格基准，与波动率弱相关 | 趋势市中与趋势方向相反，符号随市况切换 |
| 波动率 | 风险状态 | 波动幅度历史分位 | 与前三类理论上都较弱相关 | 与量价中的量能扩张有同步倾向 |
| 量价 | 参与度 | 资金流向变化率 | 与趋势弱相关，与波动率弱相关 | 与趋势、均线类特征存在价格符号带来的重叠 |

用这张表可以形成一个粗略的操作顺序：先用低相关的一对特征构造组合，观察 ICIR 是否高于两者；确认存在互补之后，再考虑加入第三个维度；每一步都重新计算与已有特征的相关性，相关性偏高时宁可停下。相关性本身的计算要用横截面平均，而不是把整个面板混在一起算一次，因为后者会把时间序列的共动误当成横截面相关。

```python
# 四类代表特征的横截面平均相关系数
feats = ["sma_dev", "rsi_dev", "atr_rank", "obv_change"]

# 先做横截面标准化，再按日计算相关矩阵并求平均
z = panel.copy()
for c in feats:
    z[c] = z.groupby("date")[c].transform(
        lambda s: (s - s.median()) / (s - s.median()).abs().median()
        if (s - s.median()).abs().median() > 0 else 0)

corr_daily = z.groupby("date")[feats].corr()
avg_corr = corr_daily.groupby(level=1).mean()
print(avg_corr.round(2))
```

```r
# 四类代表特征的横截面平均相关系数
feats <- c("sma_dev", "rsi_dev", "atr_rank", "obv_change")

# 先按日做横截面标准化，再逐日计算相关矩阵并求平均
z <- panel |>
  group_by(date) |>
  mutate(across(all_of(feats), function(x) {
    # constant = 1 取裸中位绝对差，与 Python 侧一致
    m <- mad(x, na.rm = TRUE, constant = 1)
    if (isTRUE(m > 0)) (x - median(x, na.rm = TRUE)) / m else 0
  })) |>
  ungroup()

avg_corr <- matrix(0, length(feats), length(feats), dimnames = list(feats, feats))
for (d in split(z, z$date)) {
  cm <- cor(as.matrix(d[, feats]), method = "spearman")
  avg_corr <- avg_corr + replace(cm, is.na(cm), 0)
}
avg_corr <- avg_corr / length(unique(z$date))
print(round(avg_corr, 2))
```

这一段用的是 5 只蓝筹，样本量只够验证流程是否跑通。真实的横截面研究需要扩充到 50 只以上，并做行业中性处理，否则相关矩阵会被少数标的的异常收益扰动，稳定性不足。

相关矩阵给出的是两两之间的关系。若某一对特征的相关系数在四类两两之间偏高，那么这一对不适合直接加权，更合适的做法是改用条件掩码，或者只保留其中一个。相关矩阵因此是组合之前的第一道筛子，而不是可有可无的附注。

当相关性偏高又不想放弃某个特征时，还有第三条路：正交化。做法是把待加入的特征对已有特征做横截面回归，取残差作为新的因子。残差与已有特征在构造上正交，携带的是原有特征没有覆盖的那部分信息。这条路的代价是残差的经济含义变得模糊，它不再是原来那个可解释的特征，解释时要谨慎。震荡类指标各章在讨论同源指标的搭配时提到过同样的做法，这里的逻辑一致。

```python
# 正交化：把震荡特征对趋势特征回归后的残差作为增量因子
import numpy as np

resid = []
for _, gg in panel.groupby("date"):
    d = gg.dropna(subset=["sma_dev", "rsi_dev"])
    if len(d) < 5:
        resid.append(pd.Series(np.nan, index=d.index))
        continue
    x = np.column_stack([np.ones(len(d)), d["sma_dev"]])
    beta, *_ = np.linalg.lstsq(x, d["rsi_dev"], rcond=None)
    resid.append(pd.Series(d["rsi_dev"] - x @ beta, index=d.index))
panel["rsi_resid"] = pd.concat(resid).reindex(panel.index)

print(ic_summary(cross_section_ic(panel, "rsi_resid", "forward_5")))
# 残差因子的 IC 若仍为正，说明震荡特征含有趋势之外的信息
```

```r
# 正交化：把震荡特征对趋势特征做横截面回归，取残差作为增量因子
panel <- panel |>
  group_by(date) |>
  mutate(rsi_resid = {
    d <- pick(sma_dev, rsi_dev)
    ok <- stats::complete.cases(d)
    out <- rep(NA_real_, dplyr::n())
    if (sum(ok) >= 5) {
      out[ok] <- stats::resid(stats::lm(rsi_dev ~ sma_dev, data = d[ok, ]))
    }
    out
  }) |>
  ungroup()

print(ic_summary(cross_section_ic(panel, "rsi_resid", "forward_5")))
# 残差因子的 IC 若仍为正，说明震荡特征含有趋势之外的信息
```

上述正交化在 5 只标的上运行，标的数少于回归所需，残差没有统计意义，只用于说明做法。真实的横截面研究需要 50 只以上标的，正交化的回归才有意义，残差因子的 IC 也才值得解释。

## 组合方法及其检验

组合的具体做法有六种，从最朴素的等权到最复杂的条件组合。每一种都有它的适用条件与失效情形，下面逐个说明。所有方法的检验对象都是同一个：先把合成得到的新特征当作一个普通因子，重新走一遍第 007 章的截面与择时流程，再与参与组合的各个单特征对照。判读标准也只有一个，组合 ICIR 高于两者才说明互补，介于两者之间只是平均。

六种方法并不是越往后越好，它们对应的是不同的信息结构。等权与加权合成把特征当作可以相加的信息，条件组合把特征当作有先后的决策步骤，分层组合则介于两者之间，先按维度聚合再并列。选择哪一种，取决于特征之间的经济关系，而不是取决于方法的复杂度。错配是最常见的问题：特征之间本来有先后逻辑，硬做加权合成，得到的组合既没有清晰含义，效果也未必稳定。

### 等权合成

等权合成把所有标准化后的特征直接平均，不估计任何权重：

$$g_{i,t} = \frac{1}{K}\sum_{k=1}^{K} z\left(f^{(k)}_{i,t}\right)$$

其中 $z(\cdot)$ 是第 007 章的横截面标准化，$K$ 是特征个数。等权的最大优势是无需估计权重，因此也没有权重误差。它在实践中常被当作基准，任何复杂方法都要先通过一个检验：样本外的表现能否超过等权。

等权的适用条件比较宽松，只要各特征已经对齐方向。所谓对齐，是指先确认每个特征的 IC 符号，符号为负的特征取其相反数再进入合成，否则一个正向因子与一个反向因子相加会相互抵消，得到接近零的组合。这一步在跨类组合里尤其重要，波动率类特征的符号常与方向类相反，直接相加的后果是组合 IC 均值被拉平，看起来像是两个特征都无效，实际是符号没有对齐。

等权的失效情形主要有两类。一是特征数量少而相关性差异大时，等权把高相关特征与低相关特征同等对待，低相关特征的贡献被稀释。二是各特征的信息量差异悬殊时，等权让信息量小的特征占据与信息量大的特征相同的权重，浪费了权重预算。不过在多数情形下，等权的稳健性足以覆盖这些损失，这也是它在样本外常难被超越的原因。参数少是它的核心优点，参数少意味着出错的地方少。

检验方法很直接：用 `combined_signal` 传入特征列，`weights` 留空即等权，再对合成的 `combined` 列走一遍 `cross_section_ic` 与 `ic_summary`，与单特征结果并列比较。

```python
# 等权合成：weights 留空
panel = combined_signal(panel, ["sma_dev", "rsi_dev", "atr_rank", "obv_change"])
ic_eq = cross_section_ic(panel, "combined", "forward_5")
print(ic_summary(ic_eq))
# 与四个单特征的 ICIR 并列，判断组合是否高于上界
```

```r
panel <- combined_signal(panel, c("sma_dev", "rsi_dev", "atr_rank", "obv_change"))

```

这里的 5 只标的仅用于核对组合流程。真实的组合检验需要 50 只以上标的并做行业中性，否则组合与单特征之间的 ICIR 差异多半来自噪声，无法判断。

### IC 加权合成

IC 加权按各特征的历史 IC 均值分配权重，信息量大的特征获得更高的权重：

$$w_k = \frac{\overline{IC}_k}{\sum_{j=1}^{K}\left|\overline{IC}_j\right|},\qquad g_{i,t}=\sum_{k=1}^{K} w_k\, z\left(f^{(k)}_{i,t}\right)$$

权重的分母取绝对值之和而非直接求和，是为了在存在负 IC 特征时保证权重尺度可控。这个方法的直觉是让历史表现好的特征多说一点话，让历史表现弱的特征少说一点话。

适用条件是各特征的 IC 序列相对稳定，符号不在样本间反复变化。只要符号稳定，IC 均值就是一个可用的权重代理。相比等权，它多引入了一层对历史表现的依赖：若某个特征在某段样本内恰好表现突出，它会获得偏高的权重，而这段突出未必来自真实的信息量。

它的主要失效情形是 IC 估计的噪声。IC 均值来自有限样本，本身带有抽样误差，当样本期数不多时，这个误差可能接近甚至超过 IC 均值本身。此时权重更多反映的是噪声，而不是真实的信息量。若某个特征的 IC 符号在样本内出现过翻转，权重也会随之来回跳动，组合的稳定性下降。更麻烦的是，IC 加权的权重估计与检验用的是同一段数据，样本内的 IC 均值天然被高估，这会系统性地放大部分特征的主导程度。

使用时要先算出每个特征的 IC 均值，再归一化得到权重，最后把权重传给 `combined_signal`。

```python
# IC 加权：先用单特征 IC 均值构造权重
feats = ["sma_dev", "rsi_dev", "atr_rank", "obv_change"]
ic_means = {c: cross_section_ic(panel, c, "forward_5").mean() for c in feats}
total = sum(abs(v) for v in ic_means.values())
w_ic = [ic_means[c] / total for c in feats]
print(dict(zip(feats, [round(w, 3) for w in w_ic])))

panel = combined_signal(panel, feats, weights=w_ic)
print(ic_summary(cross_section_ic(panel, "combined", "forward_5")))
```

```r
# IC 加权：先用单特征 IC 均值构造权重
feats <- c("sma_dev", "rsi_dev", "atr_rank", "obv_change")
ic_means <- sapply(feats, function(f) {
  ic_summary(cross_section_ic(panel, f, "forward_5"))$IC均值
})
w_ic <- ic_means / sum(abs(ic_means))
print(round(w_ic, 3))

panel <- combined_signal(panel, feats, weights = as.numeric(w_ic))
print(ic_summary(cross_section_ic(panel, "combined", "forward_5")))
```

这一段仍以 5 只标的演示，只够确认权重能正确传入。真实的权重估计需要更多标的与更长的样本，否则权重本身的可信度不足。检验时要多做一个动作：把样本切成前后两段，分别估计权重，比较两段权重是否接近。权重在前后两段之间大幅变动，说明 IC 估计不稳定，IC 加权在这个组合上未必合适，退回等权是更稳妥的选择。

### ICIR 加权合成

ICIR 加权把权重建立在风险调整后的 IC 上，同时考虑方向与稳定性：

$$w_k = \frac{ICIR_k}{\sum_{j=1}^{K} ICIR_j},\qquad ICIR_k = \frac{\overline{IC}_k}{\sigma_{IC_k}}$$

与 IC 加权相比，它更偏好那些方向稳定、波动小的特征，而不是单看 IC 均值高的特征。第 007 章已经指出，IC 均值高但波动大的特征，在组合里通常不如 IC 均值中等但稳定的特征。ICIR 加权正是把这一判断写进了权重。它的经济含义可以这样理解：一个偶尔很准、经常不着调的特征，不如一个每次都略准的特征更适合进入组合。

它的适用条件是各特征的 IC 序列波动水平可以比较。当各特征的波动率处在同一数量级时，ICIR 加权与 IC 加权的排序接近；当波动率差异很大时，ICIR 加权会把权重明显偏向低波动特征，这一点需要在解释时说明，否则容易误以为某个特征更重要，实际只是它的 IC 更平。

它的失效情形与 IC 加权类似，只是表现形式不同：当某个特征的 IC 序列波动极小但样本期数不足时，ICIR 的分母偏小，权重会被放大到一个不合理的水平。稳健的做法是给权重加一个上限，或者用滚动窗口估计 ICIR 并做平滑，避免单个特征主导整个组合。ICIR 的分子与分母都来自同一段样本，样本外的稳定性需要另做验证，不能只凭权重看起来平滑就认为它可靠。

```python
# ICIR 加权：用 IC 均值与 IC 标准差构造权重
feats = ["sma_dev", "rsi_dev", "atr_rank", "obv_change"]
icirs = {}
for c in feats:
    ic = cross_section_ic(panel, c, "forward_5")
    icirs[c] = ic.mean() / ic.std()
total = sum(icirs.values())
w_icir = [icirs[c] / total for c in feats]

panel = combined_signal(panel, feats, weights=w_icir)
print(ic_summary(cross_section_ic(panel, "combined", "forward_5")))
```

### 最优化权重合成

最优化权重不再是启发式分配，而是把权重当作一个优化问题的解。把组合因子的 IC 序列写成 $IC^{g}_t = w^{\top} IC_t$，其中 $IC_t$ 是各特征在时点 $t$ 的 IC 向量，则组合的 IC 均值是 $w^{\top}\mu$，方差是 $w^{\top}\Sigma w$，最大化风险调整后的比值得到：

$$\max_{w}\ \frac{w^{\top}\mu}{\sqrt{w^{\top}\Sigma\, w}}\ \Longrightarrow\ w^{\star} \propto \Sigma^{-1}\mu$$

其中 $\mu$ 是各特征 IC 均值的向量，$\Sigma$ 是 IC 序列的协方差矩阵。这个解在数学上干净，含义是同时追求高 IC 与高分散，把两个目标的权衡交给协方差结构处理。

它的适用条件很苛刻：协方差矩阵 $\Sigma$ 需要被稳定地估计出来。IC 序列长度有限，特征个数一多，$\Sigma$ 的估计误差就迅速放大，求逆之后误差被进一步放大，得到的权重对样本极其敏感。这是它在样本外经常失灵的根本原因，也是本节需要重点提醒的一点。

失效表现是样本内好看、样本外退步。在样本内，最优化权重会充分利用特征之间的相关结构，把组合 ICIR 推到很高；换到样本外，相关结构发生变化，原先的权重不再合适，表现往往回落，甚至不如等权。原因是权重估计本身的误差超过了优化带来的那点收益。这个现象在金融优化里反复出现：待估参数越多，估计误差的绝对值越大，而优化恰恰倾向于把权重压到估计误差最大的方向上。

处理办法通常是加重权重约束，例如限制单个特征权重上限、限制权重偏离等权的幅度，或者干脆放弃最优化，改用等权。约束本身也是一种信息，它把研究者的先验（例如各类特征大致同等重要）写进了模型，降低了权重估计的自由度。哪一种更好，要靠样本外对照来判断，而不是凭样本内的数值。下面的代码给出一个带约束的最小方差解，用于说明构造方式。

```python
from scipy.optimize import minimize

feats = ["sma_dev", "rsi_dev", "atr_rank", "obv_change"]
ic_mat = pd.concat(
    [cross_section_ic(panel, c, "forward_5").rename(c) for c in feats], axis=1)
mu = ic_mat.mean().values
sigma = ic_mat.cov().values

def neg_ratio(w):
    return -(w @ mu) / np.sqrt(w @ sigma @ w + 1e-12)

cons = [{"type": "eq", "fun": lambda w: w.sum() - 1}]
bounds = [(0.0, 0.5)] * len(feats)          # 单特征权重上限，抑制极端解
res = minimize(neg_ratio, np.ones(len(feats)) / len(feats),
               bounds=bounds, constraints=cons)
print(dict(zip(feats, res.x.round(3))))
```

```r
# 最优化权重：最大化组合 IC 均值与标准差的比值，限制单特征权重上限
feats <- c("sma_dev", "rsi_dev", "atr_rank", "obv_change")

# 各特征 IC 序列按日期对齐
ic_df <- NULL
for (f in feats) {
  one <- cross_section_ic(panel, f, "forward_5")
  colnames(one)[colnames(one) == "ic"] <- f
  ic_df <- if (is.null(ic_df)) one else merge(ic_df, one, by = "date")
}
mu <- colMeans(ic_df[, feats])
sigma <- cov(ic_df[, feats])

neg_ratio <- function(w) {
  -(w %*% mu) / sqrt(as.numeric(w %*% sigma %*% w) + 1e-12)
}
# 单特征权重上限 0.5，抑制极端解；归一后再比较
res <- stats::optim(rep(1 / length(feats), length(feats)), neg_ratio,
                    method = "L-BFGS-B",
                    lower = rep(0, length(feats)), upper = rep(0.5, length(feats)))
w_opt <- res$par / sum(res$par)
print(round(stats::setNames(w_opt, feats), 3))
```

这段代码用的是 5 只标的，协方差矩阵的估计极不稳定，权重没有参考价值。真实研究需要在 50 只以上标的上估计，并用样本外结果对照等权，才能判断约束后的最优化是否值得。

### 条件组合（掩码式）

条件组合把一类特征当作主信号，另一类当作开关，只在开关打开时主信号才生效：

$$g_{i,t} = z\left(f^{(a)}_{i,t}\right)\cdot \mathbf{1}\left[\,z\left(f^{(b)}_{i,t}\right) > c\,\right]$$

主信号是 $f^{(a)}$，掩码是 $f^{(b)}$，$c$ 是掩码阈值。这类组合无法用加权表示，因为它本质上是一个乘法或筛选操作。趋势与震荡的搭配最常见：趋势特征定方向，震荡特征只在方向成立时才参与排序。

适用条件是两个特征之间存在明确的逻辑先后，而不只是数值上的互补。趋势定方向、震荡找位置，量价做确认，波动率定风险预算，这些搭配都有经济上的先后关系，适合用掩码表达。反过来说，若两个特征只是弱相关而没有逻辑顺序，加权合成比掩码更合适，因为掩码会丢掉未通过筛选的样本，样本量下降，统计功效随之减弱。

它的失效情形是掩码阈值的选择引入拟合。阈值 $c$ 若在样本内调到最优，组合的表现会被高估。稳健的做法是把阈值固定在几个先验合理的位置分别检验，例如按横截面分位取中位数或三分之一分位，观察结论是否随阈值平稳变化。阈值敏感的组合，本身就是一个不稳定信号，说明它依赖的是样本内的偶然结构。

还有一种失效值得单列：当掩码本身与主信号高度相关时，掩码的作用接近把主信号取平方或做截断，它改变的是分布形状，而不是筛选逻辑。这时条件组合与对主信号做非线性变换没有实质区别，解释时要避免把两者混淆。

检验上，条件组合应当比较条件 IC 与无条件 IC。做法是先用掩码把横截面切成两个子集，分别在子集内计算主信号因子的 IC，再与全样本 IC 对照。


### 分层组合（先类内再类间）

分层组合先在每个类别内部合成一个类内分数，再在类别之间合成最终分数：

$$s^{(m)}_{i,t} = \frac{1}{K_m}\sum_{k \in m} z\left(f^{(k)}_{i,t}\right),\qquad g_{i,t} = \sum_{m=1}^{M}\lambda_m\, s^{(m)}_{i,t}$$

其中 $m$ 标识类别，$K_m$ 是该类别内的特征数，$\lambda_m$ 是类别权重。这个结构把权重的估计分成两步，第一步不估计参数（类内取等权），第二步只在类别层面估计 $M$ 个参数。

适用条件是类别内部特征较多、类别之间维度清晰。它最直接的好处是压缩了需要估计的权重个数：若四类共十几个特征，直接加权要估计十几个权重，分层之后只需估计四个类别权重，估计噪声显著降低。这也是它在特征数量较多时相对最优化权重更稳健的原因，参数少、自由度低，样本外更容易站住。类别权重的解释也更清楚，它回答的是哪一类信息更重要，而不是某个具体特征更重要，这个层次上的判断通常比单特征层面的判断更可靠。

它的失效情形出现在类别内部的合成方式上。若某个类别内部的几个特征高度相关，类内等权会把同一维度放大，稀释其他类别的贡献；若类别内部特征方向不一致，类内平均又会相互抵消。因此类内合成之前，仍要先检查类别内部的相关性与方向一致性。类别权重 $\lambda_m$ 的估计则回到前面几种方法的老问题，可以用等权、ICIR 加权或带约束的优化，同样需要检查样本外的稳定性。

分层组合还可以反过来用，作为诊断工具。若类内合成后的四个类别分数之间的相关性很低，说明四类的信息确实分得开，跨类组合的前景较好；若某个类别分数与另一个高度相关，说明这两类在特征层面上没有真正分开，跨类组合的互补性会很有限。

R 侧的实现可以沿用第 007 章的标准化逻辑，用 dplyr 分组完成类内平均，再对类别分数做第二次加权。

```r
library(dplyr)
library(TTR)

# 类内合成：按日期分组做横截面标准化，再取类内均值
class_score <- function(panel, cols, name) {
  panel |>
    group_by(date) |>
    mutate(across(all_of(cols),
      ~ (.x - median(.x, na.rm = TRUE)) / mad(.x, na.rm = TRUE, constant = 1))) |>
    summarise(score = rowMeans(across(all_of(cols)), na.rm = TRUE),
              .groups = "drop") |>
    rename(!!name := score)
}

# 类间合成：对四个类别分数再做一次等权或加权平均
final <- class_score(panel, "sma_dev", "s_trend") |>
  left_join(class_score(panel, "rsi_dev", "s_osc"), by = "date") |>
  left_join(class_score(panel, "atr_rank", "s_vol"), by = "date") |>
  left_join(class_score(panel, "obv_change", "s_vp"), by = "date") |>
  mutate(combined = rowMeans(pick(s_trend, s_osc, s_vol, s_vp), na.rm = TRUE))
```

分层组合的价值在特征数量较多时最明显。直接加权要把所有特征放进一个求和式，权重个数等于特征个数，估计误差随特征数增长；分层组合把合成拆成两步，每步的加权对象都少，估计误差因此更小。代价是它牺牲了类别之间的交叉信息，无法表达某一类的信息只在另一类成立时才有效的交互，这类交互仍然要靠条件组合来处理。因此分层组合与条件组合不是竞争关系，前者处理并列的维度，后者处理有先后逻辑的维度。

## 组合增益的归因

组合变好之后，第一步不是庆祝，而是拆分。组合 ICIR 高于单特征，这件事有三种完全不同的来源，价值也完全不同。分不清来源，就无法判断组合是否值得保留，也无法判断它在下一次市况变化时是否还成立。

来源之一是信息互补。两个低相关特征各自携带独立信息，合成之后覆盖的判断维度变宽，组合 IC 均值上升，ICIR 随之提升。这是最理想的增益，因为它意味着组合确实比任何单个特征看到了更多的东西，而且新增的信息是市场结构本身提供的，不依赖某一段样本的偶然。

来源之二是风险分散。两个特征的 IC 序列各自波动，合成之后波动被平均掉，ICIR 的分母下降，于是 ICIR 提升，而 IC 均值可能完全没有变化。这是最常见的增益来源，也是最容易被误认为预测能力提升的地方。ICIR 提高只说明方向更稳定，不说明平均预测强度变强。若据此加大仓位，可能承担了与预期不符的风险；更稳妥的理解是，它降低了策略表现的波动，改善的是稳定性而非收益率。

来源之三是权重拟合。组合在样本内表现优异，靠的是在样本内把权重调到最优，样本外这份优势消失。这是伪增益，需要在检验中识别出来。它的典型特征是样本内 ICIR 明显高于等权，样本外回落到等权附近，两者的差距就是拟合的成分。伪增益的危险在于它看起来最诱人，因为它恰恰是样本内最好的那一组权重。

需要指出的是，三个来源在结果上并不互斥。一次组合调整同时带来信息互补与风险分散的情形很常见，报出的 ICIR 提升是两者之和。归因的目的是估计各自占多少，而不是把提升强行归到单一来源。实践中可行的做法是分步合成：每加入一个特征时单独记录三个量的变化，把哪一步抬升了分子、哪一步压低了分母分开看清，比事后一次性归因更可靠。

判别的方法是分别比较 IC 均值、IC 标准差、ICIR 三个量在组合前后的变化，再对照样本外结果。三个量的变化组合能够区分增益类型。只看 ICIR 会混淆信息互补与风险分散，因为两者都表现为 ICIR 提升，但前者提升分子，后者压低分母，含义不同。

| 增益类型 | 组合 IC 均值 | 组合 IC 标准差 | 组合 ICIR | 样本外表现 | 判读 |
|---------|------------|--------------|----------|-----------|------|
| 信息互补 | 高于两者 | 基本不变或略降 | 高于两者 | 通常保持 | 有效增益 |
| 风险分散 | 与两者相当 | 低于较低者 | 高于两者 | 通常保持 | 有效增益，来自降波动 |
| 权重拟合 | 样本内偏高 | 样本内偏低 | 样本内明显偏高 | 回落至等权附近 | 伪增益 |
| 无增益 | 介于两者之间 | 介于两者之间 | 介于两者之间 | 不适用 | 只是平均 |

表中方向为定性示意，用于说明判读逻辑，不是实测数值。具体到某一组特征，三个量的实际变化需要用数据计算。

因此组合检验的报告至少要拆成 IC 均值、IC 标准差、ICIR 三个数，缺一个都难以判断增益的性质。报告里只留一个 ICIR，等于把三种来源的信息压缩成一个数字，读者无法分辨它是来自更宽的覆盖，还是来自更平的波动。

```python
# 增益归因：分别比较组合与单特征的三个量
def triple(panel, col):
```

识别权重拟合最直接的办法是做一次样本内外对照。按时间顺序把样本切成前后两段，前段用来估计权重，后段用来评估表现。若组合在前段的 ICIR 明显高于等权，而在后段回落到等权附近，这份高出的部分就是拟合。对照的关键是，两段的表现要用同一套权重，后段的权重不能被后段数据再次调整，否则对照失效。

```python
# 样本内外对照：识别权重拟合
cut = panel["date"].quantile(0.6)            # 前 60% 作样本内，后 40% 作样本外
in_s, out_s = panel[panel["date"] <= cut], panel[panel["date"] > cut]

def icir_of(df, col):
    ic = cross_section_ic(df, col, "forward_5")
    return ic.mean() / ic.std()

panel = combined_signal(panel, ["sma_dev", "rsi_dev"])       # 等权组合
print("样本内 等权", icir_of(in_s.assign(combined=panel.loc[in_s.index, "combined"]), "combined"))
print("样本外 等权", icir_of(out_s.assign(combined=panel.loc[out_s.index, "combined"]), "combined"))
# 再用样本内估计的 ICIR 权重合成，重算两段，比较样本内外的差距是否扩大
```

## 组合的截面验证

截面验证的完整流程是：构造四类代表特征、做横截面标准化与去极值、分步合成并逐步记录 IC 与 ICIR、观察每一步的边际贡献。分步合成的意义在于把组合从两个特征开始，逐个加入，每加一个都重新评估，这样能看清增益是在哪一步出现的，也能及早发现新增特征不再带来增量。一次性把四类特征全部塞进组合，只能得到一个总的结果，无法回答增益来自哪一步。

流程中有一个容易省略的步骤是特征的方向对齐。进入合成之前，要先确认每个特征的 IC 符号，把符号为负的特征取反，让所有特征在方向上一致。这一步在跨类组合里尤其不能省，因为波动率类特征的符号常与方向类相反，若不对齐，等权合成会把一个正贡献与一个负贡献相加，组合看起来毫无信息，实际是两个有效特征相互抵消。对齐的依据来自单特征检验的结果，而不是临时的判断。

下面是特征的构造与分步合成的代码。四类代表特征依次取趋势偏离度、震荡中轴偏离、波动率分位与量价变化率，构造口径分别见第 60、65、70、75 章，这里只做最小重述。

```python
import numpy as np
import pandas as pd

# panel 由第 007 章的数据获取代码得到，含 date / code / close / high / low / volume
g = panel.groupby("code")

# 趋势：价格相对 20 日均线的偏离度
panel["sma_dev"] = panel["close"] / g["close"].transform(lambda s: s.rolling(20).mean()) - 1

# 震荡：14 日 RSI 相对中轴的偏离
up = g["close"].transform(lambda s: s.diff().clip(lower=0).ewm(alpha=1/14, adjust=False).mean())
dn = g["close"].transform(lambda s: (-s.diff().clip(upper=0)).ewm(alpha=1/14, adjust=False).mean())
panel["rsi_dev"] = (100 - 100 / (1 + up / dn)) - 50

# 波动率：14 日 ATR 占价格的比率，再取横截面分位
tr = pd.concat([(panel["high"] - panel["low"]),
                (panel["high"] - g["close"].shift()).abs(),
                (panel["low"] - g["close"].shift()).abs()], axis=1).max(axis=1)
panel["atr_ratio"] = tr.groupby(panel["code"]).transform(
    lambda s: s.ewm(alpha=1/14, adjust=False).mean()) / panel["close"]
panel["atr_rank"] = panel.groupby("date")["atr_ratio"].transform(lambda s: s.rank(pct=True))

# 量价：OBV 的 10 日变化率
sign = np.sign(panel.groupby("code")["close"].diff().fillna(0))
panel["obv"] = (sign * panel["volume"]).groupby(panel["code"]).cumsum()
panel["obv_change"] = panel.groupby("code")["obv"].transform(
    lambda s: s.diff(10) / s.shift(10).abs())
```

特征准备好之后，做分步合成。每一步都调用 `combined_signal`，再做去极值，最后计算 IC 与 ICIR。去极值这一步不能省，波动率分位与量价变化率的尾部都偏厚，个别时点的极端值会主导排序。另一个常被忽略的动作是保留每一步的中间列，便于后续把某一步单独拿出来复核；如果只留最终组合，一旦结果异常，很难判断问题出在哪一步。

```python
# 分步合成：从两个特征开始，逐个加入
steps = [["sma_dev", "rsi_dev"],
         ["sma_dev", "rsi_dev", "atr_rank"],
         ["sma_dev", "rsi_dev", "atr_rank", "obv_change"]]

for cols in steps:
    panel = combined_signal(panel, cols)
    # 去极值：标准化后的列截断在正负 3 之间，再重新平均
    zcols = [c for c in panel.columns if c.endswith("_z")]
    panel[zcols] = panel[zcols].clip(-3, 3)
    panel["combined"] = panel[zcols].mean(axis=1)
    ic_c = cross_section_ic(panel, "combined", "forward_5")
    print(len(cols), ic_summary(ic_c).to_dict())
```

边际贡献的检验要分两步判断。每加入一个特征，先看组合 ICIR 是否相对上一步提升；若 ICIR 没有提升，说明新增特征没有改善方向稳定性，可以直接舍弃，不必再纠结它的经济含义。再看 IC 均值是否提升：ICIR 提升而 IC 均值不变，说明这一步带来的是风险分散而非信息互补；两者同时提升，才更接近信息互补。把每步的 IC 均值、IC 标准差、ICIR 并列画出来，能直观看到增益出现的时点，也能看出增益是在哪一步开始停滞。

| 合成步骤 | 组成特征 | IC 均值判读 | IC 标准差判读 | ICIR 判读 | 边际结论 |
|---------|---------|-----------|-------------|----------|---------|
| 第一步 | 趋势与震荡 | 相对单特征略升 | 低于两者 | 高于两者 | 出现增益 |
| 第二步 | 再加波动率 | 变化不大 | 继续下降 | 可能小幅上升 | 以风险分散为主 |
| 第三步 | 再加量价 | 接近持平 | 接近持平 | 接近持平 | 边际贡献接近零 |

表中判读为定性示意，不是实测数值。它的用处是给出一条预期的路径：增益通常出现在前两步，第三步之后边际贡献趋于平缓，这与前面“组合不是越多越好”的判断一致。

## 组合的择时验证

组合信号做择时，比单指标多了一个步骤。截面上的组合分数是每只标的一个值，要先用它决定整体仓位，就得先把它聚合成一个时序信号。常用的做法是取横截面均值或中位数，代表市场整体的状态：所有标的的平均特征分偏高，说明市场整体处在特征所描述的状态里，可以据此调整整体敞口。这一步是截面与择时之间的桥，跳过它直接对某一只标的的组合分数做择时，得到的只是个股现象，不是组合信号的效果。

聚合方式有两种常见选择，含义略有区别。取均值反映的是市场整体的平均状态，容易被极端标的拉动；取中位数反映的是中位标的的状态，更稳健，但对少数标的的剧烈变化不敏感。两种方式应当分别试一次，观察结论是否一致。若两种聚合给出的择时结论差别很大，说明策略依赖的是分布的形状而非中心，这一层信息需要在报告中说明，因为它意味着策略对小样本或极端事件更敏感。

聚合成时序信号之后，检验流程与第 007 章的择时线一致：用 `conditional_quantile_return` 看聚合信号分档后的条件收益，用 `timing_backtest` 把信号转成仓位规则，与买入持有对照。判读的重点是与单指标择时策略的横向比较，观察夏普与最大回撤是否改善，而不是看绝对收益。组合信号做择时的目标是让整体敞口更贴合市场状态，而不是精确择顶择底，把目标定在后者会容易误判结果。

```python
# 把截面组合分数聚合成市场时序信号

    mkt_signal=("combined", "median"),      # 横截面中位数，代表市场整体状态
    mkt_ret=("forward_1", "mean"),          # 等权平均的前向收益，作为市场收益代理
```

曲线以 5 只标的演示，仅用于说明对照方式，数值不构成结论。判断组合择时是否有效，要看策略曲线相对买入持有的形态：是全程更平滑，还是只在个别区间领先，两种形态的含义不同。全程更平滑通常对应风险分散带来的稳定，个别区间领先则更像对某段市况的捕捉，后者需要检查是否只在单一市况下成立。

还有一点容易被忽略：组合信号做择时时，仓位规则只用到信号的相对高低，而组合信号的绝对值水平与单特征并不在同一尺度上。因此仓位阈值应当按组合信号自身的分位重新确定，不能沿用单特征时代的分位数换算。沿用旧阈值会让持仓比例偏离设计意图，得到的对照结论也就失去意义。

## 与前四章结论的衔接

把前四章的判读汇总到一张表里，可以看清跨类组合的可能空间。下表给出四类特征的截面能力判读、择时能力判读与跨类互补性预期，均为先验取向，不是实测结论。

| 特征类别 | 代表特征 | 截面能力判读 | 择时能力判读 | 跨类互补性预期 |
|---------|---------|------------|------------|--------------|
| 趋势 | 价格相对均线偏离度 | 方向偏正，随市况切换符号 | 交叉与状态久期较清晰 | 与波动率、量价互补性较高 |
| 震荡 | 读数相对中轴偏离 | 反向为主，需分段复核符号 | 超买超卖反转，趋势市易失效 | 与趋势需以掩码搭配，避免冲突 |
| 波动率 | 波动幅度历史分位 | 收益目标偏负，波动率目标偏正 | 决定仓位大小而非方向 | 与趋势、量价互补性较高 |
| 量价 | 资金流向变化率 | 需先转相对量才可比 | 确认与背离为主 | 与趋势、波动率互补性中等 |

这张表最关键的一行是波动率。它的截面方向常为负，与趋势、震荡的方向都不一致，直接加权容易相互抵消，因此它更适合作为条件变量或仓位变量使用，而不是与其他因子并列放进加权求和。这与波动率类各指标章的判读一致：波动率因子决定仓位大小，方向因子决定持仓符号。

从这张表可以挑出几组值得优先尝试的跨类组合。选择的标准是信息维度不同、且有明确的经济先后。

第一组是趋势偏离度与波动率分位。一个给方向，一个给风险状态，两者的经济含义正交，实测相关通常也不高。逻辑上风险状态既影响方向信号的可靠性，也影响应持有的仓位，组合可以同时用于排序与仓位。需要留意的是波动率类特征符号常为负，进入等权合成前要先对齐方向，否则组合会被拉平。

第二组是量价变化率与趋势斜率。一个给参与度，一个给方向，量能配合下的趋势通常比孤立的趋势更可靠。这一组的做法可以是加权合成，也可以用量价做掩码，只在资金流向与价格方向一致时才采信趋势信号，后者更贴近量价确认的直觉，也更能解释为什么某些趋势信号值得等一等。

第三组是震荡偏离与趋势状态掩码。震荡特征给位置，趋势特征给方向并充当开关，只在趋势成立时才启用震荡信号。这组是典型的条件组合，检验时要比较条件 IC 与无条件 IC，确认掩码确实改变了震荡信号的生效范围。它与震荡类指标各章的结论直接对应：震荡类与趋势类搭配的本质是市况分工，而不是信息叠加。

第四组是波动率带宽与量价参与度。波动率收缩对应方向选择前的蓄势，量能扩张对应资金开始行动，两者在时点上常有先后关系。这一组的互补逻辑来自风险状态与参与度的配合，检验重点在时序上的前后关系，而不是横截面上的并列排序，因此它更适合走择时线，用聚合后的时序信号检验。

第五组是四类代表特征的等权合成，作为前面几组的对照基准。它不做选择性搭配，把四个维度一并纳入。它的用处是提供一个下界：任何精心设计的组合，若样本外不能稳定超过这个简单基准，就不值得采用。把等权摆在最后，是提醒研究者，复杂方法的价值要用它来度量。

这几组的检验顺序建议一致：先算两两横截面相关系数，相关性偏高时改用掩码或只取其一；再做分步合成，观察每步的边际贡献；最后把组合信号聚合成时序信号，与单指标择时对照。每一步都用第 007 章的判读标准，不另设门槛。顺序固定的好处是结果可比较，避免因为检验步骤不同而得出无法对话的结论。

把五组组合的逻辑与检验重点并列出来，便于安排验证的先后次序。下表的预期增益类型为定性示意，实际结论需要用数据判断。

| 优先组合 | 组成特征 | 互补逻辑 | 建议结构 | 预期增益类型 |
|---------|---------|---------|---------|------------|
| 第一组 | 趋势偏离度与波动率分位 | 方向与风险状态 | 等权或 ICIR 加权 | 信息互补为主 |
| 第二组 | 量价变化率与趋势斜率 | 参与度与方向 | 等权或量价掩码 | 信息互补为主 |
| 第三组 | 震荡偏离与趋势状态掩码 | 位置与方向 | 条件掩码 | 视掩码有效性而定 |
| 第四组 | 波动率带宽与量价参与度 | 风险状态与参与度 | 聚合后走择时线 | 风险分散为主 |
| 第五组 | 四类代表特征 | 四维度并列 | 等权 | 对照基准 |

第一到第三组走截面线更自然，因为它们的特征是横截面因子，排序含义清晰；第四组的两个维度在时点上有先后关系，走择时线更合适，聚合成市场状态后再判断仓位。第五组不追求增益，只提供对照。这样的安排把验证工作按结构分类，而不是按特征个数堆叠，检验的效率更高，结论也更容易归因。

## 通往机器学习

本章的方法到等权与掩码就基本走到边界，剩下的三个局限留给第四部分。它们不是实现上的疏忽，而是线性加权框架本身的性质。

其一，加权合成是线性的，难以直接表达特征之间的交互效应。低波动且高动量这类条件本身就是一个交互项，线性加权只能把两个特征各自的贡献相加，表达不出两者同时成立时才有效这层含义。掩码可以处理一部分交互，但需要人工指定哪个特征当开关，属于人工设定的交互，而非模型发现的交互。

其二，权重全局固定，难以随市况自适应。同一组特征在趋势市与震荡市的相对重要性不同，固定权重是在两者之间取折中，两种市况下都得不到最优配置。

其三，特征的构造仍依赖人工先验。本章拆出的四类代表特征按经济含义选定，它是否是市场信息的充分统计量，无法从检验中直接回答，也可能存在更有解释力、只是没有被想到的构造。

第四部分针对这三点展开，依次讨论特征挖掘、树模型、序列模型、状态模型与因子融合，用模型自动处理交互与自适应，并把人工构造特征与学习到的表示放在同一口径下比较。无论模型多复杂，判读增益的方法不变，仍要区分信息互补、风险分散与拟合。

## 本章检验结果汇总

把讨论过的组合方案归到一起，便于横向对照。下表给出一组先验判读，用于说明各方案的特点与适用场合，不是实测结论。

| 组合方案 | 组成特征 | 截面 ICIR 判读 | 择时改进判读 | 增益类型 | 推荐度 |
|---------|---------|--------------|------------|---------|-------|
| 等权四类合成 | 趋势、震荡、波动率、量价 | 通常接近单特征上界，偏稳 | 聚合后换手下降，回撤可能收窄 | 以风险分散为主 | 高，作为基准 |
| IC 加权合成 | 同上 | 依赖 IC 估计稳定性 | 无明显额外改进 | 混合，含拟合成分 | 中 |
| ICIR 加权合成 | 同上 | 偏向低波动特征，稳定性较好 | 同等权接近 | 以风险分散为主 | 中到高 |
| 最优化权重 | 同上 | 样本内偏高，样本外常回落 | 样本外改进有限 | 易含拟合成分 | 低，需约束与样本外验证 |
| 条件掩码组合 | 趋势掩码配震荡或量价 | 条件 IC 与无条件 IC 的差异是判读对象 | 信号数量下降，回撤可能收窄 | 取决于掩码是否有效 | 中到高，逻辑清晰 |
| 分层组合 | 先类内等权再类间合成 | 参数少，估计噪声较低 | 同等权接近 | 以风险分散为主 | 高，特征较多时优先 |

表中判读为定性示意，实际结论需要在 50 只以上标的、完成行业中性并留出样本外的条件下计算。表里反复出现的一条主线是：增益的稳定性比增益的幅度更值得关注，等权之所以常作基准，正是因为它没有权重误差这条额外的风险来源。任何想超越等权的方法，都要先证明它在样本外确实做到了，而不是在样本内看起来更好。

把这张表与前四章的逐指标汇总表放在一起看，可以形成一个完整的判断顺序：先确认每个单特征是否可用，再确认跨类组合是否带来增量，最后确认这份增量属于哪一类增益。三个步骤对应三张表，任何一步没有通过，后面的结论都不必强求。这套顺序本身就是第三部分想要传递的检验纪律。

## 小结

本章把趋势、震荡、波动率、量价四类特征放在一起做了跨类别组合。组合分三个层次：同类组合冗余高、增益有限；跨类组合互补性最强；条件组合以一类作掩码，最接近实际交易逻辑。四类特征分别提取方向、位置、风险状态与参与度，理论上正交，实测相关性往往高于预期，且随市况变化。组合方法有六种，其中等权最稳健，复杂加权在样本外常难超越等权，原因是权重估计误差超过了优化收益。判定增益时要拆开看：IC 均值上升多为信息互补，IC 标准差下降多为风险分散，样本内高而样本外回落则是伪增益。这些局限正好指向第四部分：线性加权难以表达交互，权重不随市况自适应，特征构造仍依赖人工先验。
