# 第042章 特征挖掘：从人工构造到自动生成

第三部分拆解出几十个有经济含义的特征，第四部分的第一件事是问：这些特征够不够。这一章处理的正是这个问题，把特征从"人工想出来"变成"系统生成出来再筛选"。

## 要解决的问题

第 006 章的四步流程从拆解开始。拆解依赖研究者的先验，由人判断一个指标可以被切成哪几个维度。这个做法有三个说不清的地方。

第一是覆盖面。拆出的这组特征是否已经包含该指标的全部有用信息，没有方法可以验证。如果真实的有效信息藏在没有被想到的维度里，后续的检验和建模都补不回来。

第二是构造细节。斜率取五日的差分还是十日的，偏离度除以价格还是除以波动率，这些选择多来自习惯，缺少系统的比较。同一个直觉可以写成多种算式，不同算式对应的因子表现可能差别明显，但人工只能试其中几种。

第三是跨指标组合。28 个指标各自拆解，拆出的特征之间是否有遗漏的交叉形式，也没有系统的方法去发现。趋势指标的位置信息与波动率指标的幅度信息相乘会得到什么，人工不容易想到，也不容易穷举。

这三点的共同后果是：特征空间的探索是局部的、依赖灵感的。特征挖掘要把它变成系统的、可枚举的。

## 核心思想

解决思路是把"生成特征"和"筛选特征"分成两件独立的事。

生成阶段不追求每个特征都有意义，只要求它合法、可不重不漏地覆盖一类变换。给定一组基础量和一组算子，让所有合法的组合都生成出来。这一步是机械的，可以用代码完成，产出的数量会远多于人工。

筛选阶段承担真正的研究判断。生成的候选里通常有大量无用、重复、甚至有害的特征。筛选的任务是从候选里留下少量可用的，标准有三个层次，先验、统计、模型驱动。

把两件事分开，是为了让生成的"宽"和筛选的"严"各司其职。生成太保守，会漏掉有用的特征；筛选太宽松，会把噪声带进模型。两者都要做，但作用的环节不同。

这个思路有一个容易被忽略的前提。分支的关键不在于生成多少个特征，而在于筛选的次序。下面的方法细节会说明，先验、统计、模型驱动三个层次的次序不能颠倒，颠倒之后的筛选结果在样本外最容易失效。

## 方法细节

### 特征扩充：从拆解到穷举

第三部分拆解出的特征是"有经济含义的特征"。它们通常只涉及一两个算子，形式接近常见的金融直觉，例如价格相对均线的偏离、均线自身的斜率。

特征扩充改变的是产出规模。它把算子与基础量做组合，生成几百到几千个候选特征。基础量不只是价格和成交量两类原始数据，也包括 28 个指标本身。算子不只是差分和比值，也包括滚动统计、分位、符号、交叉等形式。基数和算子的乘积决定了候选的规模。

扩充的目的不是让每个候选都有用，而是尽量不遗漏可能有用的形式。筛选会负责剔除无用的部分。这里有个取舍：生成得越宽，漏掉有用特征的概率越低，但筛选的负担和过拟合的风险越高。第 042 章的这一节只交代生成，控制风险的任务交给后面的筛选层次。

### 自动化特征生成（算子组合）

生成的基本结构是两层组合。给定基础序列集合 $B$ 与算子集合 $O$，先生成 $O(B)$，也就是把每个算子作用到每个基础量上；再生成 $O(O(B))$，也就是把算子作用到一层的输出上。两层之后，候选里既有对原始量的直接变形，也有对变形结果的再变形。

算子按作用分成几类，每一类的输入输出类型不同。下表列出常用的算子类别。

| 算子类别 | 具体算子 | 输入类型 | 输出示例 | 适用基础量 |
|---------|---------|---------|---------|-----------|
| 变化类 | 一阶差分、变化率、对数变化率、二阶差分 | 单序列 | 收盘价五日变化率 | 价格、成交量、指标序列 |
| 相对类 | 与滚动均值之比、与自身取值范围之比、两序列之差与比值 | 单序列或序列对 | 成交量比二十日均量 | 价格与成交量、不同周期指标 |
| 滚动统计类 | 滚动均值、滚动标准差、滚动分位位置、滚动偏度 | 单序列 | 收益的二十日波动 | 收益序列、指标读数 |
| 排序与状态类 | 横截面分位、符号、穿越标记、状态久期 | 单序列或横截面 | 指标高于中位数的连续天数 | 指标读数、信号序列 |
| 交叉类 | 两个特征的乘积、比值、条件掩码 | 序列对 | 低波动与高动量的联合标记 | 任意两个已生成特征 |

几个类别的作用不同。变化类提取方向与速度，相对类把量纲归一，滚动统计类刻画分布与波动，排序与状态类把连续值转成可比较或可解释的状态，交叉类显式构造两个特征的条件关系。交叉类与第 043 章的树模型存在功能重叠，树模型可以自动学到一部分交互，但显式给出交叉特征能让模型在样本有限时更容易捕捉到它们。

状态类与交叉类有一个共同的风险：容易引入未来信息。滚动分位若用了全样本的分位数，就用了未来的信息；状态久期若没有对齐到当日，也可能把未来算进来。生成阶段的每个算子都要检查其计算是否只依赖当日及之前的数据。

给出一个量级估算。以 5 个基础量（开盘、最高、最低、收盘、成交量）与 4 类算子（变化、相对、滚动统计、状态标记）为例，一层生成 $4 \times 5 = 20$ 个候选，二层把 4 类算子再作用于一层的 20 个输出，得到 $4 \times 20 = 80$ 个候选，两层合计 100 个。若滚动统计算子各取四个窗口（如 5、10、20、60 日），滚动类贡献的特征数乘以 4；若把相对类里的两两比值与交叉类的两两组合算进来，交叉项按基础对数的平方增长。两项叠加后，候选特征从百级升到千级，也就是几百到几千个。这个量级正是自动化生成与人工拆解的分水岭：人工拆解产出几十个有含义的特征，自动化生成产出成百上千个待筛选的候选。

### 特征选择的三个层次

筛选分三个层次，次序不能颠倒。

**第一层，先验筛选。** 依据经济含义判断，含义不成立的直接删。典型的情况包括：算子组合在金融上无法解释，例如把成交量与成交额同时相除得到常数；量纲不可跨标的比较，例如未归一的价格绝对水平；构造方式引入了未来信息。这一层的判断不需要数据，只依赖对指标和市场的理解。

**第二层，统计筛选。** 依据数据的统计性质删。常用的判据有覆盖率、方差和相关性。覆盖率指非缺失值的占比，滚动窗口越长的特征在样本头部缺失越多，覆盖率过低时可用样本不足。方差过低的特征近似常数，对排序没有贡献。相关性过高的一组特征信息重复，只保留其中代表。相关性可以用聚类处理：把两两秩相关超过阈值的特征聚成一类，每类留一个代表，代表的选择可以按方差、按覆盖率，或按经济含义的清晰程度。

**第三层，模型驱动筛选。** 依据模型给出的重要性删。方法包括树模型的特征重要性、前向选择、以及带 L1 正则的线性模型。这一层最接近模型，也最容易被误用。

三层筛选的关键在次序。**先验优先于统计，统计优先于模型驱动。** 反过来做，也就是先用模型挑出重要性高的特征，再回头找解释，会系统性地挑出"统计显著但无法解释"的特征。这类特征在样本内往往表现不错，在样本外最容易失效，因为它们多半拟合了训练样本特有的噪声。把先验放在最前，相当于先划定合法特征的范围，模型驱动只在这个范围内做微调。

统计筛选放在模型驱动之前，理由类似。相关性过高的特征若交给模型重要性去挑，模型可能在其中随机保留一个，保留哪个取决于样本噪声，结果不稳定。先用统计方法把重复的合并掉，再让模型在信息互补的特征里挑选，结论更稳。

第三层筛选在低信噪比数据上还有一个特有的问题：重要性估计本身不稳定。用不同的随机种子、不同的时间窗口训练，得到的重要性排序可能差别很大。因此模型驱动筛选的结果不宜作为唯一依据，需要与先验判断对照，并检查重要性排序在时间上是否稳定。

### 主成分与因子旋转

主成分分析（PCA）把一组相关特征线性组合成若干个互不相关的主成分，用少数几个主成分代表原来的大部分信息。在金融里，PCA 有一个经典的用法：对个股收益做 PCA，第一主成分通常近似于市场共同因子，占比较高，可以用来衡量市场整体风险。

直接把 PCA 用作预测输入的降维，则要谨慎。一是可解释性损失：主成分是原始特征的线性组合，方向由数据的协方差结构决定，常常没有明确的经济含义，难以判断某个主成分究竟代表什么。二是稳定性差：协方差结构随样本变化，主成分的方向也会随之旋转，同一主成分在不同样本里的含义可能不同。三是有信息损失：用前几个主成分代表全部特征，会丢掉尾部主成分里可能存在的、与收益相关的信息，而这些信息恰恰容易出现在与常见因子正交的方向上。

因子旋转可以缓解可解释性问题。旋转（如方差最大化旋转）改变主成分的方向，使每个主成分在少数原始特征上载荷较高、在其余特征上载荷接近零，便于给主成分命名。旋转不改变主成分张成的空间，只改变表达方式，因此信息量不变。对于想用降维后的成分做风险因子，而不是做预测输入的场景，旋转是有用的。

本书对 PCA 的用法给出一个界限：把它用于识别和剔除共同风险暴露，例如从特征里剥离市场与行业因子，是合适的；把它当作预测模型的输入层降维，则要记住上面三点代价，并用样本外检验确认降维没有损失有用信息。

### 特征重要性评估的两个体系

模型驱动筛选依赖特征重要性，而重要性有两套体系，结论可能不一致。

第一套是树模型内置的重要性，包括基于分裂次数与基于不纯度的口径，后者常称为 gain 重要性。它的计算是训练过程的副产品，成本低。它的偏倚也来自训练过程：取值多的特征，也就是基数高的特征，有更多可能的分裂点，因此更容易被选作分裂特征，即使它对预测没有贡献。连续型特征、尤其是量纲较大或取值分布分散的特征，天然更容易获得较高的 gain 重要性。用这套重要性排序时，要警惕它是被基数而不是被预测能力推动的。

第二套是排列重要性。做法是把某一个特征的值打乱，保持其他特征不变，看模型性能下降多少。下降越多，说明该特征越重要。它衡量的是特征对模型预测的实际贡献，不依赖训练过程，因此受基数偏倚的影响小一些。

排列重要性有两个需要注意的地方。一是对相关特征会低估：若两个特征高度相关，打乱其中一个时，模型仍可通过另一个获得几乎相同的信息，性能下降不明显，于是两个都被判为不重要。处理方式是先做相关性聚类，在每类里保留代表，再对代表做排列；或者使用分组排列，把相关的一组特征一起打乱。二是打乱方式会破坏时间结构：金融特征有纵向的时序相关，若逐点随机打乱某个特征，会制造出原本不存在的形态，使重要性估计失真。更合适的做法是分块排列，把时间轴切成若干块，在块之间整体置换，保留块内的时序结构。

两套体系应当对照使用。若一个特征在两套体系里都重要，可信度较高；若只在 gain 重要性里靠前而在排列重要性里靠后，多半是基数偏倚；若只在排列重要性里靠前，则要检查是否与某个更重要特征相关，排列时被低估了它的替补作用。

```python
import numpy as np
import pandas as pd

WINDOWS = [5, 10, 20, 60]

def ops_change(s):
    """变化类算子：差分、变化率、对数变化率。"""
    out = {}
    out[f"{s.name}_diff"] = s.diff()
    out[f"{s.name}_ret"] = s.pct_change()
    out[f"{s.name}_logret"] = np.log(s.clip(lower=1e-9)).diff()
    return out

def ops_relative(s):
    """相对类算子：与滚动均值之比、在滚动区间内的位置。"""
    out = {}
    for w in WINDOWS:
        ma = s.rolling(w).mean()
        lo = s.rolling(w).min()
        hi = s.rolling(w).max()
        out[f"{s.name}_ma{w}_dev"] = s / ma - 1
        out[f"{s.name}_pos{w}"] = (s - lo) / (hi - lo + 1e-9)
    return out

def ops_rolling(s):
    """滚动统计类算子：标准差、偏度、滚动分位位置。"""
    out = {}
    for w in WINDOWS:
        out[f"{s.name}_std{w}"] = s.rolling(w).std()
        out[f"{s.name}_skew{w}"] = s.rolling(w).skew()
        r = s.rolling(w).apply(lambda x: (x[-1] > x).mean(), raw=True)
        out[f"{s.name}_rank{w}"] = r
    return out

def ops_state(s):
    """状态标记类算子：符号、穿越、带符号的久期。"""
    sign = np.sign(s.diff())
    turn = sign.diff().abs() > 0
    dur = sign.groupby(turn.cumsum()).cumcount() + 1
    return {f"{s.name}_sign": sign, f"{s.name}_dur": sign * dur}

OPS_ONE = [ops_change, ops_relative, ops_rolling, ops_state]

def build_zoo(df, base_cols, two_layer=True):
    """两层生成：一层 O(B)，二层 O(O(B))。"""
    zoo = {}
    for c in base_cols:
        for op in OPS_ONE:
            zoo.update(op(df[c]))
    if two_layer:
        layer1 = pd.DataFrame(zoo, index=df.index)
        for c in layer1.columns:
            for op in OPS_ONE:
                for k, v in op(layer1[c]).items():
                    # 二层结果加前缀，避免与一层同名
                    zoo[f"L2_{k}"] = v
    return pd.DataFrame(zoo, index=df.index)
```

```python
from scipy.cluster.hierarchy import linkage, fcluster
from scipy.spatial.distance import squareform

def screen_by_prior(cols):
    """先验筛选：剔除经济含义不成立或引入未来信息的候选。"""
    banned_kw = ["_diff_diff", "_logret_logret"]  # 二阶差分等视为无经济含义
    return [c for c in cols if not any(k in c for k in banned_kw)]

def screen_by_stats(zoo, cols, cov_thr=0.8, var_thr=1e-8, corr_thr=0.9):
    """统计筛选：覆盖率、方差、相关性聚类。"""
    keep = [c for c in cols if zoo[c].notna().mean() >= cov_thr]
    keep = [c for c in keep if zoo[c].var() > var_thr and zoo[c].nunique() > 2]
    if len(keep) < 2:
        return keep
    corr = zoo[keep].corr(method="spearman").abs().fillna(0.0)
    dist = squareform(1 - corr.values, checks=False)
    lab = fcluster(linkage(dist, "average"), t=1 - corr_thr, criterion="distance")
    # 每类里保留方差最大的一个作为代表
    rep = {}
    for c, g in zip(keep, lab):
        if g not in rep or zoo[c].var() > zoo[rep[g]].var():
            rep[g] = c
    return list(rep.values())
```

```r
# 先验筛选：剔除经济含义不成立或引入未来信息的候选
screen_by_prior <- function(cols) {
  banned <- c("_diff_diff", "_logret_logret")   # 二阶差分等视为无经济含义
  keep <- rep(TRUE, length(cols))
  for (k in banned) keep <- keep & !grepl(k, cols, fixed = TRUE)
  cols[keep]
}

# 统计筛选：覆盖率、方差、相关性聚类
screen_by_stats <- function(zoo, cols, cov_thr = 0.8, var_thr = 1e-8, corr_thr = 0.9) {
  keep <- cols[colMeans(!is.na(zoo[, cols, drop = FALSE])) >= cov_thr]
  var_ok <- vapply(keep, function(c) {
    x <- zoo[[c]]
    v <- var(x, na.rm = TRUE)
    is.finite(v) && v > var_thr && length(unique(stats::na.omit(x))) > 2
  }, logical(1))
  keep <- keep[var_ok]
  if (length(keep) < 2) return(keep)

  corr <- abs(cor(zoo[, keep, drop = FALSE],
                  use = "pairwise.complete.obs", method = "spearman"))
  corr[is.na(corr)] <- 0
  # 平均连接聚类，把秩相关超过阈值的特征聚成一类
  hc <- stats::hclust(stats::as.dist(1 - corr), method = "average")
  lab <- stats::cutree(hc, h = 1 - corr_thr)

  # 每类里保留方差最大的一个作为代表
  v <- vapply(keep, function(c) var(zoo[[c]], na.rm = TRUE), numeric(1))
  names(v) <- keep
  unname(vapply(split(keep, lab), function(g) g[which.max(v[g])], character(1)))
}
```

```python
import lightgbm as lgb

def block_permutation_importance(model, X, y, block=20, n_repeat=5, seed=0):
    """分块排列重要性：在时间块之间置换，保留块内时序结构。"""
    rng = np.random.default_rng(seed)
    base = -np.mean((model.predict(X) - y) ** 2)
    idx = np.arange(len(X))
    blocks = np.array_split(idx, max(1, len(X) // block))
    out = {}
    for c in X.columns:
        drops = []
        for _ in range(n_repeat):
            Xp = X.copy()
            order = rng.permutation(len(blocks))
            new_idx = np.concatenate([blocks[p] for p in order])
            Xp[c] = Xp[c].to_numpy()[new_idx]
            drops.append(base - (-np.mean((model.predict(Xp) - y) ** 2)))
        out[c] = float(np.mean(drops))
    return pd.Series(out).sort_values(ascending=False)

def train_and_rank(panel, feature_cols, target_col, split_date):
    """按时间切分训练，输出 gain 重要性与分块排列重要性。"""
    tr = panel[panel["date"] < split_date]
    va = panel[panel["date"] >= split_date]
    model = lgb.LGBMRegressor(
        n_estimators=500, learning_rate=0.05, num_leaves=15,
        subsample=0.8, colsample_bytree=0.6, min_child_samples=200,
        reg_lambda=1.0, random_state=0)
    model.fit(tr[feature_cols], tr[target_col],
              eval_set=[(va[feature_cols], va[target_col])],
              eval_metric="l2", callbacks=[lgb.early_stopping(30, verbose=False)])
    gain = pd.Series(model.booster_.feature_importance("gain"),
                     index=feature_cols).sort_values(ascending=False)
    perm = block_permutation_importance(model, va[feature_cols], va[target_col])
    return gain, perm
```

```r
# 分块排列重要性：在时间块之间置换，保留块内时序结构
block_permutation_importance <- function(fit, data, features, target,
                                         block = 20, n_repeat = 5, seed = 0) {
  set.seed(seed)
  base <- -mean((predict(fit, data = data)$predictions - data[[target]])^2)
  idx <- seq_len(nrow(data))
  blocks <- split(idx, ceiling(idx / block))
  out <- numeric(length(features))
  for (j in seq_along(features)) {
    drops <- numeric(n_repeat)
    for (r in seq_len(n_repeat)) {
      ord <- sample(length(blocks))
      new_idx <- unlist(blocks[ord], use.names = FALSE)
      d <- data
      d[[features[j]]] <- d[[features[j]]][new_idx]
      p <- predict(fit, data = d)$predictions
      drops[r] <- base - (-mean((p - data[[target]])^2))
    }
    out[j] <- mean(drops)
  }
  names(out) <- features
  sort(out, decreasing = TRUE)
}

# 按时间切分训练，输出 gain 重要性与分块排列重要性
train_and_rank <- function(panel, feature_cols, target_col, split_date) {
  tr <- panel[panel$date <  split_date, ]
  va <- panel[panel$date >= split_date, ]
  form <- stats::as.formula(paste(target_col, "~", paste(feature_cols, collapse = " + ")))
  fit <- ranger(form, data = tr, num.trees = 500, mtry = 10,
                min.node.size = 200, importance = "impurity")
  gain <- sort(fit$variable.importance, decreasing = TRUE)
  perm <- block_permutation_importance(fit, va, feature_cols, target_col)
  list(gain = gain, perm = perm)
}
```

```r
library(dplyr)
library(xts)
library(TTR)
library(ranger)

WINDOWS <- c(5, 10, 20, 60)

# 变化类算子
ops_change <- function(s, nm) {
  lag1 <- stats::lag(s, 1)
  data.frame(
    diff    = s - lag1,
    ret     = s / lag1 - 1,
    logret  = log(pmax(s, 1e-9)) - log(pmax(lag1, 1e-9))
  ) |> setNames(paste0(nm, "_", c("diff", "ret", "logret")))
}

# 滚动统计类算子
ops_rolling <- function(s, nm) {
  res <- lapply(WINDOWS, function(w) {
    ma <- runMean(s, w)
    sdv <- runSD(s, w)
    data.frame(dev = s / ma - 1, std = sdv) |>
      setNames(paste0(nm, "_", c(paste0("ma", w, "_dev"), paste0("std", w))))
  })
  do.call(cbind, res)
}

# 两层生成
build_zoo <- function(df, base_cols) {
  layer1 <- lapply(base_cols, function(c) {
    s <- xts::xts(df[[c]], order.by = df$date)
    cbind(ops_change(s, c), ops_rolling(s, c))
  })
  zoo <- do.call(cbind, layer1)
  # 二层：对一层输出再做变化类算子
  layer2 <- lapply(colnames(zoo), function(c) {
    ops_change(zoo[, c], paste0("L2_", c))
  })
  cbind(zoo, do.call(cbind, layer2))
}

# 统计筛选：覆盖率与方差
screen_by_stats <- function(zoo, cov_thr = 0.8, var_thr = 1e-8) {
  cov <- colMeans(!is.na(zoo))
  v <- apply(zoo, 2, function(x) var(x, na.rm = TRUE))
  colnames(zoo)[cov >= cov_thr & v > var_thr]
}

# 模型驱动：ranger 的变量重要性（impurity 口径）
train_and_rank <- function(panel, feature_cols, target_col) {
  form <- as.formula(paste(target_col, "~", paste(feature_cols, collapse = "+")))
  fit <- ranger(form, data = panel, num.trees = 500, mtry = 10,
                min.node.size = 100, importance = "impurity")
  sort(fit$variable.importance, decreasing = TRUE) |> head(20)
}
```

## 常见陷阱

**筛选次序颠倒。** 先用模型重要性挑特征，再回头寻找解释，会挑出统计上显著但无法解释的特征。这类特征样本外最容易失效。次序应当是先验、统计、模型驱动。

**在筛选阶段使用全样本统计量。** 用全样本的分位数做滚动分位、用全样本的均值做中心化，都会把未来信息带进特征。筛选用的统计量也要按时间点滚动计算。

**生成阶段忽略未来信息。** 算子里的滚动窗口若对齐错误，或者状态久期没有回移到当日，都可能让特征包含未来几天的信息。生成之后应逐列检查每个值只依赖当日及之前的数据。

**排列重要性打乱时间结构。** 逐点随机打乱某个特征会破坏时序相关，制造出原本不存在的形态，重要性估计失真。应当分块排列，在时间块之间置换。

**被 gain 重要性误导。** 高基数特征天然更容易获得高分分裂，gain 重要性对它们有系统性抬升。排序时要与排列重要性对照，两个体系都靠前的特征才更可信。

**把 PCA 当无损降维。** 前几个主成分保留的方差占比高，不代表保留了与收益相关的信息。信息可能分布在尾部主成分里。用 PCA 做预测输入前，应当做样本外对照。

**候选过多引发的多重检验问题。** 在几千个候选里，总会有几十个在历史数据上偶然显得有效。若不控制这一点，筛选会把噪声当成信号。处理方式是提高显著性门槛，并要求入选特征在多个时间窗口上一致。

**相关性聚类把互补特征合并。** 相关性过高只是重复的标志之一。两个特征可能整体的相关系数不高，却在关键区间互补。聚类时除了看平均相关，还应看在不同市况分段下的相关。

## 小结

特征挖掘把特征的来源从人工先验扩展为系统生成。生成阶段用基础量与算子的两层组合，把候选从几十个扩充到成百上千个；筛选阶段按先验、统计、模型驱动三个层次逐级收缩，次序不能颠倒。主成分分析在金融里适合用来识别与剔除共同风险暴露，用作预测输入的降维则要留意可解释性、稳定性与信息损失三点代价。特征重要性有 gain 与排列两套体系，前者对高基数特征有偏，后者更接近实际贡献，但需要在筛选相关特征之后、用分块方式打乱，才能得到可靠结论。自动化生成的代价是过拟合风险上升、计算成本增加、可解释性下降，这些代价由筛选层次和样本外检验来承担。

特征库准备好之后，下一个问题是模型怎么用这些特征。线性加权已经证明无法表达特征之间的交互，下一章要引入的树模型，用递归分裂的方式自动构造条件关系，把"先按波动率分、再按动量分"这类交互直接学出来，同时保留对特征重要性的可解释输出。
