# 第047章 稳健性：过拟合识别与模型衰减

第 81 到 85 章介绍了特征挖掘、树模型、序列模型、状态模型与融合。这些方法有一个共同的敌人，就是过拟合。模型越复杂、搜索越宽、融合的层次越多，过拟合的机会也越多。而在低信噪比的金融数据上，过拟合有一个特点：它在样本内看不出来，只在样本外暴露。

本章是第四部分的守门章。它回答三个问题：怎么知道一个漂亮的结果是真的，怎么知道它在未来还有效，怎么知道它已经失效。第 007 章给过六条常见陷阱，但那是针对单个因子的检验。模型层面有过拟合的额外来源，本章专门处理这些来源，并给出一套可以逐项执行的验证方案。

## 要解决的问题

第 007 章的陷阱清单针对的是单个因子的检验，例如用线性相关代替秩相关、忽略 IC 序列的自相关、用 5 只标的做横截面检验。这些问题在模型层面同样存在，但模型带来了新的过拟合来源，可以归纳成三类。

第一类是搜索过拟合。研究者在做研究时会试很多种组合：不同的特征子集、不同的模型、不同的超参数、不同的预测窗口。试的次数越多，纯靠运气，总有一个组合在历史数据上看起来不错。如果只报告最好的那个，结果的可信度与尝试的次数直接相关。试了一百次挑出最好的一次，与只试了一次就是最好的，两者的意义完全不同。

第二类是样本过拟合。模型把训练样本里的偶然模式当成规律。这在低信噪比数据上尤其容易发生，因为可拟合的真实结构很弱，模型会把大量容量花在拟合噪声上。表现是训练集与验证集的差距扩大，且这个差距随模型容量增大而变大。

第三类是结构过拟合。它不是模型记住了训练数据，而是验证方式本身有漏洞。常见的漏洞包括：随机切分引入了时间泄漏，标签重叠让训练与测试样本共享信息，做了很多次检验却没有校正多重比较。这三类里，结构过拟合最隐蔽，因为模型本身可能很简洁，问题出在评估环节，从结果上看不出异常。

三类过拟合的共同后果是：样本内的表现被高估，而高估的程度无法从样本内看出来。要在做研究之前就设计出能识别它们的机制，而不是事后补救。

## 核心思想

应对过拟合的方向不是避免它，而是量化它的程度，并设定可接受的上限。完全消除过拟合在金融数据上做不到，因为信噪比低、样本量小、搜索空间大，这三者同时存在。可行的目标是让过拟合的程度小到不至于改变结论的方向。本章后续的方法都围绕这个目标展开：一边把验证方式做严，堵住可以堵的漏洞；一边把搜索规模记录下来，让无法消除的那部分过拟合至少可以被度量。

量化过拟合的关键是把"隐藏的搜索"变成"记录在案的搜索"。搜索过拟合之所以危险，是因为尝试的次数常常没有被记录下来。研究者记得最后一次尝试的成功，忘记了前面几十次失败。若每次都记录，包括失败的，尝试次数就变成一个明确的数字，可以用它来校正结果的显著性。这也是本章反复强调的一条：如果不能记录尝试次数，就无法校正，也就无法判断结果真伪。

另一个关键是把验证方式设计得足够严格，让结构过拟合的漏洞被封住。按时间切分、净化隔离区、校正多重比较，这三件事分别对应前面三类过拟合，缺一不可。它们不是可选项，而是模型层面检验的默认配置。

把三类来源与它们的应对方式并列出来，可以看到本章要处理的全貌。

| 来源 | 表现 | 检测方法 | 应对措施 |
|------|------|---------|---------|
| 搜索过拟合 | 试得足够多，总有组合历史表现好 | 统计尝试次数，计算校正后的显著性 | 记录所有尝试，用多重比较校正，提高门槛 |
| 样本过拟合 | 训练表现远好于验证表现 | 比较训练与验证的差距，看差距随容量的变化 | 限制模型复杂度，加正则，用集成 |
| 结构过拟合 | 模型简单但样本外仍虚高 | 检查切分方式、标签重叠、检验次数 | 按时间切分，加净化与禁运，校正多重比较 |

表中的三类来源可以同时存在，应对措施也常常需要一起用。一个模型可能既被搜索过拟合影响，又有结构过拟合的漏洞，单独修一处不足以让结论可信。

可接受的上限设在什么位置，需要一个参照。一个可用的参照是随机搜索的期望水平：在同样的样本长度、同样的收益分布、同样的尝试次数下，纯靠运气能得到的最高表现是多少。实际结果若明显超过这个期望，说明表现中可能有真实成分；若只是略高于期望，就难以区分是能力还是运气。Deflated Sharpe 正是把这个期望显式算出来，用它来调整观测到的夏普。这个思路的关键是，它把"多少算好"变成一个相对于搜索规模的问题，而不是一个绝对门槛。搜索规模越大，门槛越高，这与直觉一致。

设定上限还有一个现实意义：它让研究者可以事先说清"在什么条件下我会承认这个结果不可信"。有了这条线，后续看到的结果就有一个稳定的判断标准，不会因为结果看起来漂亮而临时放宽要求。这与第 041 章第五条原则一致，任何结论都要样本外验证，而验证的严格程度应当在看到结果之前就确定。

## 方法细节

### 时间序列交叉验证的三种切法

第 041 章已经说明金融数据不能随机切分。本节把按时间切分的三种具体做法交代清楚，它们适用于不同的场景。

第一种是滚动窗口（rolling），训练集长度固定，随预测时点向前滑动。例如固定三年训练，每季度向后移动一次。它的特点是训练集始终只包含最近的一段历史，旧数据被丢弃。适合市场结构变化较快、旧样本参考价值低的场景。代价是每次训练的样本量固定且偏少，估计较不稳定。

第二种是扩张窗口（expanding），训练集从起始日一直延伸到预测时点之前，样本量随时间增加。它的特点是保留全部历史，适合结构相对稳定的场景。代价是对早期结构的记忆不会清除，若某段早期行情与当前结构差异很大，它会持续影响模型。

第三种是净化切分（purged split），它是前两种与交叉验证的结合。做法是按时间把样本分成若干块，每一块轮流作为测试块，但训练块与测试块之间要做净化与禁运处理，避免标签重叠带来的泄漏。这一种最严格，也最适合用来做模型的样本外评估和超参数选择。它的细节放在下一小节。

| 切法 | 训练集长度 | 对旧数据的处理 | 主要用途 |
|------|-----------|--------------|---------|
| 滚动窗口 | 固定 | 丢弃超出窗口的旧数据 | 结构变化快的场景 |
| 扩张窗口 | 递增 | 保留全部历史 | 结构相对稳定，样本紧张 |
| 净化切分 | 按折变化 | 按折保留，但隔离重叠区 | 模型评估与超参数选择 |

三种切法都要遵守一条共同的纪律：切分点之后的数据不能以任何形式影响切分点之前的结果。模型的选择、超参数的确定、特征的筛选，都要在训练块上完成，测试块只用于最终评估一次。

还有一个与切法相关的数量问题：折数。折数多，每一折的测试样本少，评估的方差大；折数少，每折测试样本多，评估更稳，但能做的迭代次数少。金融数据上折数通常不多，三到六折是常见区间。折数本身也是一个需要固定并记录的选择，不宜根据测试结果反复调整。

### 净化与禁运（Purging 与 Embargo）

净化的对象是标签重叠。金融标签通常是未来一段时间的收益，例如未来五日收益。相邻时点的标签区间互相重叠：第 1 日的五日收益覆盖第 1 到 5 日，第 2 日的覆盖第 2 到 6 日。若训练集里有时点 $t$ 的样本，测试集里有时点 $t+1$ 的样本，两者的标签区间重叠了四天。这四天的信息同时出现在训练与测试中，测试表现会被高估。

净化（purging）的做法是：把训练集中那些标签区间与测试集标签区间重叠的样本剔除。具体来说，对于每一个测试样本，凡是标签期与它重叠的训练样本，都不参与该测试折的训练。这样训练与测试在标签层面上被隔开。

禁运（embargo）在净化的基础上再加一段。它的做法是：在测试块之后，额外剔除一段时间的训练样本，宽度设为标签持有期的一个倍数。原因是标签重叠之外，还存在一种更隐蔽的传递：测试块之前的样本，其标签期可能延伸进测试块，或者特征在测试块附近存在自相关，禁运把这段缓冲也清掉。禁运的宽度通常取标签持有期，也就是预测窗口的长度，有时会取它的倍数以充分隔离。

把两者放在一起，切分的结构是：训练块、净化区、测试块、禁运区，依次排列。净化区落在训练块与测试块之间，禁运区落在测试块之后，两者都属于不参与训练的区域。

| 区域 | 位置 | 处理方式 | 目的 |
|------|------|---------|------|
| 训练块 | 测试块之前 | 参与训练 | 提供模型拟合样本 |
| 净化区 | 训练块与测试块之间 | 剔除标签与测试重叠的样本 | 消除标签重叠泄漏 |
| 测试块 | 净化区之后 | 只用于评估 | 提供样本外表现 |
| 禁运区 | 测试块之后 | 从训练中剔除 | 消除特征自相关带来的邻近泄漏 |

这三段隔离加起来的宽度由标签持有期决定。标签持有期越长，需要隔离的区域越宽，可用的训练样本越少。第 044 章讨论序列模型时提到的缓冲期，本质上是净化在窗口层面的一种形式。本节把它推广到一般的标签重叠场景。

净化的实现有一个细节：它按每个测试样本单独判断要剔除哪些训练样本，因此比简单的整段剔除更精细，能保留更多可用样本。这在样本紧张的金融数据上是有意义的，因为整段剔除会浪费掉本来可用的样本。

一个具体的例子可以把这个过程看清。设标签为未来五日收益，测试块从第 101 日开始。训练集里第 96 日的样本，其标签覆盖第 96 到 100 日，没有进入测试块，可以保留。第 98 日的样本，其标签覆盖第 98 到 102 日，与测试块的第 101 日重叠，要被净化剔除。第 97 日的样本，标签覆盖第 97 到 101 日，同样触及测试块，也要剔除。剔除以标签区间的实际重叠为准，而不是以某个固定天数为准，这是净化与简单留白的关键差别。

| 训练样本日期 | 标签覆盖区间 | 是否触及测试块 | 处理 |
|------------|-------------|--------------|------|
| 第 95 日 | 第 95 到 99 日 | 否 | 保留 |
| 第 96 日 | 第 96 到 100 日 | 否 | 保留 |
| 第 97 日 | 第 97 到 101 日 | 是 | 净化剔除 |
| 第 98 日 | 第 98 到 102 日 | 是 | 净化剔除 |

禁运则在测试块结束之后再加一段。若测试块覆盖第 101 到 110 日，标签持有期为五日，则禁运从第 111 日到第 115 日的训练样本一并剔除。这样测试块附近的样本在标签与特征两个层面都与测试隔离，评估结果更接近真实的样本外场景。代价是可用训练样本进一步减少，隔离区越宽，这个代价越大，因此禁运宽度要按标签持有期设定，不宜盲目加宽。

### 多重比较的校正（Deflated Sharpe、BH 校正）

搜索过拟合的校正需要两个输入：尝试的次数，以及每次尝试的结果。如果只记得最好的一次，就只有一个数，无法校正。因此校正的第一步是记录，第二步才是计算。

先看记录。研究日志应当包含每一次尝试的配置、以及在统一的样本外口径下的表现。失败的结果同样要记，因为它们参与了搜索空间的规模。有了这份日志，尝试次数 $N$ 就明确了。

再看校正。最常用的一个量是收缩后的夏普比率（Deflated Sharpe Ratio）。它的思路是：在一共做了 $N$ 次尝试、每次尝试的收益分布有特定的偏度与峰度、样本长度为 $T$ 的条件下，计算"随机也能得到的最优夏普"的期望水平，再用它去调整观测到的夏普。若观测的夏普没有超过这个随机期望，说明它可能只是搜索的产物。这个校正考虑了四个因素：尝试次数、收益的偏度、收益的峰度、样本长度。尝试次数越多、样本越短，随机期望越高，需要观测夏普超过的门槛也越高。

另一个是多重比较的假发现率控制，常用的做法是 Benjamini-Hochberg（BH）校正。它的做法是：把 $N$ 个检验的 p 值从小到大排序，对第 $i$ 个 p 值使用阈值 $i/N \times \alpha$，找出满足条件的最大 $i$，把它以及它之前的检验判为显著。它控制的不是"一个都不错判"，而是"判为显著的那一批里错判的比例"，因此在金融里的大规模筛选场景比邦费罗尼校正更实用。邦费罗尼把阈值直接除以 $N$，过于保守，在 $N$ 上千时几乎筛不出任何东西。

Deflated Sharpe 与 BH 校正解决的问题略有不同。前者校正的是一个"经过大量尝试后挑出的最优结果"的夏普，后者控制的是一批检验里误报的比例。做因子筛选时两者可以配合使用：先用 BH 校正处理一批因子的显著性，再用 Deflated Sharpe 处理最终入选因子的夏普是否可信。

无论用哪一种，前提都是记录。若尝试的次数没有记录，$N$ 只能估计，校正的结果也就不可信。这是本章最想强调的一点：**校正的能力上限，取决于记录是否完整。**

### 特征数量与样本量的匹配

第 041 章已经指出，样本量受限于时间，横截面观测的有效样本量远小于观测数。这一节把它量化，用来判断一个模型是否可训练。

观测数容易得到，它等于标的数乘期数。有效样本量不是这个数。同一时期不同标的的收益互相相关，它们共同受市场、行业、宏观因素的影响，因此独立信息的数量被压缩。一个粗略的估计是：若横截面上标的之间的平均相关为 $\bar{\rho}$，则 $M$ 只标的的有效样本量约为

$$M_{\text{eff}} = \frac{M}{1 + (M-1)\bar{\rho}}$$

当 $\bar{\rho}$ 为零时，有效样本量等于标的数；当 $\bar{\rho}$ 接近 1 时，有效样本量趋近于 1。A 股标的之间的平均相关通常不低，同一行业内的相关更高，因此有效样本量会明显小于标的数。

有了有效样本量，就可以看它与特征数量的比例。经验上，有效样本量与特征数量之比应当保持在一个量级之上，具体门槛取决于模型复杂度与信噪比，不是固定数值。这个比的直觉是：每个待估的有效参数需要足够多的独立观测来支撑，否则估计的就是噪声。第 041 章第三条原则"复杂度与样本量匹配"在这里有了一个可计算的版本。

需要提醒的是，这个比例只是必要的筛查，不是充分的依据。比例达标不代表模型不会过拟合，比例不达标则几乎可以确定模型在拟合噪声。用它来做的第一个判断，是决定模型是否值得训练，而不是决定模型是否可用。

用一个例子看这个折算的力度。设横截面有五十只标的，平均相关为 0.3，则有效样本量约为 $50 / (1 + 49 \times 0.3) \approx 3.2$，也就是五十只标的在同一个时点上只相当于三点几个独立观测。若平均相关升到 0.5，有效样本量降到约 1.96。这说明在相关性高的样本里，横截面的独立信息被压缩得很厉害。把这个数与特征数量放在一起看，就能理解为什么在高相关场景下，能支撑的模型规模比观测数看起来小得多。这个折算为粗略估计，实际相关结构在行业与标的上并不均匀，但它给出的量级足以指导"该不该训练这个模型"的判断。

| 量 | 计算方式 | 用途 | 注意点 |
|----|---------|------|--------|
| 观测数 | 标的数乘期数 | 上界估计 | 会高估可用信息 |
| 横截面平均相关 | 逐日横截面相关对时间求平均 | 估算有效样本量 | 混算会偏高 |
| 有效样本量 | 按平均相关折算 | 与特征数比较 | 只是粗略估计 |
| 有效样本量与特征数之比 | 两数相除 | 判断是否可训练 | 必要非充分 |

### 超参数搜索的纪律

超参数搜索是搜索过拟合的主要来源。第 043 章已经给出了树模型关键超参数的范围，本节补充搜索过程本身的纪律。

第一条纪律是禁止在样本外反复试探。样本外之所以叫样本外，是因为模型没有见过它。一旦根据它的表现调整模型，它就被用作了验证集，独立性不复存在。测试集只使用一次，这条在第 041 章已经作为原则提出，这里强调它在超参数搜索上最容易违反，因为研究者会本能地想"再试一个参数看看会不会更好"。

第二条纪律是用嵌套交叉验证。做法是外层做模型评估，内层做超参数选择。外层把数据分成若干折，每一折上，内层再用一部分数据选超参数，然后在折外的数据上评估。这样超参数的选择没有用到评估数据，评估结果的偏差被控制。嵌套交叉验证的计算量是普通交叉验证的数倍，但在样本紧张、超参数众多时，它是把选择与评估分开的可靠方式。

第三条纪律是搜索空间事先确定并记录。参数的范围、取值、搜索方式都要在做研究之前定下来，写进日志。事后扩大范围会让尝试次数失控，也会让校正无从下手。若研究中途确实需要扩大范围，就把它当作一次新的搜索，记录在案。

第四条是搜索次数要计入多重比较校正。每一次超参数组合的尝试，都是一次检验。若一共试了 $N$ 组超参数，最终选出的那组的样本外表现，其显著性应当按 $N$ 次尝试校正，而不是按一次。不做这一步，从大量参数组合里挑出的最优组合，其表现会被系统性高估。这一条与前面搜索过拟合的校正是一致的，只是搜索的对象从因子组合变成了超参数组合。

把这四条放在一起，可以形成一条贯穿研究过程的纪律：先定搜索空间，再定切分方式，把每次尝试记录在案，最后按尝试次数校正。任何一步缺失，结论的可信度都会下降。

### 研究日志与可复现性

前面的校正都依赖记录，本节把记录的字段与用途交代清楚。研究日志不是流水账，它的作用有两个：一是让多重比较校正在事后可以进行，二是让结论可以被别人复核。

日志的最小字段包括：尝试的编号与时间、这次尝试的配置（用了哪些特征、哪个模型、哪组超参数）、切分方式（训练与测试的区间、净化与禁运的宽度）、以及统一的样本外评估结果。配置与切分方式决定了这次尝试与别次尝试是否可比，评估结果要在同一口径下计算，否则无法排序，也无法估计尝试次数对结果的抬升。

日志还要包含失败的结果。这一点前面已经强调，这里说明它在复核时的作用：只有当失败记录完整，别人才能算出真实的尝试次数 $N$，才能判断最终结果的显著性是否经过充分校正。只交付成功的那一次，等于把搜索规模隐藏起来，读者无法自行判断。

可复现性还要求固定几个容易漂移的东西。随机种子要固定，因为它会影响树模型的采样与神经网络的初始化。数据版本要记录，因为数据源会修订历史行情。代码版本要记录，因为特征定义可能被改动。这三样不固定，同一个流程跑两遍可能得到不同结果，讨论也就无从展开。

日志的粒度需要在成本与收益之间取舍。逐次记录全部配置会带来维护成本，过于简略又会让校正无法进行。一个折中的做法是自动记录，把配置与结果写入结构化文件，而不是靠人工手记。这样既不增加研究者的负担，又能让字段保持完整。

### 样本外衰减的监控

模型上线之后，需要一套机制判断它是否还在工作。核心指标是滚动样本外 IC，也就是在每个时点用过去一段窗口的数据，滚动计算模型预测与真实收益的秩相关。

监控的关键在于"衰减多少算异常"这个判读。一个容易犯的错误是拿当前 IC 与零比较，看到 IC 转负就认为模型失效。实际上 IC 本身在零附近波动，短期的负值很常见，随机也会出现。更合适的参照是模型自身的 IC 历史波动幅度：把当前的滚动 IC 放到它自己的历史分布里，看它落在什么分位。落在很低的尾部时，才说明表现异常。这与第 046 章讨论模型衰减时的判读方式一致：与分布比较，而不是与单点比较。

除了 IC 本身，还有几个监控指标值得一起看。换手率异常上升，往往意味着预测排序变得不稳定，可能是模型对噪声更敏感了。特征分布漂移，指模型输入特征的分布相对训练期发生明显偏移，这是模型失效的前兆。多空组合的收益分布变化，例如最大回撤持续扩大，也是需要关注的信号。

监控之后是响应。响应分两个层次：报警与重训。报警是记录异常并通知，重训是重新训练模型并更新。重训的条件通常设两个：滚动 IC 跌破历史低分位，或者连续若干期低于零。重训频率不宜过高，第 046 章已经说明，频繁重训等于在追逐近期噪声。设一个最短重训间隔，按固定节奏重训，是更稳妥的做法。

响应还需要回滚。若重训后的模型在随后的样本外表现没有改善，应当能回到上一个版本。回滚的判断依据同样是滚动样本外 IC，而不是单次的直觉。没有回滚机制，一次失败的重训可能让模型长期处于较差的状态。

监控方案在实施前需要先定阈值，而阈值的确定要在模型上线之前完成，用历史数据做回放。做法是把过去若干年想象成上线期，逐段滚动计算监控指标，看它在没有真实失效的时期落在什么范围，据此设定报警线。这样得到的报警线与模型自身的波动相匹配，比拍一个数字更可靠。阈值一旦确定，在一个监控周期内保持不变，避免看到结果之后再调整。

报警之后还应当区分程度。轻微越过阈值的，记录并继续观察，不立即动作；明显跌破并持续的，通知研究并准备重训；伴随换手率与特征分布同时异常的，优先排查数据问题而不是模型问题，因为数据源变动常会同时触发多个指标。分级响应能减少无谓的重训，也能让研究者的注意力落在真正需要处理的情况上。

先实现带净化与禁运的时间序列切分。

```python
import numpy as np
import pandas as pd

def purged_splits(dates, n_splits=4, label_horizon=5, embargo=5):
    """按时间切分并返回各折的训练与测试索引。
    dates 为按时间排序的唯一交易日；label_horizon 为标签持有期（交易日）；
    embargo 为禁运宽度（交易日）。训练样本剔除标签区间与测试重叠的部分。"""
    dates = np.sort(np.asarray(dates))
    bounds = np.array_split(dates, n_splits)
    splits = []
    for i in range(1, len(bounds)):
        test_dates = bounds[i]
        train_dates = np.concatenate(bounds[:i])
        t0, t1 = test_dates[0], test_dates[-1]
        # 测试标签区间上界：测试最后一天加上持有期
        test_label_end = np.datetime64(t1) + np.timedelta64(label_horizon, "D")
        # 净化：训练样本的标签区间若延伸进测试标签区间，则剔除
        keep = []
        for d in train_dates:
            train_label_end = np.datetime64(d) + np.timedelta64(label_horizon, "D")
            if train_label_end < np.datetime64(t0):
                keep.append(d)
        # 禁运：测试块之后再剔除一段，防止特征自相关传递
        embargo_start = test_label_end
        embargo_end = embargo_start + np.timedelta64(embargo, "D")
        keep = [d for d in keep if not (np.datetime64(d) >= embargo_start
                                         and np.datetime64(d) <= embargo_end)]
        splits.append((np.array(keep), test_dates))
    return splits
```

接着估算有效样本量。它需要横截面平均相关，先按日算相关，再对时间求平均。

```python
def avg_cross_corr(panel, ret_col="forward_5", date_col="date"):
    """标的间平均相关：整理成日期乘标的的收益矩阵，求相关矩阵后取上三角平均。
    注意这里算的是标的之间的相关，不是某个时点内两列因子的相关。
    后者在单时点上只有一个观测，估不出相关。"""
    wide = panel.pivot_table(index=date_col, columns="code", values=ret_col)
    corr = wide.corr(method="spearman")
    arr = corr.to_numpy()
    iu = np.triu_indices_from(arr, k=1)
    return float(np.nanmean(arr[iu]))

def effective_n(n_assets, avg_rho):
    """由标的数与平均相关估算有效样本量：相关越高，独立信息越少。"""
    return n_assets / (1 + (n_assets - 1) * avg_rho)

rho = avg_cross_corr(panel)
n_assets = panel["code"].nunique()
print("标的间平均相关", round(rho, 3),
      "有效标的数", round(effective_n(n_assets, rho), 2),
      "名义标的数", n_assets)
```

```r
library(dplyr)

# 横截面平均相关：把收益整理成日期乘标的的矩阵，求相关矩阵后取上三角平均
# 单个时点的横截面只有一个观测，相关系数只能在时间序列上估计
avg_cross_corr <- function(panel, ret_col = "forward_5") {
  wide <- panel |>
    select(date, code, all_of(ret_col)) |>
    tidyr::pivot_wider(names_from = code, values_from = all_of(ret_col)) |>
    arrange(date) |>
    select(-date)
  m <- cor(as.matrix(wide), use = "pairwise.complete.obs")
  m[upper.tri(m)]
}

# 有效样本量：标的数按平均相关折算，相关越高压缩越强
effective_n <- function(n_assets, avg_rho) n_assets / (1 + (n_assets - 1) * avg_rho)

rho <- mean(avg_cross_corr(panel), na.rm = TRUE)
n_assets <- dplyr::n_distinct(panel$code)
n_features <- 4        # 示意：四个候选特征

data.frame(
  标的数 = n_assets,
  平均相关 = round(rho, 3),
  有效样本量 = round(effective_n(n_assets, rho), 2),
  特征数 = n_features,
  有效样本量与特征数之比 = round(effective_n(n_assets, rho) / n_features, 2)
)
```

这里只有 5 只标的，平均相关与有效样本量的估计都不稳定。这段代码的作用是说明估算过程与它的量级含义：在标的数少、相关高时，有效样本量会远小于标的数，从而压缩了特征数量的生存空间。

多重比较校正在一批因子的 t 统计量上做 Benjamini-Hochberg 控制。

```python
from scipy import stats

def bh_correction(pvals, alpha=0.05):
    """Benjamini-Hochberg 假发现率校正，返回每个检验是否显著。"""
    p = np.asarray(pvals)
    order = np.argsort(p)
    n = len(p)
    thresh = alpha * (np.arange(1, n + 1) / n)
    passed = p[order] <= thresh
    # 取满足条件的最大序号，之前的都算显著
    k = np.where(passed)[0].max() + 1 if passed.any() else 0
    sig = np.zeros(n, dtype=bool)
    sig[order[:k]] = True
    return sig

# 示意：对若干候选因子做单因子 IC 检验，收集 t 统计量
def ic_tstat(panel, col, ret_col="forward_5", date_col="date"):
    def _ic(g):
        s = g.dropna(subset=[col, ret_col])
        return stats.spearmanr(s[col], s[ret_col])[0] if len(s) >= 5 else np.nan
    ic = panel.groupby(date_col).apply(_ic).dropna()
    return ic.mean() / ic.std() * np.sqrt(len(ic)) if ic.std() > 0 else np.nan

cands = ["ret5", "ma20_dev", "vol20", "vol_ratio"]     # 示意候选
ts = np.array([ic_tstat(panel, c) for c in cands])
pvals = 2 * (1 - stats.norm.cdf(np.abs(ts)))           # 双侧近似
sig = bh_correction(pvals, alpha=0.05)
print(pd.DataFrame({"因子": cands, "t": ts.round(2),
                    "p": pvals.round(4), "BH显著": sig}))
```

```r
legend("topright", legend = c("滚动 IC 均值", "历史 10% 分位"),
       col = c("steelblue", "firebrick"), lty = c(1, 2), bty = "n")
```

图中真正要看的是滚动 IC 相对它自身历史分布的落点。跌破历史低分位并持续，才是异常信号；短暂穿过零线不足以说明模型失效。这条曲线在 5 只标的上只会抖动剧烈，无法作为判读依据。

### R

R 侧可以用 `zoo` 或 `xts` 处理时间序列，`TTR` 计算指标。下面给出净化切分与 BH 校正的最小实现，逻辑与 Python 一致。

```r
library(dplyr)

# 净化切分：返回训练与测试日期集合，训练样本的标签区间不与测试重叠
purged_splits <- function(dates, n_splits = 4, horizon = 5, embargo = 5) {
  dates <- sort(unique(dates))
  bounds <- split(dates, cut(seq_along(dates), n_splits, labels = FALSE))
  lapply(seq(2, length(bounds)), function(i) {
    test <- bounds[[i]]
    train <- unlist(bounds[seq_len(i - 1)])
    t0 <- min(test); t1 <- max(test)
    test_end <- t1 + horizon
    train <- train[train + horizon < t0]          # 净化
    train <- train[!(train >= test_end & train <= test_end + embargo)]  # 禁运
    list(train = train, test = test)
  })
}

# BH 校正
bh_correction <- function(p, alpha = 0.05) {
  o <- order(p); n <- length(p)
  thr <- alpha * seq_len(n) / n
  pass <- p[o] <= thr
  k <- if (any(pass)) max(which(pass)) else 0
  sig <- logical(n); sig[o[seq_len(k)]] <- TRUE
  sig
}
```

R 侧这段只在少量数据上演示，切分与校正的逻辑与 Python 相同。真实使用时应把标签持有期与禁运宽度设为与预测窗口匹配的取值，并把全部尝试结果写入研究日志。

## 常见陷阱

**用随机切分评估模型。** 随机切分让相邻样本分处训练与测试，时间泄漏使表现虚高。金融数据一律按时间切分。

**只按日期切分而不做净化。** 标签是未来一段收益时，训练与测试的标签区间可能重叠。只按标签所在日期切分不足以形成隔离，需要按标签区间做净化。

**忘记禁运。** 净化处理标签重叠，禁运处理特征自相关带来的邻近泄漏。两者作用不同，缺一不可，隔离区宽度都不小于标签持有期。

**不记录失败的尝试。** 只记成功的结果，尝试次数无从估计，多重比较校正也无从下手。研究日志要包含失败结果。

**把邦费罗尼当代替方案。** 在 $N$ 上千的因子筛选里，邦费罗尼把阈值除以 $N$，过于保守，几乎筛不出任何因子。多数场景下应当用 BH 校正控制假发现率。

**把最优夏普直接上报。** 从大量尝试里挑出的最优夏普是有偏的。应当用 Deflated Sharpe 这类方法校正，或至少说明尝试的次数。

**用观测数代替有效样本量。** 同期标的的收益互相相关，有效样本量远小于观测数。直接用观测数乘特征数门槛，会高估可训练的模型规模。

**在测试集上反复调参。** 任何根据测试表现的调整都会让测试集变成验证集。所有调整在验证集完成，测试集只使用一次。

**用普通交叉验证选超参数。** 超参数的选择若与评估共用数据，评估结果会被污染。选择超参数应当用嵌套交叉验证，把选择与评估分开。

**忽略超参数搜索带来的多重比较。** 一次模型训练背后的超参数搜索可能包含几十次尝试，这些都要计入校正。只把最终模型当作一次检验，会低估搜索过拟合。

**把衰减判断建立在与零比较上。** IC 在零附近波动，短期为负很正常。判断异常应当与模型自身的历史分布比较。

**重训过于频繁。** 一触发就重训等于追逐近期噪声，还会抬高换手。应当设最短重训间隔，按固定节奏重训，并保留回滚。

**只监控不响应。** 有监控指标但没有报警阈值与响应流程，等于没有监控。监控要配套触发条件与处置动作。

**把稳健性当一次性动作。** 稳健性检查不是上线前做完就结束，而是要随模型运行持续进行。样本外监控本身就是稳健性检查的一部分。

**报警阈值上线后再定。** 阈值若在看到运行结果之后才设定，就会不自觉地迁就现有表现，失去报警的作用。阈值应当用历史回放事先确定，并在一个监控周期内保持不变。

**忽略随机种子与数据版本。** 种子不固定，同一流程跑两遍结果可能不同；数据版本不记录，行情修订会让结果无法复现。这两样与代码版本一样，都要写进日志。

**把清单当成流程的替代。** 自检清单是检查工具，不是先有清单再有研究。研究设计仍要围绕经济含义与样本外验证展开，清单只是用来确认关键环节没有被遗漏。

## 小结

本章处理模型层面的过拟合。过拟合有三个来源：搜索过拟合来自试得足够多，样本过拟合来自模型记住了训练数据，结构过拟合来自验证方式本身有漏洞。应对的方向不是消除过拟合，而是量化它并设定可接受上限。时间序列交叉验证有三种切法，滚动窗口、扩张窗口与净化切分，前两种用于训练组织，第三种最严格，适合评估与超参数选择。净化剔除标签区间与测试重叠的训练样本，禁运在测试块之后再留一段缓冲，两者隔离的宽度都不小于标签持有期，这是 de Prado 提出的净化与禁运的核心。多重比较校正在记录全部尝试的基础上进行，Deflated Sharpe 校正最优夏普的搜索偏差，BH 控制一批检验的假发现率，本章反复强调的一点是：不能记录尝试次数，就无法校正，也无法判断结果真伪。特征数量要与有效样本量匹配，有效样本量不等于观测数，同期标的的相关会大幅压缩它。超参数搜索的纪律有四条：不在样本外反复试探、用嵌套交叉验证、搜索空间事先确定并记录、搜索次数计入校正。样本外衰减用滚动 IC 监控，异常判断与模型自身的历史分布比较，而不是与零比较。本章给出了十五项验证方案自检清单，每一项都要有可查证的依据。
