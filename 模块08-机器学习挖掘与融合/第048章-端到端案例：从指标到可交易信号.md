# 第048章 端到端案例：从指标到可交易信号

前面七章分别处理了特征、树模型、序列模型、状态模型、融合与稳健性。本章把它们串成一条完整的流水线，从原始价格出发，经过特征构建、切分、基线、建模、融合、回测，一直走到上线监控。目标是走通一条可验证、可复现、可审计的流程，不是为了做出一个高收益策略。

需要在一开始就声明两件事。第一，本章展示的是流程，其中的任何表现数值都不构成收益预期。第二，受示例数据限制，流程中的若干环节无法在本章完整验证，第十步会逐项如实标注哪些没有通过，以及这对结论的影响。保留这份标注，是为了示范研究过程中诚实的态度，而不是为了掩盖不足。

## 案例设定

标的池一开始只有 5 只 A 股蓝筹，代码为贵州茅台（600519.SS）、招商银行（600036.SS）、中国平安（601318.SS）、宁德时代（300750.SZ）、五粮液（000858.SZ）。时间区间取 2023-01-01 至 2025-06-01。可用数据是日频的开盘、最高、最低、收盘与成交量。

用 5 只标的的原因是演示方便。5 只标的在任何一个横截面上只有 5 个样本，做横截面排序与分层回测时统计意义很弱，得到的 IC 与回测结果都不能当真。扩大方案是把标的池扩充到 50 只以上，覆盖尽可能多的行业，时间跨度拉到十年以上，并完成行业中性化。这一步是后续所有结论成立的前提，本章无法在 5 只标的上完成。

数据文件提供了两种规模，切换成本只有一行。`data/parquet/panel_blue_chip.parquet` 是本章用的 5 只标的，2905 行。`data/parquet/panel.parquet` 是 287 只、30 万行、2021-06 起的扩展面板，带行业字段与前向收益，把代码里的读取路径换掉就能跑真实横截面。后者仍然不满足十年区间的要求，但在样本量上跨过了"能下结论"的门槛。两者都由 `scripts/` 下的两个脚本从本地库生成，字段说明见 `data/README.md`。

目标定得具体：给每个标的在每个交易日打一个分数，用这个分数在横截面上排序，构造多空组合，并在计入交易成本后评估。评价口径全程沿用第 007 章，用秩相关 IC、ICIR 与分层回测的单调性，不另立标准。整个流程围绕一个原则展开：任何一步的输入都只依赖当日及之前的数据，任何结论都要在测试期上做一次样本外确认。

## 第一步：特征构建

从第二部分选 8 个跨类别的代表性指标，各自拆出一到两个特征，覆盖趋势、震荡、波动率、量价四个维度。选择它们的原因是维度不同、信息源互补，且构造规则清晰，便于复核。

| 维度 | 指标 | 拆出的特征 | 经济含义 |
|------|------|-----------|---------|
| 趋势 | 简单移动平均线 | 价格偏离度 | 价格相对二十日均线的位置 |
| 趋势 | 指数平滑异同平均线 | 柱状值归一 | 动能相对信号线的偏离 |
| 趋势 | 平均趋向指数 | 强度值 | 趋势强度，作门限变量 |
| 震荡 | 相对强弱指数 | 中轴偏离 | 读数相对五十的位置 |
| 震荡 | 随机指标 | K 减 D 的差 | 短期位置相对中轴的偏离 |
| 波动率 | 真实波幅 | 占价比率分位 | 波动幅度相对历史的水平 |
| 波动率 | 布林带 | 带宽 | 波动率的另一种度量 |
| 量价 | 能量潮 | 变化率 | 资金流向的边际变化 |

八个特征里，趋势类占三个，震荡类两个，波动率两个，量价一个。这样的配比是示意，实际研究应当按各维度的检验结果调整权重，而不是平均分配。

计算全部特征，并输出特征矩阵的维度与缺失率。

```python
import numpy as np
import pandas as pd

# 本地数据，由 xquant-db 导出，字段见 data/README.md
_panel = pd.read_parquet("data/parquet/panel_blue_chip.parquet")
CODES = {"600519.SS": "贵州茅台", "600036.SS": "招商银行",
         "601318.SS": "中国平安", "300750.SZ": "宁德时代",
         "000858.SZ": "五粮液"}

def build_features(code):
    _oneday = _panel[_panel["code"] == code].set_index("date").sort_index()
    raw = _oneday[["open", "high", "low", "close", "volume"]].copy()
    raw.columns = ["Open", "High", "Low", "Close", "Volume"]
    if raw.empty:
        return None
    d = raw.squeeze()[["Open", "High", "Low", "Close", "Volume"]].copy()
    d.columns = ["open", "high", "low", "close", "volume"]
    d["code"] = code
    c, h, l, v = d["close"], d["high"], d["low"], d["volume"]

    # 趋势：价格相对二十日均线的偏离度
    d["sma_dev"] = c / c.rolling(20).mean() - 1
    # 趋势：MACD 柱状值归一
    dif = c.ewm(span=12, adjust=False).mean() - c.ewm(span=26, adjust=False).mean()
    dea = dif.ewm(span=9, adjust=False).mean()
    d["macd_bar"] = (dif - dea) / c
    # 趋势：ADX 强度值（简化实现）
    up, dn = h.diff(), -l.diff()
    dmp = np.where((up > dn) & (up > 0), up, 0)
    dmn = np.where((dn > up) & (dn > 0), dn, 0)
    tr = pd.concat([h - l, (h - c.shift()).abs(), (l - c.shift()).abs()], axis=1).max(axis=1)
    dmp = pd.Series(dmp, index=d.index).ewm(alpha=1/14, adjust=False).mean()
    dmn = pd.Series(dmn, index=d.index).ewm(alpha=1/14, adjust=False).mean()
    trs = tr.ewm(alpha=1/14, adjust=False).mean()
    di_diff = 100 * (dmp - dmn) / trs
    d["adx"] = di_diff.abs().ewm(alpha=1/14, adjust=False).mean()
    # 震荡：RSI 相对中轴的偏离
    gain = c.diff().clip(lower=0).ewm(alpha=1/14, adjust=False).mean()
    loss = (-c.diff().clip(upper=0)).ewm(alpha=1/14, adjust=False).mean()
    d["rsi_dev"] = (100 - 100 / (1 + gain / loss)) - 50
    # 震荡：随机指标 K 减 D
    ll, hh = l.rolling(9).min(), h.rolling(9).max()
    rsv = (c - ll) / (hh - ll + 1e-9) * 100
    k = rsv.ewm(com=2, adjust=False).mean()
    dd = k.ewm(com=2, adjust=False).mean()
    d["kd_diff"] = (k - dd) / 100
    # 波动率：真实波幅占价格比率的历史分位
    d["atr_ratio"] = tr.ewm(alpha=1/14, adjust=False).mean() / c
    d["atr_rank"] = d["atr_ratio"].rolling(120, min_periods=40).apply(
        lambda x: (x[-1] > x).mean(), raw=True)
    # 波动率：布林带带宽
    ma20, sd20 = c.rolling(20).mean(), c.rolling(20).std()
    d["bb_width"] = (4 * sd20) / ma20
    # 量价：OBV 的十日变化率
    sign = np.sign(c.diff().fillna(0))
    obv = (sign * v).cumsum()
    d["obv_change"] = obv.diff(10) / obv.shift(10).abs().replace(0, np.nan)
    # 标签：未来五日收益
    d["forward_5"] = c.pct_change().shift(-5)
    return d.reset_index().rename(columns={"Date": "date"})

frames = [f for f in (build_features(k) for k in CODES) if f is not None]
panel = pd.concat(frames, ignore_index=True)

FEATURES = ["sma_dev", "macd_bar", "adx", "rsi_dev",
            "kd_diff", "atr_rank", "bb_width", "obv_change"]
print("面板维度", panel.shape)
print("特征缺失率")
print(panel[FEATURES].isna().mean().round(3))
```

```r
# 面板特征构建：8 个跨类别指标，全部用滚动窗口，只依赖当日及之前
library(quantmod)
library(dplyr)
library(TTR)

CODES <- c("600519.SS", "600036.SS", "601318.SS", "300750.SZ", "000858.SZ")

build_features <- function(code) {
  raw <- local({
    # 从本地 CSV 取该标的，转成 quantmod 可用的 xts
    .p <- read.csv("data/parquet/panel_blue_chip.csv", stringsAsFactors = FALSE)
    .p <- .p[.p$code == code, ]
    .x <- xts::xts(.p[, c("open", "high", "low", "close", "volume", "adjusted")],
                       order.by = as.Date(.p$date))
    colnames(.x) <- c("Open", "High", "Low", "Close", "Volume", "Adjusted")
    .x
  })
  d <- data.frame(date = index(raw), close = as.numeric(Cl(raw)),
                  high = as.numeric(Hi(raw)), low = as.numeric(Lo(raw)),
                  volume = as.numeric(Vo(raw)), code = code)
  sma20 <- zoo::rollmean(d$close, 20, fill = NA, align = "right")
  sd20  <- zoo::rollapply(d$close, 20, sd, fill = NA, align = "right")
  hl    <- d[, c("high", "low", "close")]

  # 趋势：价格相对二十日均线的偏离度
  d$sma_dev  <- d$close / sma20 - 1
  # 趋势：MACD 柱状值归一
  macd <- TTR::MACD(d$close, 12, 26, 9)
  d$macd_bar <- macd[, "macd"] / d$close
  # 趋势：ADX 强度值
  d$adx <- TTR::ADX(hl, n = 14)[, "ADX"]
  # 震荡：RSI 相对中轴的偏离
  d$rsi_dev <- TTR::RSI(d$close, n = 14) - 50
  # 震荡：随机指标 K 减 D
  stoch <- TTR::stoch(hl, nFastK = 9, nFastD = 3, nSlowD = 3)
  d$kd_diff <- (stoch[, "fastK"] - stoch[, "slowD"]) / 100
  # 波动率：真实波幅占价格比率的历史分位（120 日窗口）
  d$atr_ratio <- TTR::ATR(hl, n = 14)[, "atr"] / d$close
  d$atr_rank <- zoo::rollapply(d$atr_ratio, 120,
                               function(x) mean(x[-length(x)] < x[length(x)]),
                               fill = NA, align = "right")
  # 波动率：布林带带宽
  d$bb_width <- (4 * sd20) / sma20
  # 量价：OBV 的十日变化率
  obv <- TTR::OBV(d$close, d$volume)
  d$obv_change <- (obv - dplyr::lag(obv, 10)) /
                  pmax(abs(dplyr::lag(obv, 10)), 1e-9)
  # 标签：未来五日收益
  d$forward_5 <- d$close / dplyr::lead(d$close, 5) - 1
  d
}

panel <- bind_rows(lapply(CODES, function(k)
  tryCatch(build_features(k), error = function(e) NULL)))

FEATURES <- c("sma_dev", "macd_bar", "adx", "rsi_dev",
              "kd_diff", "atr_rank", "bb_width", "obv_change")
cat("面板维度", dim(panel), "\n")
print(round(colMeans(is.na(panel[, FEATURES])), 3))
```

这段代码同时产出 8 个特征与标签。所有特征都用滚动窗口计算，只依赖当日及之前的数据，其中波动率的滚动分位用 120 日窗口，其余指标用各自的标准窗口。这一步产生的特征矩阵在 5 只标的上约为数千行，列数等于特征数加标识与标签。

## 第二步：特征预处理与横截面标准化

预处理沿用第 007 章的口径，包含三步：去极值、行业中性、横截面标准化。第 007 章已经说明每一步的理由，这里只说明它在流水线里的位置。

前两步的目的都是让特征在横截面上可比。去极值把标准化后的值截断在正负三之间，防止个别异常值主导排序。行业中性在每个行业内减去行业均值，避免特征值实际代表的是行业属性。5 只标的分布在不同行业，本案例无法做有意义的行业中性化，这一步在真实研究中补上。

横截面标准化用中位数与绝对中位差，而不是均值与标准差，原因是金融特征分布厚尾，均值和标准差会被极值拉动。这一步要逐日进行。

有一个与建模特别相关的泄漏点需要强调：训练期与预测期的标准化要分别进行，不能用全样本的统计量。若用全样本的中位数与 MAD 标准化特征，预测期的标准化就用了预测期的分布信息，属于前视偏差。正确做法是用训练期统计出的统计量，应用到验证期与测试期；或者更严格地逐日滚动计算统计量。

```python
def winsorize_z(s):
    """逐日横截面标准化（中位数与 MAD），再截断到正负三。"""
    med = s.median()
    mad = (s - med).abs().median()
    z = (s - med) / mad if mad > 0 else s * 0.0
    return z.clip(-3, 3)

# 逐日横截面标准化，得到入模特征
for feat in FEATURES:
    panel[feat + "_z"] = panel.groupby("date")[feat].transform(winsorize_z)

ZFEATURES = [f + "_z" for f in FEATURES]

# 标签：逐日横截面标准化的未来五日收益，作为回归目标
def cs_std(g):
    med = g.median()
    mad = (g - med).abs().median()
    return (g - med) / mad if mad > 0 else g * 0.0

panel["y"] = panel.groupby("date")["forward_5"].transform(cs_std)
panel = panel.dropna(subset=ZFEATURES + ["y"])
print("可用样本", len(panel))
```

```r
# 逐日横截面标准化（中位数与 MAD），再截断到正负三
winsorize_z <- function(s) {
  med <- median(s, na.rm = TRUE)
  mad_ <- median(abs(s - med), na.rm = TRUE)
  z <- if (mad_ > 0) (s - med) / mad_ else s * 0
  pmax(pmin(z, 3), -3)
}

panel <- panel |>
  group_by(date) |>
  mutate(across(all_of(FEATURES), winsorize_z, .names = "{.col}_z")) |>
  ungroup()

ZFEATURES <- paste0(FEATURES, "_z")

# 标签：逐日横截面标准化的未来五日收益，作为回归目标
cs_std <- function(g) {
  med <- median(g, na.rm = TRUE)
  mad_ <- median(abs(g - med), na.rm = TRUE)
  if (mad_ > 0) (g - med) / mad_ else g * 0
}
panel <- panel |>
  group_by(date) |>
  mutate(y = cs_std(forward_5)) |>
  ungroup()
panel <- panel |> tidyr::drop_na(all_of(c(ZFEATURES, "y")))
cat("可用样本", nrow(panel), "\n")
```

这一步用的是全样本的逐日统计量，即每个横截面当天的中位数与 MAD。逐日计算本身不引入跨期的未来信息，但严格来说，标准化统计量应当只由训练期数据确定。本案例为简化，用逐日横截面统计量，它在同一横截面内不跨越时间，泄漏风险有限。真实研究若涉及跨期缩放，应当只在训练期估计统计量。

## 第三步：标签构造

标签用未来五日收益，并做两个处理：一是取横截面排名，二是再转成标准分。

用横截面排名而不是绝对收益作为标签，原因是排名标签对市场整体涨跌不敏感。某只标的当日收益为正，可能只是因为大盘在涨，它的相对强弱未必为正。横截面排名关注的是它相对同类的位置，这正是截面选股需要的。第 007 章的截面检验关心排序，第 043 章也指出回归输出最终交付的是排序表，标签用排名与这个目标一致。

上面的代码用的是逐日横截面标准分作为回归目标，它与排名高度接近，且保留了更多数值信息，适合回归模型。若用分类模型，可以把排名分成若干档。两种做法都行，关键是训练、验证、评价用同一个口径，不能中途更换。

标签持有期与重叠问题需要在这里交代。五日收益的标签在相邻交易日之间重叠四天，这会让样本之间高度相关，也会带来第二道泄漏：训练集末端的样本与测试集前端的样本，其标签区间可能重叠。这一点在第四步的切分里用净化与禁运处理。

```python
# 同时保留一个排名版本，便于与标准分版本对照
panel["y_rank"] = panel.groupby("date")["forward_5"].transform(
    lambda s: s.rank(pct=True) - 0.5)
print("标签标准差", round(panel["y"].std(), 3),
      "排名标签取值范围", (round(panel["y_rank"].min(), 2),
                          round(panel["y_rank"].max(), 2)))
```

关于标签还有一点需要提醒：五日收益是一个选择，不是唯一答案。持有期越长，标签与特征的衰减关系越弱，需要检验的窗口也越长。本案例固定用五日，是为了与第 007 章的 `forward_5` 口径一致，不代表五日是最优持有期。

## 第四步：数据切分

按时间顺序把数据切成训练、验证、测试三段，并在训练与验证之间、验证与测试之间留出隔离区。隔离区宽度不小于标签持有期，也就是五个交易日，本案例取更宽的十天，确保训练与评估在标签层面完全隔开。

| 区间 | 起止 | 用途 | 隔离 |
|------|------|------|------|
| 训练期 | 2023-01 至 2024-05 | 拟合基模型与元模型 | |
| 净化与禁运区 | 2024-05 至 2024-06 | 不参与训练 | 宽度约十天 |
| 验证期 | 2024-06 至 2024-12 | 早停与调参 | |
| 净化与禁运区 | 2024-12 至 2025-01 | 不参与训练 | 宽度约十天 |
| 测试期 | 2025-01 至 2025-06 | 最终评估一次 | |

训练期用于拟合模型，验证期用于早停与调参，测试期只用于最后确认，且只使用一次。第 047 章给出的净化与禁运在这里落地：隔离区内的样本不进入训练，也不进入评估，它的作用是切断训练与评估之间的标签重叠与邻近泄漏。

```python
TRAIN_END = pd.Timestamp("2024-05-31")
```

## 第五步：单因子基线

在建模之前，先算每个特征单独的 IC 与 ICIR，得到基线。这一步不能跳，它是后续所有模型改进的参照物。若某个复杂模型的表现没有超过最好的单因子，就没有理由引入它。

检验沿用第 007 章的 `cross_section_ic` 与 `ic_summary`，对八个特征分别计算，输出一张对照表。

```python
from scipy import stats

def cross_section_ic(panel, factor_col, ret_col, date_col="date"):
    """沿用第 007 章的横截面 IC 序列。"""
    def _ic(g):
        s = g.dropna(subset=[factor_col, ret_col])
        return stats.spearmanr(s[factor_col], s[ret_col])[0] if len(s) >= 5 else np.nan
    return panel.groupby(date_col).apply(_ic).dropna()

def ic_summary(ic):
    """沿用第 007 章的 IC 汇总。"""
    m, s = ic.mean(), ic.std()
    return pd.Series({"IC均值": round(m, 4), "IC标准差": round(s, 4),
                      "ICIR": round(m / s, 3) if s > 0 else np.nan,
                      "IC大于零比例": round((ic > 0).mean(), 3), "期数": len(ic)})

baseline = pd.DataFrame({f: ic_summary(cross_section_ic(train, f + "_z", "forward_5"))
                         for f in FEATURES}).T
print(baseline)
```

```python
def block_permutation_importance(model, X, y, block=20, n_repeat=5, seed=0):
    """分块排列重要性：在时间块之间置换，保留块内时序结构。"""
    rng = np.random.default_rng(seed)
    base = -np.mean((model.predict(X) - y) ** 2)
    idx = np.arange(len(X))
    blocks = np.array_split(idx, max(1, len(X) // block))
    out = {}
    for c in X.columns:
        drops = []
        for _ in range(n_repeat):
            Xp = X.copy()
            order = rng.permutation(len(blocks))
            new_idx = np.concatenate([blocks[p] for p in order])
            Xp[c] = Xp[c].to_numpy()[new_idx]
            drops.append(base - (-np.mean((model.predict(Xp) - y) ** 2)))
        out[c] = float(np.mean(drops))
    return pd.Series(out).sort_values(ascending=False)
```

```r
# 分块排列重要性：在时间块之间置换，保留块内时序结构
block_permutation_importance <- function(model, X, y, block = 20,
                                         n_repeat = 5, seed = 0) {
  set.seed(seed)
  base <- -mean((predict(model, as.matrix(X)) - y)^2)
  n <- nrow(X)
  # 按时间顺序切成若干块，块内元素保持原有顺序
  blocks <- split(seq_len(n), ceiling(seq_len(n) / block))
  out <- numeric(ncol(X)); names(out) <- colnames(X)
  for (c in colnames(X)) {
    drops <- numeric(n_repeat)
    for (r in seq_len(n_repeat)) {
      Xp <- X
      order_idx <- sample(seq_along(blocks))            # 打乱块的顺序
      new_idx <- unlist(blocks[order_idx], use.names = FALSE)
      Xp[[c]] <- X[[c]][new_idx]                        # 按块顺序重排该列
      drops[r] <- base - (-mean((predict(model, as.matrix(Xp)) - y)^2))
    }
    out[c] <- mean(drops)
  }
  sort(out, decreasing = TRUE)
}
```

## 第七步：序列模型

序列模型的输入是带时间维的张量，与表格模型的组织方式不同。本案例用第 044 章的滑动窗口方法重组数据，训练一个小的 LSTM，重点在于数据的组织正确，不在模型规模。

窗口取二十个交易日，特征沿用八个标准化特征。窗口只覆盖末端及之前的数据，标签取窗口末端之后的五日收益。切分点要留出不小于窗口长度的缓冲期，避免训练窗口与验证窗口在时间上重叠。

```python
import torch
import torch.nn as nn

STRIDE = 1      # 步长

def make_sequences(df, features, target, T, stride=1):
    """把面板切成 [N, T, F] 张量与标签，窗口不含未来。"""
    Xs, ys, dates, codes = [], [], [], []
    for code, g in df.groupby("code"):
        g = g.sort_values("date").reset_index(drop=True)
        X = g[features].to_numpy(dtype=np.float32)
        y = g[target].to_numpy(dtype=np.float32)
        dd = g["date"].to_numpy()
        for end in range(T, len(g), stride):
            win = X[end - T:end]
            if np.isnan(win).any() or np.isnan(y[end]):
                continue
            Xs.append(win); ys.append(y[end])
            dates.append(dd[end]); codes.append(code)
    return (np.stack(Xs), np.array(ys, dtype=np.float32),
            np.array(dates), np.array(codes))

# 窗口在训练期内构造，避免跨越切分边界
```

```python
class LSTMRegressor(nn.Module):
    def __init__(self, n_features, hidden=16, dropout=0.2):
        super().__init__()
        self.lstm = nn.LSTM(n_features, hidden, num_layers=1, batch_first=True)
        self.drop = nn.Dropout(dropout)
        self.head = nn.Linear(hidden, 1)

    def forward(self, x):
        out, _ = self.lstm(x)
        return self.head(self.drop(out[:, -1, :])).squeeze(-1)

torch.manual_seed(0)
model_lstm = LSTMRegressor(n_features=len(ZFEATURES))
opt = torch.optim.Adam(model_lstm.parameters(), lr=1e-3)
loss_fn = nn.MSELoss()

trX_t, trY_t = torch.tensor(trX), torch.tensor(trY)
vaX_t, vaY_t = torch.tensor(vaX), torch.tensor(vaY)

best, wait, tr_hist, va_hist = np.inf, 10, [], []
for epoch in range(200):
    model_lstm.train(); opt.zero_grad()
    loss = loss_fn(model_lstm(trX_t), trY_t)
    loss.backward(); opt.step()
    model_lstm.eval()
    with torch.no_grad():
        va_loss = loss_fn(model_lstm(vaX_t), vaY_t).item()
    tr_hist.append(loss.item()); va_hist.append(va_loss)
    if va_loss < best - 1e-6:
        best, wait = va_loss, 0
        torch.save(model_lstm.state_dict(), "lstm_best.pt")
    else:
        wait += 1
        if wait >= 10:
            break
print("最佳验证损失", round(best, 5))
```

```python
def layered_returns(panel, factor_col, ret_col, q=5, date_col="date"):
    def _assign(g):
        g = g.dropna(subset=[factor_col, ret_col]).copy()
        if len(g) < q:
            return None
        g["group"] = pd.qcut(g[factor_col].rank(method="first"), q, labels=False) + 1
        return g
    tmp = panel.groupby(date_col, group_keys=False).apply(_assign).dropna(subset=["group"])
    grp = tmp.groupby(["date", "group"])[ret_col].mean().unstack()
    gm = grp.mean()
    mono, _ = stats.spearmanr(gm.index.values, gm.values)
    return gm.round(5), round(mono, 3)

for col in ["equal", "gb", "fused"]:
    print(col, ic_summary(cross_section_ic(fuse, col, "y")).to_dict())
print("融合信号分层回测", layered_returns(fuse, "fused", "forward_5"))
```

这一段同样只在 5 只标的上运行，三种方案的差异多半来自噪声。真实研究需要 50 只以上标的与行业中性化，才能让方案之间的差异具备统计意义。

## 第九步：回测与成本

分层回测把标的按信号分成若干组，比较多空两端的收益。本案例只做示意，重点是成本的计入方式与 A 股的可交易性约束，而不是收益数值。

换手率决定成本。单边换手定义为相邻两期持仓集合的差异比例，成本按双边计。本案例的分层回测按月调仓，费率取 0.0003，印花税取 0.001 单边。

```python
def backtest_ls(panel, factor_col, ret_col, date_col="date", q=3,
                fee=0.0003, stamp=0.001, rebalance="ME"):
    """多空组合回测，按月调仓，计入费率与印花税。"""
    df = panel.dropna(subset=[factor_col, ret_col]).copy()
    df["period"] = pd.to_datetime(df[date_col]).dt.to_period("M")

    prev_long, prev_short = set(), set()
    rows = []
    for p, g in df.groupby("period"):
        g = g.copy()
        g["grp"] = pd.qcut(g[factor_col].rank(method="first"), q, labels=False) + 1
        long = g[g["grp"] == q]
        short = g[g["grp"] == 1]
        long_set = set(long["code"])
        short_set = set(short["code"])
        gross = long[ret_col].mean() - short[ret_col].mean()
        # 单边换手：本次持仓相对上期的差异比例，多空各算一次
        def turnover(now, prev):
            if not prev:
                return 1.0
            return 1 - len(now & prev) / max(len(now), 1)
        turn = turnover(long_set, prev_long) + turnover(short_set, prev_short)
        # 成本近似：单边换手之和乘以单边成本，费率双边计，印花税按卖出计
        cost = turn * (fee + stamp)
        rows.append({"period": p, "gross": gross, "turnover": turn, "net": gross - cost})
        prev_long, prev_short = long_set, short_set

    out = pd.DataFrame(rows)
    ann = (1 + out["net"]).prod() ** (12 / len(out)) - 1
    sharpe = out["net"].mean() / out["net"].std() * np.sqrt(12) if out["net"].std() > 0 else np.nan
    return out, round(ann, 4), round(sharpe, 2)

out, ann, sharpe = backtest_ls(fuse, "fused", "forward_5")
print("平均单边换手", round(out["turnover"].mean(), 3),
      "平均毛收益", round(out["gross"].mean(), 4),
      "平均净收益", round(out["net"].mean(), 4))
```

```r
# 多空组合回测：按月调仓，计入费率与印花税
backtest_ls <- function(panel, factor_col, ret_col, q = 3,
                        fee = 0.0003, stamp = 0.001) {
  df <- panel |>
    filter(!is.na(.data[[factor_col]]), !is.na(.data[[ret_col]])) |>
    mutate(period = format(date, "%Y-%m"))

  prev_long <- character(); prev_short <- character()
  rows <- list()
  for (p in sort(unique(df$period))) {
    g <- df |> filter(period == p)
    g$grp <- ntile(rank(g[[factor_col]]), q)
    long <- g |> filter(grp == q); short <- g |> filter(grp == 1)
    lset <- long$code; sset <- short$code
    gross <- mean(long[[ret_col]]) - mean(short[[ret_col]])
    # 单边换手：本次持仓相对上期的差异比例，多空各算一次
    turnover <- function(now, prev) {
      if (length(prev) == 0) return(1.0)
      1 - length(intersect(now, prev)) / max(length(now), 1)
    }
    turn <- turnover(lset, prev_long) + turnover(sset, prev_short)
    # 成本近似：单边换手之和乘以单边成本，费率双边计，印花税按卖出计
    cost <- turn * (fee + stamp)
    rows[[length(rows) + 1]] <- data.frame(period = p, gross = gross,
                                           turnover = turn, net = gross - cost)
    prev_long <- lset; prev_short <- sset
  }
  out <- bind_rows(rows)
  ann <- prod(1 + out$net)^(12 / nrow(out)) - 1
  sharpe <- if (sd(out$net) > 0) mean(out$net) / sd(out$net) * sqrt(12) else NA_real_
  list(out = out, ann = round(ann, 4), sharpe = round(sharpe, 2))
}

bt <- backtest_ls(fuse, "fused", "forward_5")
cat("平均单边换手", round(mean(bt$out$turnover), 3),
    "平均毛收益", round(mean(bt$out$gross), 4),
    "平均净收益", round(mean(bt$out$net), 4), "\n")
```

A 股的可交易性约束会让理论收益打折扣，回测要把这些约束计入，否则净收益会被高估。三条主要约束是 T+1 交易、涨跌停与停牌。

T+1 意味着当日买入的标的当日不能卖出，调仓信号若在当日收盘生成，最早在次日才能成交。处理方式是把持仓按信号滞后一期执行，本案例的多空回测已经隐含了这一点，因为收益用的是调仓之后的未来收益。

涨跌停意味着涨停或跌停的标的可能无法成交。做法是在生成持仓时剔除当日一字涨停或跌停的标的，或者在次日无法买入时用下一可成交日替代。数据里若无涨跌停标记，需要按价格变动幅度判断，例如当日涨跌幅接近上下限且收盘价等于当日最高或最低价时，视为难以成交。

停牌意味着标的在某段时间没有交易，特征与收益都缺值。做法是把停牌期从样本中剔除，并注意停牌前后的特征计算要保持一致，避免停牌造成的缺口被误当成形态。

```python
# 简化的可交易性过滤示意：按涨跌幅识别可能难以成交的时点
def tradable_mask(df, limit=0.098):
    """标记可能非可交易的样本：收盘价接近涨跌停。"""
    c = df["close"]
    up_limit = c.pct_change() >= limit
    dn_limit = c.pct_change() <= -limit
    return ~(up_limit | dn_limit)

fuse["tradable"] = tradable_mask(fuse)
print("可交易样本占比", round(fuse["tradable"].mean(), 3))
```

```r
# 简化的可交易性过滤示意：按涨跌幅识别可能难以成交的时点
tradable_mask <- function(df, limit = 0.098) {
  df <- df |> arrange(code, date) |> group_by(code) |>
    mutate(ret1 = close / lag(close) - 1) |> ungroup()
  # 首行无前收，按可交易处理；涨跌幅达到阈值视为难以成交
  is.na(df$ret1) | abs(df$ret1) < limit
}

fuse <- fuse |> arrange(code, date)
fuse$tradable <- tradable_mask(fuse)
cat("可交易样本占比", round(mean(fuse$tradable), 3), "\n")
```

模型上线之后，需要一套监控与响应机制。监控指标有三个。滚动样本外 IC 反映预测能力是否还在，换手率反映信号是否变得不稳，特征分布漂移反映输入是否偏离训练期。

监控的判断标准是第 047 章说明的那条：与模型自身的历史分布比较，而不是与零比较。跌破历史低分位并持续，才视为异常。

重训的触发条件设两个：滚动 IC 跌破历史低分位，或者连续若干期低于零。两者同时满足时优先重训。为避免追逐噪声，设一个最短重训间隔，按固定节奏重训，而不是一触发就立即重训。

回滚机制规定如下：重训后的模型在随后一段样本外的滚动 IC 若没有改善，回到上一个版本。回滚的判断依据同样是滚动 IC，而不是单次结果。

监控还需要记录。每一次报警、重训与回滚都要写进日志，字段与第 047 章建议的一致，包括时间、触发指标、处置动作与结果。这些记录在事后复核与判断模型是否长期有效时都要用到。

## 案例小结

把流程走一遍之后，可以回到全书一直强调的立场：技术指标不是买卖口诀，是可以计算、可以检验、可以建模的特征。流水线的价值在于任何一个环节都可以被单独检查与替换：特征构造有问题，只换特征；切分有问题，只改切分；融合有问题，只调融合。每一步的输入输出明确，出了问题能定位到具体环节，这比一个整体看不见内部的模型更可用。

本案例也暴露了流水线的边界。它证明流程可以跑通，不能证明策略盈利。第 5、6、7 项自检未通过，说明结论的显著性缺乏支撑；样本量与特征数不匹配，说明模型更可能在拟合噪声。这些没有被掩盖，而是明确写出来，因为掩盖它们会让结论看起来比实际更强。

最后给一条提醒：流程正确不等于策略盈利。市场有效性会持续侵蚀已知的信号，一个今天有效的信号，可能因为被越来越多的人使用而衰减。流水线与监控机制的作用，是在信号衰减时能及时发现并响应，而不是让它长期有效。
