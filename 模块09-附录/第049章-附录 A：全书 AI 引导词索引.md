# 第049章 附录 A：全书 AI 引导词索引

本附录把全书中出现的 AI 引导词按类别集中整理，便于快速查阅和复用。

引导词的作用是把读者从"读代码"推进到"做研究"。每个指标章里的代码实现只演示了指标的计算和信号识别，但一个指标的研究远不止于此：参数是否稳健、因子是否有效、换手率能否承受、与同类指标相比是否有优势，这些问题都需要逐一检验。引导词就是把这些检验步骤写成可以直接交给 AI 助手的自然语言任务。

用法很简单：把引导词连同指标名称一起复制给 AI 助手，再按需补充标的、区间、参数。引导词里给出的周期、区间、阈值都是示例，不是固定要求。研究目的不同，这些取值都应调整。

本附录按六类任务组织：参数敏感性检验、因子有效性检验、对照实验、规则化与回测、双重检验（截面与择时）、机器学习（挖掘与融合）。每一类先说明适用场景，再给出若干条代表性模板。模板的数量控制在二十余条，覆盖常用的研究动作，而不是穷举每个指标。

前四类服务于第二部分与第三部分的单指标研究，后两类服务于第三部分的双重检验流程与第四部分的建模工作。

## 参数敏感性检验类

参数敏感性检验回答的问题是：指标的表现是来自参数背后的经济逻辑，还是来自对历史数据的拟合。

技术指标的参数选择有一个陷阱。在历史数据上寻找让收益最高的参数，几乎总能找到一两个表现突出的取值，但这样的参数往往在样本外失效，因为价格序列的噪声足以让某些取值偶然地看起来特别出色。稳健的参数应该在一定的取值区间内都表现平稳，而不是集中在一两个孤立的点上。

这一类的引导词适合用在指标研究的起点。先确认参数是否稳健，再往下做因子检验，可以避免在过拟合的参数上浪费后续工作。下面给出四条模板，分别针对单参数扫描、双参数矩阵、周期匹配和分布敏感性。

::: prompt 模板 1：单参数扫描与过拟合识别

我在研究某个技术指标作为选股因子。请帮我设计一个参数敏感性检验方案：把指标的周期参数从最小值到最大值依次取值，在 A 股沪深 300 成分股近五年的数据上，分别计算每个参数下因子的 IC 均值和 ICIR，并画出两条曲线随参数变化的走势。请说明如何从曲线判断参数是稳健的还是过拟合的：如果 IC 在一段区间内平稳，说明参数稳健；如果只在某个孤立取值上出现尖峰，说明是拟合。请输出可直接运行的 Python 代码，只使用 pandas、numpy、yfinance、matplotlib。

:::

## 因子有效性检验类

因子有效性检验回答的问题是：指标转成因子之后，是否能够稳定地区分未来收益的高低。

一个指标在图上看起来有信号，不代表它能作为选股因子。因子研究有一套标准的检验流程：计算信息系数衡量方向稳定性，做分层回测观察收益是否单调，控制行业和市值暴露排除风格干扰。这一套流程在本书的每个指标的量化检验段落里都有描述，引导词把这些步骤写成可执行的指令。

这一类的引导词适合在参数确定之后使用。下面给出四条模板，分别针对基础 IC 检验、分层单调性、中性化处理和波动率类指标的特殊口径。

::: prompt 模板 5：基础 IC 与 ICIR 计算

我构造了一个技术指标因子，想检验它的有效性。请帮我写一段 Python 代码：1）用横截面数据（至少 50 只标的）计算每个时点各标的的因子值；2）计算因子值与未来 1 日、未来 5 日收益的 Spearman 秩相关系数，得到 IC 序列；3）计算 IC 均值、IC 标准差、ICIR（IC 均值除以标准差）以及 IC 为正的时点占比；4）输出一张结果表；5）用文字说明 IC 均值、ICIR、正值占比分别反映因子的什么性质，以及判断阈值应该怎么定。请只使用 pandas、numpy、yfinance、matplotlib，并用带中文注释的代码。

:::
::: prompt 模板 6：分层回测与单调性检验

我构造了一个技术指标因子，已经算出 IC 为正，想进一步看它是否单调。请帮我写一段分层回测的 Python 代码：1）每个调仓时点，按因子值把标的等分为五组；2）计算每组的等权组合在下一期的收益；3）累计各组收益，画出五条净值曲线；4）输出一张表，列出每组的年化收益、波动率、夏普比率和换手率；5）用文字说明如何从净值曲线和分组收益判断因子的单调性，以及如果中间组收益明显偏离、首尾两组却差距不大，可能说明什么。请把交易成本计入回测。

## 对照实验类

对照实验回答的问题是：这个指标比另一个指标好吗，好在什么条件下。

单个指标的表现容易受市况影响，看不出它的相对优势。把两个指标放在同一段数据、同一套检验流程下比较，才能看清楚差异来自哪里。对照实验的价值在于控制变量：同样的标的、同样的区间、同样的调仓频率，只有指标本身在变，比较结果才有意义。

这一类的引导词适合在指标研究的中段使用，也适合用来检验对某个指标的直觉判断是否成立。下面给出四条模板，分别针对同类指标对比、参数变体对比、市况分组对比和组合叠加对比。

::: prompt 模板 9：同类指标的横向对照

我想比较两个量价类指标作为因子的表现。请帮我写一段 Python 代码：1）两个指标使用同一批标的、同一段区间、同一套检验流程；2）两个因子都做横截面标准化；3）分别计算与未来 5 日收益的 Rank IC 均值、ICIR 和正值占比，以及两个因子之间的相关系数；4）做分层回测，输出两张净值曲线对比；5）用文字说明两者在什么市场环境下表现更优，以及如果两个因子高度相关，是否应该只用其中一个，还是应该做组合。请只使用 pandas、numpy、yfinance、matplotlib。

:::
::: prompt 模板 10：平滑方式变体的对照

我想比较同一指标在等权平滑、线性加权平滑和指数平滑三种方式下的差异。请帮我写一段 Python 代码：1）对每种平滑方式分别计算指标；2）在相同的检验流程下，比较三种方式的 IC 均值和 ICIR；3）额外统计一个反映灵敏度的指标，比如信号出现的平均间隔天数；4）输出对照表；5）用文字说明平滑方式是"灵敏度与稳定性的取舍"这一说法在数据上是否成立，以及在不同持有周期下应该选哪种。请避免依赖未安装的第三方指标库，用 rolling 和 ewm 实现。

:::
::: prompt 模板 11：市况分组下的信号质量对比

我想知道一个趋势类指标在不同市况下的表现差异。请帮我写一段 Python 代码：1）用平均趋向指数 ADX 的读数把每个时点划分为趋势市（ADX 高）和震荡市（ADX 低）；2）在这两类市况下，分别计算指标因子的 IC 均值和分层回测收益；3）再按市场整体涨跌（比如指数近 20 日收益的正负）做第二次分组；4）输出一个二乘二的对照表；5）用文字说明该指标是否只在趋势市有效，以及如果只在趋势市有效，实际使用时应该怎样加一个市况过滤器。请输出可直接运行的 Python 代码。

::: prompt 模板 12：指标叠加是否有增量

我同时使用两个技术指标，想知道叠加是否比单用更好。请帮我设计对照实验：1）分别单用指标 A、单用指标 B、等权合成 A 和 B 三个因子；2）在同一检验流程下计算三者的 IC 均值和 ICIR；3）做分层回测，比较三张净值曲线的收益和最大回撤；4）计算 A 与 B 的相关系数；5）用文字说明在什么相关系数范围内叠加能带来分散化收益，在什么范围内叠加只是把同一个信号重复了一遍。请输出可直接运行的 Python 代码，并说明合成方式应该选等权还是按 IC 加权。

## 规则化与回测类

规则化与回测回答的问题是：一个模糊的交易直觉，能否写成可执行、可检验的规则，并且在计入成本后仍然成立。

交易经验多以含糊的形式存在："背离之后要小心""放量突破才可信""横盘蓄势之后会爆发"。这些说法在语言上成立，却无法回测，因为缺少精确的定义。规则化的第一步就是消除含糊：什么叫"背离"，什么叫"放量"，"之后"是多长，把每一个词都换成可以计算的量。

这一类的引导词适合在指标研究的后段使用，也适合把某一章的信号描述推进到完整策略。下面给出四条模板，分别针对信号定义、进出场与止损、成本与偏差、以及完整的回测报告。

::: prompt 模板 13：模糊信号的精确化

我观察到"价格与指标出现背离"是一个可能有效的信号，但这个说法太模糊，无法回测。请帮我把条件写成精确的规则：1）如何定义"价格创新高"和"指标未创新高"，用什么窗口、取收盘价还是最高价、是否允许容差；2）背离的确认时点是发生时还是发生后若干日；3）信号的有效期多长，多长未验证就失效；4）如何避免同一个背离被重复计数。请输出带中文注释的 Python 代码，并用文字说明这些定义中的每一个选择会如何影响信号数量和质量。

:::
::: prompt 模板 14：进出场与止损规则

我有一套基于技术指标的买入条件，但还没有卖出规则。请帮我补全策略：1）建仓条件保持现状，请帮我把它写成代码；2）设计三种卖出规则并对比：固定持有期、指标反向穿越、基于真实波幅的跟踪止损；3）对每种规则计算策略的年化收益、最大回撤、胜率和平均持有期；4）输出对照表；5）用文字说明止损过紧和过松分别会带来什么问题，以及为什么用真实波幅而非固定百分比来设定止损距离更合理。请输出可直接运行的 Python 代码。

:::
::: prompt 模板 15：成本与偏差的核查

我有一个技术指标策略的回测结果，看起来收益不错，但我不确定是否可信。请帮我核查：1）列出回测中可能导致前视偏差的地方，逐项检查我的代码有没有这些问题；2）说明生存者偏差在选股池构造中如何体现，如何修正；3）说明 A 股的费率和印花税应该如何计入，换手率高时对净收益的影响有多大；4）请帮我做一次敏感性测试，把费率和印花税提高一倍，看收益还剩多少；5）用文字总结结果中最不可信的三个环节。

::: prompt 模板 16：完整策略的回测报告

我完成了基于某个技术指标的策略研究，请帮我把结果整理成一份完整的回测报告。报告需要包含：1）策略逻辑与信号定义；2）标的池、区间、调仓频率、成本设定；3）绩效指标，包括年化收益、波动率、夏普比率、最大回撤、换手率、胜率；4）与等权基准的对比，超额收益和超额最大回撤；5）分年度和分市况的表现拆解；6）一段对结果局限性的讨论，至少指出三个可能影响结论的因素。请给出生成行业标准图表（净值曲线、回撤曲线、月度收益热力图）的 Python 代码。

## 双重检验类：截面与择时

第三部分把每个指标的检验拆成两条线：截面选股能力回答"买哪只"，择时能力回答"何时买"。两者的数据组织方式不同，前者的每个切片是横截面，后者的每个切片是时间序列；用途也不同，前者用于构建组合，后者用于决定仓位。把两者合并成一个"有效性"判断，会掩盖关键信息。

这一类的引导词用于搭建完整的双重检验流程，以及诊断两类检验各自的常见问题。下面给出四条模板。

::: prompt 模板 17：搭建截面与择时的双重检验

我要对一个技术指标做完整的双重检验，请帮我搭流程。要求：1）横截面检验，在沪深 300 成分股上计算该指标与未来 1 日、5 日收益的 Rank IC 序列，输出 IC 均值、标准差、ICIR、t 统计量、IC 大于零比例；2）分层回测，按指标值分五组，输出各组年化收益与单调性系数；3）择时检验，在指数本身的时间序列上输出极端分位触发日与非触发日的收益差异检验、五档条件分位收益、择时策略相对买入持有的年化收益与最大回撤对照；4）把两部分结果整理成两张表，并说明如果两部分结论不一致，应该优先相信哪一个。请用 Python 实现，只用 pandas、numpy、scipy。

:::
::: prompt 模板 18：IC 序列的不稳定性诊断

:::
::: prompt 模板 19：极端样本不足时的择时检验

我要检验一个震荡类指标的择时能力，但指标的极端值样本占比只有 12% 左右。请帮我设计稳健的检验方案。要求：1）说明样本量不足会给 t 检验带来什么问题，特别是收益分布厚尾与自相关的影响；2）改用五档条件分位检验替代硬阈值检验，输出每档的平均收益与样本数；3）对最高档与最低档的差异做块状自助抽样检验，说明为什么它比普通 t 检验更适合时间序列；4）给出样本量的最低要求建议，以及样本不足时结论应如何表述。请输出可运行的 Python 代码。

::: prompt 模板 20：条件 IC 的检验

我想验证一个说法：趋势成立时，震荡指标的超买超卖信号更有效。请帮我把这个说法做成条件 IC 检验。要求：1）说明为什么用条件掩码而不是直接对样本分组；2）用趋势状态（例如价格是否位于 60 日均线上方）作为掩码，在掩码为真的子集内计算震荡指标的横截面 IC，与无条件 IC 对照；3）说明掩码带来的样本量损失，以及掩码条件过严时如何影响结论可靠性；4）给出一张对照表，列含无条件 IC、条件 IC、样本量占比、判读结论。请用 Python 实现。

## 机器学习类：挖掘与融合

第四部分处理的是人工构造特征与线性加权方法已经触及的天花板：线性加权表达不了特征之间的交互效应，权重全局固定无法随市况调整，人工拆解出的特征是否为充分统计量也无从验证。

这一类的引导词覆盖三个层次：特征生成与筛选、模型训练与超参数纪律、以及多个模型输出的融合。需要注意，机器学习放大了过拟合的空间，因此这类引导词都要明确要求时间切分与样本外验证。下面给出四条模板。

::: prompt 模板 21：自动化特征生成与筛选

我要从一个技术指标自动生成候选特征。请帮我设计生成与筛选流程。要求：1）定义算子集合，包含变化类、相对类、滚动统计类、排序与状态类、交叉类五类；2）用两层组合生成候选特征，说明第一层与第二层分别是什么，并估算生成数量；3）按三个层次筛选，先按经济含义剔除无法解释的特征，再按覆盖率与相关性聚类做统计筛选，最后用模型重要性做驱动筛选，说明为什么次序不能颠倒；4）输出筛选后的特征清单与每个特征的保留理由。请用 Python 实现，只用 pandas、numpy、scipy、scikit-learn。

:::
::: prompt 模板 22：树模型训练与超参数纪律

我要用梯度提升树把技术特征映射到未来收益，请帮我搭训练流程。要求：1）数据按时间切分为训练、验证、测试三段，说明每段的作用与隔离区设置；2）给出超参数设定的依据，至少包括树深度、学习率与迭代轮数、行采样与列采样、最小叶子样本数，并说明在金融数据上最小叶子样本数为什么要设得比通用场景大；3）用验证集做早期停止，说明为什么不能用测试集调参；4）输出特征重要性与排列重要性的对照，并说明两者不一致时该相信哪一个。请用 Python 实现，使用 lightgbm 或 xgboost。

:::
::: prompt 模板 23：堆叠融合的正确做法

我要把三个模型的输出融合成一个信号，请帮我用堆叠方法实现。要求：1）说明为什么元模型的训练输入必须来自基模型的样本外预测，如果用训练集上的预测会有什么后果；2）用时间序列交叉验证生成基模型的样本外预测，给出扩张窗口的实现代码，说明切分点如何确定；3）把三个模型的输出先转成横截面排名再融合，说明为什么要做这一步；4）比较等权融合、按样本外 IC 加权、堆叠三种方案，并说明如果融合后的 ICIR 介于最好与最差基模型之间，说明什么。请用 Python 实现。

:::
::: prompt 模板 24：过拟合的量化诊断

我做完了模型训练，结果看起来不错，想确认是否过拟合。请帮我做量化诊断。要求：1）区分三个过拟合来源：搜索过拟合、样本过拟合、结构过拟合，分别给出检测方法；2）实现净化与禁运，说明标签持有期重叠时如何确定隔离区宽度；3）如果我在研究过程中一共试过两百种特征与参数组合，最好的那个夏普比率是否有意义，应该怎么做多重比较校正，以及无法记录尝试次数时会有什么后果；4）诊断有效样本量与特征数的比例是否足够，说明为什么有效样本量不等于观测数。请输出可运行的 Python 代码与一张诊断结论表。

## 使用提醒

引导词只是研究的起点，不是结论的来源。以下几点在使用时需要留意。

**AI 生成的代码和结论必须自行验证。** 引导词写得好，AI 也可能在实现细节上出错：索引对齐有偏差、滚动窗口的边界处理不一致、收益率的复权方式不对，这些错误不会在代码运行时报错，却会让结论完全失效。拿到代码后应先用一段人工可核对的小样本验证，再放到全样本上跑。

**AI 容易在回测中引入前视偏差。** 最典型的是用当日收盘价计算指标、又假定当日收盘价成交，或者用整个样本期的分位数确定阈值。让 AI 明确回答"这个量在决策时点上是否可得"，往往能暴露这类问题。生存者偏差同样需要主动提醒，因为 AI 默认使用的成分股名单通常是当下的名单，天然排除了被剔除和退市的标的。

**引导词只给方向，不给结论。** 引导词的任务是描述要做什么研究、怎么做、输出什么格式，而不是暗示结果应该是什么。如果引导词里预设了"这个因子应该有效"，AI 可能会顺着这个方向选择数据和参数。更好的写法是把问题开放出来，让结果自己说话，包括接受"这个指标在横截面上没有增量信息"这样的结论。
