# 第050章 附录 B：公式速查表

本附录按四类汇总全书 28 个指标的核心公式，作为写作和实现的参照。公式默认使用前复权价格与成交量数据，均线类指标默认作用于收盘价序列。

## 符号约定

| 符号 | 含义 |
|------|------|
| $p_t$ | 第 t 日收盘价 |
| $o_t$ | 第 t 日开盘价 |
| $h_t$ | 第 t 日最高价 |
| $l_t$ | 第 t 日最低价 |
| $v_t$ | 第 t 日成交量 |
| $n$ | 周期参数，取值随指标而变 |
| $\alpha$ | 指数平滑系数，$\alpha = 2/(n+1)$ |
| $\mathrm{SMA}_t^{(n)}$ | n 日简单移动平均 |
| $\mathrm{EMA}_t^{(n)}$ | n 日指数移动平均 |
| $\mathrm{WMA}_t^{(n)}$ | n 日加权移动平均 |
| $\mathrm{TR}_t$ | 第 t 日真实波幅 |
| $\sigma_t^{(n)}$ | n 日收益率标准差 |
| $\mathrm{sd}_t^{(n)}$ | n 日价格标准差 |

各表中"输出范围"一列的"价格量纲"指读数的单位与价格相同，"无界"指数值没有理论上下限。

## 趋势类

| 指标 | 缩写 | 核心公式 | 默认参数 | 输出范围 |
|------|------|---------|---------|---------|
| 简单移动平均线 | SMA | $\frac{1}{n}\sum_{i=0}^{n-1}p_{t-i}$ | n = 20 | 价格量纲 |
| 指数移动平均线 | EMA | $\alpha p_t + (1-\alpha)\mathrm{EMA}_{t-1}$ | n = 20 | 价格量纲 |
| 加权移动平均线 | WMA | $\frac{\sum_{i=0}^{n-1}(n-i)\,p_{t-i}}{n(n+1)/2}$ | n = 20 | 价格量纲 |
| 双指数移动平均线 | DEMA | $2\mathrm{EMA}_t - \mathrm{EMA2}_t$ | n = 20 | 价格量纲 |
| 零延迟指数移动平均线 | ZLEMA | $\alpha d_t + (1-\alpha)\mathrm{ZLEMA}_{t-1}$，$d_t = 2p_t - p_{t-\mathrm{lag}}$，$\mathrm{lag}=\lfloor (n-1)/2\rfloor$ | n = 20 | 价格量纲 |
| 双移动平均线 | DMA | $\mathrm{SMA}_t^{(n_1)} - \mathrm{SMA}_t^{(n_2)}$ | n1 = 10，n2 = 50 | 价格量纲差值 |
| 多空指数 | BBI | $\frac{1}{4}\left(\mathrm{SMA}^{(5)}+\mathrm{SMA}^{(10)}+\mathrm{SMA}^{(20)}+\mathrm{SMA}^{(60)}\right)$ | 5/10/20/60 | 价格量纲 |
| 指数平滑异同平均线 | MACD | $\mathrm{DIF}=\mathrm{EMA}^{(12)}-\mathrm{EMA}^{(26)}$，$\mathrm{DEA}=\mathrm{EMA}(\mathrm{DIF},9)$，柱 $=2(\mathrm{DIF}-\mathrm{DEA})$ | 12/26/9 | 无界 |
| 动向指标 | DMI | $\mathrm{DI}^{\pm}=\frac{\mathrm{EMA}(\mathrm{DM}^{\pm},n)}{\mathrm{EMA}(\mathrm{TR},n)}\times 100$ | n = 14 | 0 至 100 |
| 平均趋向指数 | ADX | $\mathrm{EMA}\left(\frac{\lvert \mathrm{DI}^{+}-\mathrm{DI}^{-}\rvert}{\mathrm{DI}^{+}+\mathrm{DI}^{-}}\times 100,\ n\right)$ | n = 14 | 0 至 100 |
| 抛物线指标 | SAR | $\mathrm{SAR}_t = \mathrm{SAR}_{t-1} + AF\,(EP-\mathrm{SAR}_{t-1})$ | AF 0.02，上限 0.2 | 价格量纲 |

趋势类的输出分两种量纲。均线族与 SAR 的输出与价格同量纲，用于看图判断位置；MACD 与 DMI、ADX 的输出无量纲，便于横向比较。DMA 是两条均线的差，量纲仍是价格，但含义是距离而非位置。

## 震荡类

| 指标 | 缩写 | 核心公式 | 默认参数 | 输出范围 |
|------|------|---------|---------|---------|
| 相对强弱指数 | RSI | $100 - \frac{100}{1+RS}$，$RS=\frac{\overline{U}}{\overline{D}}$ | n = 14 | 0 至 100 |
| 随机指标 | KDJ | $\mathrm{RSV}=\frac{p_t-L_n}{H_n-L_n}\times 100$，$K=\frac{m_1-1}{m_1}K_{t-1}+\frac{1}{m_1}\mathrm{RSV}$，$J=3K-2D$ | 9/3/3 | K、D 为 0 至 100，J 无界 |
| 商品通道指数 | CCI | $\frac{\mathrm{TP}_t-\overline{\mathrm{TP}}_t}{0.015\times \mathrm{MAD}_t}$，$\mathrm{TP}=\frac{h_t+l_t+p_t}{3}$ | n = 20 | 无界 |
| 威廉指标 | WPR | $\frac{H_n - p_t}{H_n - L_n}\times (-100)$ | n = 14 | −100 至 0 |
| 变化率指标 | ROC | $\frac{p_t - p_{t-n}}{p_{t-n}}\times 100$ | n = 12 | 无界 |
| 变化率动量指标 | CMO | $\frac{\mathrm{UpSum}_t - \mathrm{DownSum}_t}{\mathrm{UpSum}_t + \mathrm{DownSum}_t}\times 100$ | n = 14 | −100 至 100 |
| 去趋势价格震荡器 | DPO | $p_t - \mathrm{SMA}_t^{(k)}$，$k=\lfloor n/2\rfloor+1$，并向右位移 $k-1$ 位 | n = 20 | 无界 |
| 随机动量指数 | SMI | $\frac{\mathrm{Dev}_t}{\mathrm{MaxDev}_t}\times 100$，$\mathrm{Dev}=p_t-\frac{H_n+L_n}{2}$ | n = 14，信号 3 | −100 至 100 |

震荡类的共同特征是把价格信息映射到有界刻度。RSI、KDJ、WPR 的边界来自构造方式本身；CCI、ROC、DPO 没有理论边界，超买超卖阈值来自经验。SMI 介于两者之间，理论范围是 −100 到 100，实际读数很少触及两端。

## 波动率类

| 指标 | 缩写 | 核心公式 | 默认参数 | 输出范围 |
|------|------|---------|---------|---------|
| 平均真实波幅 | ATR | $\mathrm{ATR}_t = \frac{\mathrm{ATR}_{t-1}(n-1)+\mathrm{TR}_t}{n}$，$\mathrm{TR}_t=\max(h_t-l_t,\ \lvert h_t-p_{t-1}\rvert,\ \lvert l_t-p_{t-1}\rvert)$ | n = 14 | 正数，价格量纲 |
| 历史波动率 | HV | $\sqrt{\frac{1}{n}\sum_{i=0}^{n-1}r_{t-i}^2}\times\sqrt{252}$，$r_t=\ln(p_t/p_{t-1})$ | n = 20 | 正数，百分比 |
| 布林带 | BBands | 中轨 $\mathrm{SMA}^{(n)}$，上轨 $+k\,\mathrm{sd}$，下轨 $-k\,\mathrm{sd}$ | n = 20，k = 2 | 价格量纲 |
| 肯特纳通道 | Keltner | 中轨 $\mathrm{EMA}^{(n)}$，上轨 $+k\,\mathrm{ATR}^{(m)}$，下轨 $-k\,\mathrm{ATR}^{(m)}$ | n = 20，m = 10，k = 2 | 价格量纲 |
| 价格包络线 | Envelope | 中轨 $\mathrm{SMA}^{(n)}$，上轨 $\times(1+p)$，下轨 $\times(1-p)$ | n = 20，p = 0.03 | 价格量纲 |

波动率类指标的读数量纲分两类。ATR 与 HV 是纯粹的波动幅度度量，前者是价格，后者是百分比；通道类指标输出的是价格，但通道宽度本身携带波动率信息，宽度变化往往比中轨方向更有用。

## 量价类

| 指标 | 缩写 | 核心公式 | 默认参数 | 输出范围 |
|------|------|---------|---------|---------|
| 能量潮 | OBV | $\mathrm{OBV}_t=\mathrm{OBV}_{t-1}+\operatorname{sign}(p_t-p_{t-1})\,v_t$ | 无参数 | 累积量，无界 |
| 柴金资金流量 | CMF | $\frac{\sum \mathrm{MFV}}{\sum v}$，$\mathrm{MFM}=\frac{(p_t-l_t)-(h_t-p_t)}{h_t-l_t}$，$\mathrm{MFV}=\mathrm{MFM}\times v_t$ | n = 20 | −1 至 1 |
| 成交量震荡器 | VO | $\frac{\overline{v}_t^{(S)}-\overline{v}_t^{(L)}}{\overline{v}_t^{(L)}}\times 100$ | S = 10，L = 20 | 无界百分比 |
| 弹性成交量加权移动平均线 | EVWMA | $\frac{v_t p_t + \mathrm{EVWMA}_{t-1}(W_t-v_t)}{W_t}$，$W_t=\sum_{i=0}^{n-1}v_{t-i}$ | n = 20 | 价格量纲 |

量价类的输出范围差异最大。OBV 是无界的累积量，绝对值没有意义，只能看走势；CMF 落在有界区间内，可以直接设定阈值；VO 是无界百分比，正负表示量能扩张或收缩；EVWMA 与价格同量纲，用法与普通均线一致。

## 参数默认值一览

下表汇总 28 个指标在本书中的默认参数。这些取值来自各指标章的公式说明和 TTR 包的实现，实务中应根据标的特性和持有周期调整。

| 类别 | 指标 | 默认参数 |
|------|------|---------|
| 趋势 | SMA | n = 20 |
| 趋势 | EMA | n = 20 |
| 趋势 | WMA | n = 20 |
| 趋势 | DEMA | n = 20 |
| 趋势 | ZLEMA | n = 20 |
| 趋势 | DMA | n1 = 10，n2 = 50 |
| 趋势 | BBI | 5、10、20、60 |
| 趋势 | MACD | 快 12，慢 26，信号 9 |
| 趋势 | DMI | n = 14 |
| 趋势 | ADX | n = 14 |
| 趋势 | SAR | 加速因子 0.02，步进 0.02，上限 0.2 |
| 震荡 | RSI | n = 14 |
| 震荡 | KDJ | n = 9，m1 = 3，m2 = 3 |
| 震荡 | CCI | n = 20 |
| 震荡 | WPR | n = 14 |
| 震荡 | ROC | n = 12 |
| 震荡 | CMO | n = 14 |
| 震荡 | DPO | n = 20 |
| 震荡 | SMI | 区间 14，信号线 3 |
| 波动率 | ATR | n = 14 |
| 波动率 | HV | n = 20，年化因子 252 |
| 波动率 | BBands | n = 20，倍数 2 |
| 波动率 | Keltner | 中轨 20，ATR 周期 10，倍数 2 |
| 波动率 | Envelope | n = 20，偏移 3% |
| 量价 | OBV | 无参数 |
| 量价 | CMF | n = 20，阈值 ±0.05 |
| 量价 | VO | 短期 10，长期 20 |
| 量价 | EVWMA | n = 20 |

参数取值集中在三类数字上：14、20 和 10/20 的组合。14 的来源与 Wilder 的原始设定有关，他的一系列指标都使用 14 日；20 大致对应一个月的交易日数；10 与 20 的组合是短期与中期的常用划分。这些数字成为习惯不是因为它们最优，而是因为它们被反复使用，形成了一种默认的参照。研究中不应把它们当作固定值，而应视为起点，用参数敏感性检验确认在目标品种上是否稳健。
