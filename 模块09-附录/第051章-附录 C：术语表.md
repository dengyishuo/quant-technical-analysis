# 第051章 附录 C：术语表

全书出现的统计、交易与机器学习术语，按使用频率挑选 30 条。每条给一句能独立读懂的解释，以及它主要出现在哪一章。

指标名称本身（SMA、MACD 等）不在此表，各指标章的第一节已经交代了全称、缩写与来历。

## 人名与缩写的读法

中文文献里这些名字通常直接音译，讲座与音频里读原文时容易读错，列在这里备查。

| 原文 | 常见读法 | 相关指标 |
|---|---|---|
| Wilder | 怀尔德 | RSI、ATR、DMI、ADX、SAR |
| Schabacker | 舒巴克 | 早期形态与均线整理 |
| Granville | 格兰维尔 | OBV |
| Bollinger | 布林格 | 布林带 |
| Keltner | 肯特纳 | 肯特纳通道 |
| Chaikin | 柴金 | CMF |
| Appel | 阿佩尔 | MACD |
| Lane | 莱恩 | KDJ |
| Williams | 威廉斯 | WPR |
| Lambert | 兰伯特 | CCI |
| Chande | 钱德 | CMO |
| Blau | 布劳 | SMI |

缩写一般逐字母读，例如 SMA 读 S-M-A、IC 读 I-C。MACD 在口语里有"马克迪"的读法，书面场合仍以逐字母为准。ICIR 读 I-C-I-R，不要读成一个词。

## 小结

这张表的作用是让读者在遇到不熟悉的词时能快速定位，而不是替代正文。任何一条解释都省略了适用条件，真正的定义在对应章节里。术语的价值不在名字，而在它约束了什么：说一个因子有 IC，只是说排序与未来收益相关，没有说它能赚钱；说一个策略样本外有效，才第一次触及了证据。
